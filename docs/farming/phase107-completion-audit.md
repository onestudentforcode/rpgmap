## 复现入口

```powershell
.\test-p10-7.bat                    # 全链；未变更且完整的分区自动复用
.\test-p10-7.bat -Stage Model -Models transactions
.\test-p10-7.bat -Stage Run -Cases barter
.\test-p10-7.bat -Stage Audit -Cases barter
.\test-p10-7.bat -Stage Probes
.\test-p10-7.bat -Stage Report
.\test-p10-7.bat -Stage UI           # 含GPU；SkipGpu只作局部检查，不能代替Accept
.\test-p10-7.bat -Stage Accept       # 不运行经营，只核对所需证据是否仍有效
```

独立运行Python时，多个case/model用空格分隔，例如`python tools/farming/test_p107.py --stage Run --cases barter stage-resources`。PowerShell直调`.ps1`可传数组。`-Fresh`只使本次请求的工作不复用；运行器保留独立日志，重跑场景/冒烟先归档原证据。改审计器只重审，不要求重新经营；源码或产物变化只会使依赖它的证明失效。

## 结论边界

声明夹具的初始资源/现金不是经营收入；无注入场景和成长参考模块的证明范围不同。标准成本筛查与有条件的完整上游容量方案不称为整链玩家实测或普遍净利润。主观试玩、正式美术与发行包不在本期技术验收内；未代签用户主观认可。
