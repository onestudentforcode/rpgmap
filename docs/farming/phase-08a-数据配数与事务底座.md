继承P7的60元石、24AP/日、15日/时节、20×22地图、三槽及既有种植/牧渔/加工/供货。登记6新增物种、8新增设施、38资源/采购凭证、24工艺＋3变体和12研究；未实施能力显式标记不可执行，不能直接开放所有内容或免费发样本。

本阶段实装水场实际换水生成污水，作为后续T04研究样本来源；净水菌床运行留P8.e。地图布局审核使用现有20×14陆地和20×8水库，不扩大地图、不引入付费扩地。

## 3. 配置与状态职责

| 配置/状态 | 必须表达的内容 | 边界 |
|---|---|---|
| 资源 | ID、名称、属性、供养资格、买卖价、用途、标准成本来源 | 属性不推导食材/燃料资格，买价0不表示免费 |
| 物种 | 标准单位、成长、基础食谱、生产条件、容量与去留 | 群/只/培养单位不混为单体模拟 |
| 设施 | 占地/地形、造价、能力标签、所属研究 | 类别不隐含配方，研究台基础可建 |
| 配方 | 精确投入/产出、普通日或有效维护日、执行物种/设施 | 活体与普通加工不能共用错误的日期完成判断 |
| 研究 | 前置、样本、启动费、有效日、解锁ID | 12项目无环，不能用本项目产物当启动样本 |
| 运行策略 | 负责人、优先级、持续生产、目标及保留量 | 配置状态不免费执行动作 |
| 事务状态 | 日界标记、实例UID、实际服务、资源流、冻结回顾 | 每次实际变化只入账一次 |

38项登记含培养采购凭证：培养单位买入直接占设施容量，不同时加进库存。幼体采购同样必须预检空间和全部费用，失败不扣款、不部分购入。

后续阶段逐步加入花源、研究、活体工艺、设备状态的严格快照校验；本阶段先确定公共事务和扩展位置，不塞入尚无用途的模拟字段。数据烘焙应稳定排序，同输入连续两次结果一致，正式运行加载烘焙产物。

## 4. 成本编译与供养值冻结

按资源表权重计算标准成本：种子/幼体购入、标准原料来源、成长与首轮维护、启动/维护/收取AP及时间；加工追加标准投入。一次性建筑/研究开支进入经营账，不摊进食材供养值。保留旧食材静态值，新合格食材取`max(1, ceil(单份分摊成本))`。

成本表须输出来源节点、标准参考轮、原料量、AP、有效日/普通日、分摊权重、每份未取整成本和最终供养值。多年生和留存动物按标准首个成熟生产轮，不能按无限寿命摊到零；水、腐殖土等旧物品用固定既有来源，回收路线不递归改价。

油籽花同时有供花与种实产出，必须在**同一标准轮的总成本内**统一分摊。资源表的花蜜/花粉与油籽/花瓣比例是各子组比例，不能给两组各摊100%的整轮成本；外层初值、参考花期份额和默认花源来源见资源表，由本阶段复算后冻结。授粉额外油籽不作为基准产量，避免成本表依赖循环增益。

蜂群消耗的是本地花源份额，标准成本需计入供花来源，但不能再加入玩家未执行的手采AP，或把内流伪装成库存消费。净化和岩兽日粮、厨房木炭均须计入；铁份额审计不是元石成本节点。新多产物分摊缺项必须报错，不默认为每项背整批成本。

市场审计使用实际整数订单结算，检查采购直交及购买原料加工再交路径。若新饲料/净化/加工没有成本、产能或用途上的价值，在冻结前调整初值；不能靠供养值虚高和涨售价掩盖无成本循环。静态审核通过不等于90日平衡通过。

## 5. 日界事务与自动存档

服务日D与`total_days`零起点的对应关系必须在唯一时间适配层定义，不让新模块各自使用`day+1`。统一顺序：D开日设备一次运行→手动动作→日结雇工→普通加工及有效服务推进→D资源账/报告和45日快照冻结→D+1开日→所属槽提交。

新档先执行首日开日，读档只恢复已有开日状态；新建/修改装置次日生效。P8.g尚未实装时开日设备步骤为空，但事务位置固定。最后1AP的手动作与主动结束当天走同一日界流程，任务服务记录必须在消耗AP触发日结**之前**建立。

建议在独立候选状态中完成日结并校验、写盘，成功后发布新状态。失败恢复触发操作前的完整状态，并保留唯一待提交候选、锁定普通操作；“重试保存”只写该候选，成功后应用一次，不能重新运行雇工/生态/开日。“放弃当天”恢复原槽最后有效档案，清除候选。候选内容和已恢复状态必须在UI中区分。

如果最末AP采收触发保存失败，库存、采收标记、人工费、研究/花源/设备日标记和回顾都恢复到触发操作前；重试成功才应用这一采收及日结。磁盘写入使用临时文件/备份，断点恢复以最后有效快照为准；成功写盘后的异常不能把同一候选再当新日结执行。

每日实际材料账保持`期末＝期初＋入库－出库`，先冻结D再记D+1设备消耗；现金含出售、订单、采购、建造、研究与人工等实际项。未收取/内部生态流/预测不并入库存恒等式，第45日回顾不混入46日开日消费。

## 6. 基础换水与布局检查

P8换水须有动物、状态<满值、当天未换水、材料/AP可支付；成功后扣清水、提升状态、发污水并记录共同日标记。数量从资源表读取，手动/雇工共享标记，空场/满值/重复/失败不产污水。V2原有维护规则不在本批改变。

输出一份布局/启动预算审核：八类设施、两种岩兽分别占场、必要供花株、旧加工/牧渔和资源点能在现地图安排；不需要人物通道模拟，但不覆盖资源点或越界。研究样本从正常起始物资及默认路线能取得，启动草案不靠开发注入。
