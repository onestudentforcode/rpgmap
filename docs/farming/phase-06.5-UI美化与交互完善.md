## 1. 定位与边界

V1已经交付种植、资源点、加工、五行订单、普通雇工、三槽日存档和首次45天回顾，并提供Windows占位美术试玩包。以此作为已完成的玩法基线；Phase 6.5提升信息可读性、操作效率和视觉一致性。

推进顺序为：**Demo V0（Phase 0～6）→ Demo V1（已完成）→ Phase 6.5（UI与交互）→ Demo V2（养殖等，另行设计）**。Phase 6.5是开发阶段编号，不另行定义产品“V1.5”。

本阶段沿用现有四植物、三资源点、四设施和配方、五行食材与rank、固定价格、AP和雇工结算规则。维持20×14地图、共享库存、无人物实体、建造拆除手动执行、V1独立三槽与每日自动存档。用户确认Phase 6.5收尾后将`play.bat`和F5默认切换到新版，V0保留独立入口与历史测试；当前工作区入口尚未修改。

养殖、水产、蛊虫本体、物流和新生产路线留后续版本；经济数值不因UI改版自动调整。完整作物阶段图、设施场景图的制作另列美术批次，本阶段先处理UI图标、缩略图和界面装饰。音乐不在本批范围内。

## 3. 分批实施

每批依次完成实现、相关检查、真实窗口截图核对与执行记录。代码、测试、文档按类型分批提交；新增资产单独成批。未实施项保持未勾选。

### P6.5.a：布局与基础交互

目标是先解决侧栏过载与误操作。以2560×1440为主独立安排UI尺寸，避免将640×360整张界面放大。地图上的目标详情留在右侧可收起侧栏；行囊/市场、订单、雇工管理与回顾采用较宽的固定窗口，一次打开一个。窗口关闭后保留地图位置和已选目标。

- [ ] 整理开始页、三槽卡与顶部状态栏，明确日期/AP/元石和功能入口。
- [ ] 将全局管理窗口与地格/资源点/设施详情分开，统一标题、返回和关闭行为。
- [ ] 农务工具选中态、悬停说明、框选有效/无效预览与数量提示。
- [ ] 地格详情按当前状态突出可执行动作，持续选种与等待原因可见。
- [ ] 买卖先支持数量输入和总价预览；完整物品分类与卡片留下一批。
- [ ] 统一成功变化、失败原因和危险操作确认；接入V1显示设置。
- [ ] 右键取消框选/当前放置操作；Esc先取消当前操作，再关闭最上层窗口，最后进入游戏菜单。
- [ ] 框选/放置后工具持续选中；右键回到查看。清理/拆除/覆盖确认，批量清理每次框选只确认一次，成熟收获/砍伐不反复弹确认。
- [ ] 文本输入、模态窗口和面板滚动正确阻断地图点击、框选与缩放。

### P6.5.b：高频经营面板

目标是让玩家一次看清投入、结果与阻塞条件，减少反复切页和长距离滚动。

- [ ] 行囊/市场分类、筛选、快捷数量、持有/可购/可售数量及总价。
- [ ] 建设入口与放置预览：完整占地、可放/冲突位置、材料与元石造价。
- [ ] 加工配方卡、缺料提示、进度/剩余天数、待收提醒和领取反馈。
- [ ] 雇工人员卡、工作优先级表、预算与成功工作量，负责区域定位/单项删除。
- [ ] 资源点产量/日额度/指派状态与五行订单必要数量/回款并列显示。
- [ ] 日摘要分类与关联目标定位，保存原有逐条报告和时节小结的形式。
- [ ] 45天回顾以宽版经营账对照总计和三个时节，期末库存清晰列出。

### P6.5.c：统一视觉与收尾

目标是形成明亮、柔和、可读的东方玄幻经营界面。用户已取消沿用墨绿深底及像素风的限制；首稿采用暖米白、浅茶绿与少量柔陶色，具体见新美术指导。印章、账册分隔、木牌等元素用于标题和少量状态装饰；正文和高频图标保持简洁。后续世界图片必须核对边缘拼接、相机机位和光照，完整场景美术仍另批制作。

- [ ] 统一字体层级、间距、按钮尺寸、焦点/选中/禁用/悬停状态。
- [ ] 按清单补齐UI图标和缩略图，更新风格表及资产登记。
- [ ] UI缩放独立于地图缩放；设置变化后窗口、输入坐标和框选范围一致。
- [ ] 对2560×1440主规格、1920×1080、1280×720及960×540紧凑窗口截图逐页核对，检查系统/UI缩放、遮挡、溢出和滚动。
- [ ] 完成相关回归、独立Windows包重建与发行版冒烟，更新操作说明。
- [ ] 收尾将`play.bat`和F5默认切换到新版，V0保留显式入口并验证独立存档。

## 4. UI资产清单与风格

| 类别 | 预计数量 | 说明 |
|---|---:|---|
| 农务/区域工具图标 | 10 | 与实际工具一一对应，清理/砍伐/区域编辑明确区分 |
| 物品图标 | 18 | 行囊、市场、投入与产物复用；资源点可复用对应物品图标 |
| 植物缩略图 | 4 | 面板识别用，不等于整套生长阶段场景图 |
| 设施图标 | 4 | 建设页与加工面板复用 |
| 五行徽记 | 5 | 金木水火土配文字，不能仅靠颜色区分 |
| 状态与通用导航 | 按复用需求 | 成熟、缺料、待收、暂停、关闭、返回等，无需人物肖像 |

设计色值集中在[Phase 6.5 UI色板](ui-design/phase65-ui-palette.json)，实现时建立对应V1主题，避免直接改变V0历史主题。正文和辅助文字对比度至少4.5:1，状态同时提供文字或形状。UI资产与世界逻辑64单位地格分开确定；新非像素素材的尺寸、过滤与alpha规范按母版验证结果制定，不强制沿用NEAREST缩至64px和二值alpha。现有V0资产保持其历史校验规范。

图标先验证小尺寸辨识度，再制作变体；完整场景美术仍按母版审核后衍生的流程另批推进。东方玄幻元素适量加入，避免装饰占据经营信息的空间。

## 5. 交互与数据约束

- 悬停、筛选、数量预览、放置预览与任务状态查询都是只读；不扣AP、元石或材料，不推进日期，不创建任务。
- 农务工具仍添加雇工待办标记；玩家手动动作仍调用原有操作接口。资源点单独指派雇工，建造/拆除仍手动执行。
- 数量买卖、订单交付、投料和收取复用V1模型校验；不足或无效输入失败零改动，连续点击不重复结算。同次操作不得拆成绕过余额/库存校验的多次UI扣款。
- 清理、拆除与存档覆盖确认显示当前对象及实际损失/返还规则；批量清理每次框选只确认一次，成熟收获/砍伐直接按原有校验执行。取消操作零改动；批量框选不因预览而执行农事。
- 日结束、末AP、存档失败阻断与重试沿用现有流程。窗口切换、缩放和报告重看不触发日结；失败重试不再次劳动或收费。
- 首次45天统计和三个时节小计的口径保持不变；只改善呈现。旧V1缺失历史的提示继续保留，不补造旧记录。

## 6. 验收清单

- [ ] 从开始页选择槽、种植、加工、交易、供货、派工、结束一天到回顾，各流程可用鼠标完成。
- [ ] 常用面板能看清当前状态、完整投入、预期结果和阻塞原因；高频动作不依赖长列表反复寻找。
- [ ] 框选/建设预览与实际判定一致；UI输入不穿透地图，取消/关闭/返回无误操作。
- [ ] 买卖数量、资金/库存不足、重复点击、危险操作取消和存档失败重试验证通过。
- [ ] 2560×1440主规格、1920×1080、1280×720及紧凑窗口在支持的系统/UI缩放下无关键信息遮挡；小图标与正文可辨识，悬停与键盘焦点显示功能说明。
- [ ] V1相关模型、真实界面、首次45天及发行版检查通过；修改共享组件时补跑受影响V0/历史场景回归。
- [ ] 新资产通过适用的QC和真实窗口审核；独立Windows包可运行，文档与包行为一致。

每小批运行与改动相关的检查；阶段收尾再执行`test.bat`、V1发行版冒烟和截图核对。历史demo/phase00场景使用各自独立入口，不重新混入V1体验流程。
