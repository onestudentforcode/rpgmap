# Phase 6.5 UI资产登记

> 2026-10-11，已接入并验收。原生SVG，64×64画布、透明背景、线性过滤；字体单独渲染，不强制像素风和二值alpha。

素材位于`assets/farming/ui/`，精确ID清单为[manifest.json](../../../assets/farming/ui/manifest.json)。用`python tools/farming/gen_ui_icons.py`确定性生成；`python -m unittest tools.farming.test_ui_assets -v`检查覆盖、规格、安全本地内容及工具区分，发行冒烟负责真实纹理解码。

| 用途 | 数量 | 复用位置 |
|---|---:|---|
| 农务与区域 | 10 | 查看/开垦/播种/收获/浇水/施肥/砍伐/清理/取消标记/负责区域 |
| 物品 | 18 | 市场、订单、投入/产出、三资源点 |
| 植物缩略图 | 4 | 地格详情与地图示意，部分图形与对应材料同源 |
| 设施 | 4 | 建设目录、加工详情、地图示意 |
| 五行 | 5 | 形状加文字，避免仅靠颜色 |
| 通用 | 17 | 导航、设置、日结、关闭、定位、交易、领取等 |
| 合计 | 58 | V1运行时与独立Windows包 |

主轮廓为深茶色，辅以浅茶绿、水蓝、谷金和柔陶色。工具以20单位图形放入36～40单位按钮；选中态、悬停、键盘焦点与禁用态统一。暖纸面板和少量“灵”字印章按[风格表](phase65-art-direction.md)实现，字体使用可缩放字形。

这批是UI符号与识别缩略图。地图借用符号展示尚未制作的世界对象，完整生长阶段图、斜俯视设施图和世界材质仍另批，不能将本登记视为正式场景美术交付。后续世界图继续检查机位、光照和无缝边缘。
