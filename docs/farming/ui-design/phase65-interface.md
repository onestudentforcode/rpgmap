# Phase 6.5 界面与交互设计稿

> 2026-10-11，首版设计。用户的六项回答及补充已纳入；代码与正式UI素材尚未实施。依据：[Phase 6.5任务](../phase-06.5-UI美化与交互完善.md)、[一页式美术指导](phase65-art-direction.md)。交互草图源：[lingtian-interface.html](lingtian-interface.html)。草图使用示意场景和临时数据，不读写游戏存档。

## 1. 已确认的设计决定

| 项目 | 决定 |
|---|---|
| 主分辨率 | 2560×1440；兼容1920×1080、1280×720，960×540使用紧凑布局 |
| 风格 | 柔和明亮，不再限制像素风，也不沿用旧墨绿深底；后续图片核对拼接、相机机位和光照 |
| 管理窗口 | 固定位置、一次一个；打开时阻断地图，关闭恢复目标和视野 |
| 目标详情 | 右侧可收起侧栏，仅显示选中地格/资源点/设施 |
| 连续操作 | 框选/放置后工具保持选中；右键返回查看；Esc先取消操作，再关闭最上层窗口，最后进入菜单 |
| 确认 | 清理、拆除、覆盖存档确认；批量清理每次框选确认一次；成熟收获/砍伐不反复弹确认 |
| 启动入口 | Phase 6.5收尾后，`play.bat`和F5默认进入新版，V0保留独立入口 |
| 操作按钮 | 紧凑简单图标代替大文字按钮，悬停显示对应功能；页签、数量、种子选择等信息控件保留文字 |

## 2. 主界面构图

地图占据主要空间；顶部为一条轻薄状态栏，右上放图标导航。目标详情按需出现在右侧，农务工具浮在底部。日报小面板在左下显示，避开工具栏和当前框选区域。

以下尺寸为2560×1440、UI缩放100%时的设计初值，独立于地图缩放；不再将640×360整张UI放大四倍。

| 区域 | 初值 | 内容 |
|---|---|---|
| 安全边距 | 24px | 窗口四边与浮层间距 |
| 顶部栏 | 56px高 | 日期/时节进度、AP、元石；行囊、市场、订单、雇工、建设、记录、手册、菜单 |
| 右侧详情 | 360px宽 | 对象名/状态、进度/环境、种植计划或生产投入、当前可用动作 |
| 农务工具 | 40px图标按钮，8px间距 | 默认收起；展开后显示查看与九种农务/区域工具，标记优先级单独紧凑输入 |
| 导航/行内动作 | 36px点击区，18～20px图标 | 主导航、收获、浇水、派工、收取、关闭、定位等 |
| 管理窗口 | 约1040×720px | 居中固定，不可拖动；内容过长时内部滚动，标题与关闭入口保持可见 |
| 正文/辅助/标题 | 18/16/22px | 首版字体尺度，设置提供100%/125%/150% UI缩放 |

1280×720缩小的是间距、窗口和侧栏宽度；正文不按屏幕比例无限缩小。960×540可收起侧栏、减少行内说明、改为单列内容。主分辨率与系统125%/150%缩放必须实机核对；地图相机缩放和UI缩放分别保存。

## 3. 图标与提示

- 导航、工具和当前动作采用图标；不使用大面积文字按钮。悬停约350ms显示“功能名 · 快捷键”，必要时追加AP、材料或操作方式。
- 查看图标显示指针，开垦显示锄具意象，播种显示种苗，收获显示穗/采收器，浇水显示水滴，施肥显示肥料袋，砍伐显示斧具，清理显示移除，取消标记与负责区域使用不同符号。草图暂用通用线形图标验证布局，正式图标另批制作。
- 同一动作的图标在工具栏、侧栏、列表中一致。已选工具有浅茶底、细焦点边线，底部状态条同时显示名称，便于学习。
- 键盘焦点也展示功能说明；图标按钮有可访问名称。禁用原因显示在相关投入/字段旁，悬停可重看。
- 金额、持有/所需、阶段、等待原因等关键信息直接可见；悬停用于解释功能，不能成为唯一的信息来源。
- “结束当天”用独立日落/月亮图标，与其他导航留明显间距；悬停说明日结与自动保存。点击一次完成原有日结流程。

建议快捷键：0查看，1～9对应开垦/播种/收获/浇水/施肥/砍伐/清理/取消标记/负责区域；M行囊交易、O订单、U雇工、B建设、J记录、F全图、R结束当天。WASD/方向键继续平移。输入数量/文本或打开管理窗口时，地图和农务快捷键暂停，Esc仍有效。

## 4. 四条高频操作流程

### 种植与收获

点击地格→侧栏显示空闲/生长/成熟→选择持续种植计划→核对完整占地与投入→点击手动动作图标，或选择农务工具框选待办。成长条、水分/肥力、固定光照及缺料/等待状态同屏。

成熟作物优先显示收获/砍伐；空闲耕地优先播种；无关动作折叠。清理使用单独的危险图标；弹窗写清对象、数量、不返还投入和是否保留种植计划。标记成功只显示“新增待办”，不得显示成已完成农事。资源点继续通过自身侧栏单独派工。

### 加工

点击设施→侧栏显示空闲/加工中/待收→空闲时打开该设施配方册→横向对照投入、产物、天数与启动AP→选择配方投料。投料后回到设施详情；显示剩余天数，完成后突出收取图标。缺料在投入行标出持有/需要，忙碌时不能再次投料或拆除。

建设从统一建设图标进入设施目录；选设施后关闭管理窗口，进入连续放置。鼠标位置显示完整占地预览与造价；不可放原因直接显示。合法点击调用原有建设校验，右键取消放置。

### 行囊与交易

行囊/市场打开同一管理窗口的不同页签→按种子/生产投入/食材查看→选物品→输入数量或1/5/10→同屏显示单价、总价、持有和余额→点击买/卖图标。材料不开放采购/出售时显示原因；余额不足/库存不足禁用提交，保持当前选物品与数量。

订单单独成窗口，卡片显示五行、rank、需求值、食材持有/必要数量和回款拆分。示例：木一转需求12，谷粒供养值4，必要3份；市价12元石，加整数溢价1，回款13。数量按必要值自动计算；已交付卡保留结算记录，无第二个交付按钮。

### 雇工与派工

打开雇工管理→选择人员→设置日预算/暂停/八类工作偏好→点击负责区域的添加图标→管理窗口关闭，进入地图框选→完成后保持区域工具，继续添加或右键退出。

人员卡显示最多2人、1元石/成功操作、12次/人/日的原有规则。工作偏好以0～5矩阵呈现；0明确写为禁止。区域列表逐条定位/删除，资源点指派在该点侧栏处理。工作完成与收费发生在日结，预览/改设置不提前扣工资。

## 5. 其他页面

- 开始页：居中标题与三个存档卡；日期、元石、保存时间可见。继续/新建/覆盖用图标与悬停说明，覆盖另确认；设置与退出为角落图标。
- 日摘要：保留前三条紧凑报告；分类图标配文字/数量。点击详情打开记录窗口。每15天的时节小结沿用条目形式，45天首次回顾自动打开宽账册。
- 回顾：总计与三个时节作为文字页签，收支表列出销售、订单、采购、建设、人工与净现金变化；库存另列。关闭后继续经营，统计冻结规则不变。
- 菜单/设置：设置包括全屏、窗口分辨率、帧率/FPS与UI缩放；音乐未启用，不增加音量占位操作。设置保存为全局偏好，不改变所属槽。
- 反馈：成功短提示显示资源/AP/元石变化；缺料/无效原因靠近操作处。日存档失败使用固定错误栏和重试图标，不被普通提示覆盖。

## 6. 实施与验证

P6.5.a先实现独立屏幕布局、图标按钮/提示、窗口阻断与Esc/右键、上下文详情、基础数量交易和显示设置。P6.5.b完成配方/建设预览、雇工矩阵、订单与报告面板。P6.5.c统一正式UI资产、过滤/缩放验收、发布包与默认入口切换。

界面设计与V1经济模型分离。新的预览必须只读，最终操作复用模型；末AP、日存档失败、取消和重复提交继续保留既有保护。检查主分辨率与UI缩放、菜单输入穿透、框选坐标、危险操作确认频率、数量交易边界和各窗口关闭后的恢复。

本批只完成设计文档、色板及可交互草图，尚未宣称Godot界面或新的非像素素材已完成。草图的地图是程序绘制的场景示意，不作为正式贴图验收图。

设计资料检查：草图脚本语法、静态控件名称/ID、文档本地链接与差异格式通过；色板11组文字对比度最低4.82:1，三组明度坡道均递增。该检查不替代后续Godot实机截图和游戏回归。
