# Phase 6.5 一页式美术指导

> 2026-10-11。方向由用户确认的“柔和明亮、无需像素风、图标按钮、适量东方玄幻元素”展开。已接入V1独立主题与58个SVG，完成本轮运行时验收；世界场景图仍另批。色值来源：[UI设计色板](phase65-ui-palette.json)；布局见[界面设计稿](phase65-interface.md)。

**方向词：暖米白、浅茶绿、柔陶色；清爽、松弛、轻巧。** 大面积明亮实底与深色文字保证阅读，东方意象用在标题、器物轮廓和少量纹样。图标优先简洁线形，正文使用清晰的现代中文字体。

明度坡道：茶绿 `#37533f → #5b7b60 → #8caa88 → #c1d4b6 → #e7efdf`；暖纸与陶色坡道见色板。灰度下各阶须递增。正文和辅助文字对实际背景对比度≥4.5:1；图标/状态不能只靠颜色表达。UI色板与世界贴图色板分别管理。

**参考拆解：** 用户指定的明亮柔和色调用于面板与按钮；东方玄幻通过青釉、木器、灵植叶形与克制纹样表达；时节报告保留用户指定的条目式结构。完整场景美术另批制作，草图中的地图仅示意布局，不作为正式纹理或相机模板。

**后续图片规范：** 不再强制像素风、二值alpha或NEAREST降为64px；新非像素资源允许渐变、抗锯齿与平滑透明边缘。逻辑地格仍为64单位。正式图片先用母版验证尺寸、缩放与过滤，再制定对应QC；现有V0素材继续使用其历史校验。

- 地面使用正交俯视的可平铺纹理，无透视收缩、整图明暗渐变或方向性边缘阴影；检查原尺寸、3×3平铺及实际相机缩放下的边界。砖缝/垄沟与地格周期相容。
- 立体作物和设施使用统一的正交斜俯视模板、左上主光；既有45°描述作为母版校准初值，先同屏核对后冻结新模板。禁止在同一批混用等距菱形、透视镜头和不同光向。
- 同一物种阶段保持轮廓、机位、光照和底部锚点连续；透明边缘无白边/黑边。独立精灵不自带一块地面，地面接触表现由场景统一处理。
- UI导航/工具图标使用统一线宽与圆角，小尺寸单色仍可识别；物品缩略图与场景资产可共享母版，不能混用不同机位的参考。

**禁止事项：** 全屏泛白光晕、低对比正文、过度透明面板、厚金边、密集符咒文字、大面积发光、装饰挤占操作空间；不将旧像素负面提示词直接用于新非像素资产。
