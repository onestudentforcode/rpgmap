## 1. 系统定位

### 1.1 设计目标

后勤蛊虫系统是生产经营模块的重要组成部分，主要负责为玩家提供特殊的资源生产与生产辅助能力。

经营模块有两个主要经济目标：

1. 通过生产和交易获取货币（元石）。
2. 生产战斗蛊虫喂养、炼制和成长所需的各类资源。

玩家可以通过传统建筑、种植、养殖以及后勤蛊虫建立自己的生产体系，并通过组合不同生产方式来优化基地的资源利用效率。

### 1.2 核心设计原则

**原则一：允许功能重叠，但避免完全同质化。**

后勤蛊虫可以与普通建筑、作物或养殖动物生产相同的资源，但应在生产成本、环境要求、生产周期、副产物等方面具有区别。

**原则二：蛊虫可以改变生产规则。**

后勤蛊虫的价值不仅是提高生产效率，还包括改变生产配方、替换原材料、创造特殊环境、解锁新的生产路线。

**原则三：鼓励不同生产方式之间的协同。**

普通设施可以受到后勤蛊虫影响，独立部署的后勤蛊虫也可以受到其他后勤蛊虫影响。

**原则四：维持轻松经营体验。**

大部分后勤蛊虫不需要独立的手动喂养流程。资源转化过程中的物资损耗视为其正常食料消耗，并通过周期性元石消耗建立运营成本。

2026-10-20补充确认：0、1经济阶段主要积累以解锁下一级，2、3阶段形成规模后开始快速增长；平均约两次普通扩建后，再利用扩建后的产能经营4～6轮满足跨级建设。赚钱路线与低售价但有用途的关键材料路线允许分工，以特色资源交换支持产业专精；非冲突的既有房间和蛊效果本阶段不改。阶段事件可开放蛊获取资格，不代表本模块接管上游捕捉、炼制或升转系统。

**原则五：控制初期系统复杂度。**

第一阶段只实现直接的生产增益和环境协同，不引入递归增强、多层效果传播或复杂的食物培养机制。

### 1.3 与上游系统的关系

后勤蛊虫与战斗蛊虫是两种严格分离的类型。

- 战斗蛊虫消耗经营系统生产的资源，不参与经营生产。
- 后勤蛊虫可以生产资源、修改生产条件或提供生产辅助。
- 两类蛊虫不进行战斗与经营能力的交叉复用。

蛊虫购买、捕捉、炼制、转数提升等功能由上游系统负责。

本模块只需要读取可派遣的后勤蛊虫实例，并管理其部署状态、生产效果与经营成本。

当前蛊虫转数支持一转至五转，为未来六至九转预留数据扩展空间。

## 2. 生产体系架构

### 2.1 生产对象分类

| 对象 | 核心职责 | 是否必须依赖后勤蛊 |
|---|---|---|
| 资源点 | 提供基础资源入口 | 否 |
| 普通建筑 | 生产、加工和存储资源 | 否 |
| 作物 | 将环境条件和投入材料转化为农产品 | 否 |
| 养殖动物 | 将饲料等投入转化为养殖产物 | 否 |
| 蛊虫专用设施 | 承载特定后勤蛊虫的特殊能力 | 是 |
| 独立生产蛊 | 自身完成资源生产和转化 | 不适用 |

普通生产设施和蛊虫专用设施可以共存。

例如：

- 普通水井能够独立产水。
- 入驻水道蛊的水井可能获得更高的产量。
- 凝露台需要对应的后勤蛊虫入驻才能产水。
- 特殊的独立生产蛊可以直接部署在地图上，完成自己的生产过程。

允许不同生产方式最终产出相同资源。

### 2.2 统一生产实体

从生产计算角度，建议将建筑、作物、养殖动物和独立生产蛊统一抽象为生产实体。

生产实体可以具有以下属性：

| 属性 | 说明 |
|---|---|
| 生产配方 | 原材料、产物、副产物 |
| 生产周期 | 完成一次生产需要的时间 |
| 运行条件 | 光照、水分、温度等要求 |
| 生产标签 | 标识生产活动的类别 |
| 部署条件 | 地图地块、设施、环境约束 |
| 生产修饰 | 接收外部效果后的属性变化 |
| 运行状态 | 待机、运行、暂停等 |

共享生产逻辑不意味着共享全部游戏机制。

例如，普通作物拥有播种和收获规则，独立生产蛊拥有蛊虫实例和元石维持成本，但两者可以复用资源投入、环境判定和生产结算逻辑。

### 2.3 生产执行的基本过程

一次生产任务按以下流程执行：

1. 选择生产实体与生产配方。
2. 检查部署状态与必要的环境条件。
3. 获取入驻蛊虫及范围效果。
4. 计算当前生产速度、材料需求和其他修饰参数。
5. 检查并提交必要的生产投入。
6. 运行生产任务。
7. 任务完成后发放产物和副产物。

**建议：** v0.1 采用生产任务为单位的结算机制，不要求每个游戏渲染帧重新计算生产参数。

对光照等持续环境条件，则允许在环境变化时更新运行状态。环境条件不足时，可以暂停生产，恢复条件后继续。

## 3. 后勤蛊虫部署系统

### 3.1 部署方式

后勤蛊虫支持两种部署形态。

#### A. 设施入驻

将后勤蛊虫派遣到指定设施的蛊虫槽位中。

例如：

- 智道蛊入驻研究站。
- 宙道蛊入驻研究站。
- 光照蛊入驻照明设施。
- 炼火类蛊虫入驻熔炉。

设施可在没有蛊虫时继续工作，也可以根据设施规则要求必须入驻对应蛊虫才能运行。

#### B. 独立部署

后勤蛊虫可以直接部署在地图上，类似一个特殊的生产建筑。

例如饭袋草蛊：

- 直接占用地图地块。
- 不需要配套农田。
- 根据光照和水分条件生产稻米。
- 按周期消耗元石。

独立部署蛊虫可以拥有生产功能，也可以提供范围效果。

### 3.2 设施与蛊虫的兼容规则

采用：

**设施类型 + 蛊虫能力标签**

共同决定能否入驻。

设施定义自己允许的能力类别，蛊虫定义自身拥有的能力标签。

以研究站为例：

研究站：

- 设施类型：research_facility
- 支持槽位：research_assist
- 初期槽位数量：1（建议）

智道研究蛊：

- 能力标签：research_assist、research_time_flat

宙道研究蛊：

- 能力标签：research_assist、research_speed_multiplier

两种蛊虫都满足研究站的入驻要求，但提供的具体效果不同。

蛊虫所属流派可以用于玩法描述、筛选和配方设计，不应直接作为所有设施兼容性的唯一判断依据。

特殊设施可以进一步设置额外限制，例如指定蛊虫种类或最低转数。

### 3.3 蛊虫部署状态

建议后勤蛊虫至少具有以下状态：

| 状态 | 说明 |
|---|---|
| 未部署 | 位于库存，不提供生产效果 |
| 已部署·启用 | 正常运行并产生效果 |
| 已部署·休眠 | 保留部署位置，但停止生产和效果 |
| 运行受阻 | 已启用，但不满足环境、食料等条件 |

具体建议：

- 同一只蛊虫实例只能部署在一个位置。
- 同种蛊虫的不同实例可以同时部署。
- 运行中的生产任务不允许直接更换其入驻蛊虫；需要先完成或停止任务。
- 元石不足时，蛊虫可以自动进入休眠，不产生负数欠款。
- 休眠状态是否免除元石消耗，暂按免除设计，待经济测试确认。

## 4. 后勤蛊虫能力体系

### 4.1 能力分类

v0.1 将后勤蛊虫的能力初步分为六类。

| 能力分类 | 功能 | 示例 |
|---|---|---|
| 资源生产 | 直接生产资源 | 饭袋草蛊生产稻米 |
| 资源转化 | 改变资源之间的转化关系 | 水转化为特殊液体 |
| 效率修饰 | 改变时间、速度或生产效率 | 研究时间 -1、研究速度 ×2 |
| 配方控制 | 解锁、替换或修改生产配方 | 特殊炼制、替代原料 |
| 环境影响 | 改变地图环境条件 | 提供光照、调节温度 |
| 范围增益 | 为范围内符合条件的对象提供增益 | 加快附近作物生长 |

这些分类描述的是能力，不是互斥的蛊虫职业。

一只蛊虫可以拥有多项能力，但 v0.1 的原型蛊虫应尽量只突出一项核心功能。

### 4.2 效果作用目标

每项效果应当独立定义目标条件。

例如：

- biological_production：生物性生产，包括作物和符合条件的生产蛊。
- research_facility：研究设施。
- processing_facility：加工设施。
- water_production：产水类生产实体。
- logistics_gu：后勤蛊虫实体。

目标标签与蛊虫能力标签分开维护。

例如某种催生效果可以作用于 biological_production，而不需要分别列出所有作物及蛊虫名称。

### 4.3 效果范围

能力可以采用以下范围：

- SELF：作用于蛊虫自身。
- HOST：作用于当前入驻设施。
- AREA：作用于地图上的指定范围。

第一版建议采用基于逻辑网格的范围判断。

范围可以按格子距离计算，暂不加入墙体遮挡、高度差、效果传播路径等复杂机制。

不同转数的蛊虫允许拥有不同的范围参数。

## 5. 蛊虫协同系统

### 5.1 设计目标

后勤蛊虫可以同时接受来自环境、其他蛊虫和设施的影响。

例如：

明光蛊提供光照。

饭袋草蛊在光照范围内满足生产条件。

催生蛊进一步提高饭袋草蛊的生产速度。

这种关系不要求蛊虫之间建立固定组合配方，只需根据环境、范围和标签进行自动匹配。

### 5.2 第一阶段的协同规则

采用以下规则：

1. 不同类型的效果允许同时生效。
2. 相同类型的范围增益默认取有效效果中的最大值，不累加。
3. 环境型能力可以影响普通作物及独立生产蛊。
4. 范围增益可以影响符合标签条件的后勤蛊虫。
5. 增益效果自身默认不能受到其他增益效果的增强。
6. 不允许效果通过目标继续传播，避免递归计算。

例如：

两个催生蛊分别提供 20% 和 30% 的生产速度增益。

同一生产实体位于两者范围内时，只获得 30% 的对应增益。

但如果它还受到光照蛊提供的光照，该环境效果可以同时生效。

### 5.3 环境型与增益型的区别

必须区分两类作用方式。

**环境型效果：**

首先修改地图环境属性，再由生产实体判断自己是否满足条件。

例如明光蛊提高地块的光照水平，饭袋草蛊通过环境条件获得正常生产资格。

**生产增益型效果：**

直接修改目标生产实体的属性。

例如催生蛊使符合条件的目标生产速度 ×1.2。

在 v0.1 中，多个光源可以先采用最大光照值规则，避免复杂的环境叠加。

### 5.4 不实现的高级机制

本阶段暂不实现：

- 多层效果传播。
- 增益蛊之间的相互强化。
- 同类效果的复杂递减叠加。
- 基于蛊虫组合产生全新技能。
- 自动识别最优生产组合。
- 复杂的蛊虫羁绊和阵法系统。

这些内容保留为后续扩展方向。

## 6. 后勤蛊虫的经济与喂养

### 6.1 三种成本

蛊虫成本分为三个独立部分。

| 成本类别 | 规则 | 适用范围 |
|---|---|---|
| 生产消耗 | 根据生产配方消耗原材料 | 参与资源转化的蛊虫 |
| 元石维持 | 按游戏内周期结算元石 | 常规后勤蛊虫 |
| 特殊食料 | 消耗指定食物维持运行或使用能力 | 少数特殊蛊虫 |

### 6.2 普通生产蛊

大部分后勤蛊虫不设置额外的常规喂养流程。

生产过程中资源转化所消耗的原材料及损耗，在世界观中视为其食物需求。

例如：

饭袋草蛊需要光照与水分来生产稻米，不额外要求玩家提供一份普通食料。

但它仍然需要周期性消耗元石。

必须避免生产配方已经计入资源损耗后，再从库存重复扣除相同食料。

### 6.3 元石维护

建议 v0.1 使用固定游戏周期结算。

每只后勤蛊虫可以拥有独立的维持费用。

例如：

- 一转饭袋草蛊：2 元石 / 游戏日。
- 一转明光蛊：3 元石 / 游戏日。

以上仅为测试值。

具体维持费用不必严格按照转数统一计算。同一转数的不同蛊虫可以拥有不同的运营成本。

### 6.4 特殊食料

少数蛊虫需要特定食物。

例如宙道研究蛊：

- 提供研究速度倍率。
- 按周期消耗元石。
- 需要特定的宙道食料。

v0.1 只需要实现特殊食料的基础消耗与运行条件。

未来可以扩展：

- 不同品质的特殊食料。
- 临时强化生产效果。
- 改变生产配方或产物。
- 特殊食料与蛊虫成长的关联。

本阶段不设计完整的特殊喂养养成系统。

## 7. 首批后勤蛊虫原型

首批原型以验证机制为目的，暂不制作完整的一转至五转图鉴。

### 7.1 饭袋草蛊

**类型：** 独立生产型  
**核心机制：** 替代性生产路线  
**部署方式：** 直接部署于地图

生产规则：

- 需要光照。
- 需要水分。
- 不需要肥料。
- 产出稻米。
- 不产出秸秆。
- 周期性消耗元石。

对照对象：金穗麦。

金穗麦需要水分、光照和肥料，可以获得粮食及秸秆。

饭袋草蛊省去了肥料投入，但减少了副产物，并增加元石维持成本。

**验证目标：** 玩家是否能根据肥料、元石和副产物需求，在两条生产路线之间进行选择。

### 7.2 明光蛊（暂定名）

**类型：** 环境影响型  
**核心机制：** 区域光照  
**部署方式：** 入驻照明设施

生产规则：

- 以照明设施为中心提供光照范围。
- 范围内生产实体可以读取该光照值。
- 不直接产出资源。
- 周期性消耗元石。

不同蛊虫可以拥有不同的光照强度与范围。

第一版不实现遮挡、传播衰减或复杂照明模拟。

**验证目标：** 环境蛊能否同时服务传统农业与独立生产蛊。

### 7.3 催生蛊（暂定名）

**类型：** 范围增益型  
**核心机制：** 生物性生产加速  
**部署方式：** 入驻指定辅助设施

生产规则：

- 对范围内 biological_production 类型目标生效。
- 提高符合条件的生产实体的生产速度。
- 可以同时影响普通作物和饭袋草蛊。
- 不增强其他增益型蛊虫的效果。
- 周期性消耗元石。

测试参数：生产速度 ×1.2。

**验证目标：** 玩家是否愿意围绕范围型蛊虫重新规划种植和生产布局。

### 7.4 智道研究蛊（暂定名）

**类型：** 设施入驻型  
**核心机制：** 固定研究时间减免  
**部署方式：** 入驻研究站

效果：

- 每次研究固定减少 1 个时间单位。
- 不改变基础研究材料消耗。
- 周期性消耗元石。

建议设置研究所需时间下限，防止短周期研究被直接缩减至零。

**验证目标：** 固定时间收益是否能形成区别于倍率加速的用途。

### 7.5 宙道研究蛊（暂定名）

**类型：** 设施入驻型  
**核心机制：** 研究速度倍率  
**部署方式：** 入驻研究站

效果：

- 研究速度提升至基础速度的 200%。
- 增加一定比例的研究材料消耗。
- 周期性消耗元石。
- 需要特殊食料。

测试参数：

基础研究时间为 12，材料需求为 10。

入驻后：

- 研究时间约为 6。
- 材料需求提高至 15。
- 额外承担元石和特殊食料成本。

其中 200% 表示最终速度为基础速度的 2 倍，而不是额外增加 200%。

**验证目标：** 高速度、高成本的方案能否与低成本、固定时间缩减的方案形成区别。

### 7.6 凝露蛊（备选原型）

**类型：** 设施入驻型  
**核心机制：** 专用设施驱动  
**部署方式：** 入驻凝露台

效果：

- 凝露台没有对应蛊虫时不能生产。
- 凝露蛊入驻后，提供产水配方。
- 与普通水井形成不同的产水路线。

这一原型主要用于验证「蛊虫专用设施」机制，可以安排在其他核心功能完成后实现。

---

## 8. 研究站完整案例

研究站是验证入驻系统的重要设施。

### 8.1 基础规则

研究站可以独立进行研究。

v0.1 建议只提供一个蛊虫槽位。

因此玩家必须在不同的辅助蛊虫之间选择，不能同时使用两种入驻效果。

### 8.2 研究方案对比

| 方案 | 研究时间 | 研究材料 | 额外成本 |
|---|---:|---:|---|
| 无蛊虫 | 12 | 10 | 无 |
| 智道研究蛊 | 11 | 10 | 元石 |
| 宙道研究蛊 | 6 | 15 | 元石、特殊食料 |

智道研究蛊更适合降低基础成本较低、耗时较短的研究任务的时间需求。

宙道研究蛊能够显著缩短长周期研究，但会产生额外的资源开支。

### 8.3 时间计算建议

生产任务需要区分：

- 基础工作量。
- 固定工作量减免。
- 工作速度倍率。

可以采用以下简化规则：

**预计完成时间 = max(最小工作量, 基础工作量 - 固定减免) / 工作速度倍率**

若内部使用离散 Tick，则按游戏规定对时间取整。

材料消耗倍率独立计算，不与速度倍率自动绑定。

例如宙道蛊将速度提高至 2 倍，并不天然导致总材料消耗增加。额外材料消耗必须由该蛊虫的能力效果单独定义。

### 8.4 运行时约束

v0.1 建议：

- 研究开始时锁定入驻蛊虫和研究方案。
- 研究中不允许直接更换该蛊虫。
- 元石或必要食料不足导致蛊虫停用时，依赖该蛊虫的研究任务暂停。
- 重新满足运行条件后恢复研究。

这样可以避免研究过程中反复更换蛊虫造成时间、材料消耗结算异常。

## 9. 交互与可视化需求

### 9.1 蛊虫部署

玩家从可用后勤蛊虫列表中选择蛊虫。

根据蛊虫部署类型：

- 设施入驻型：高亮可以入驻的建筑。
- 独立部署型：显示地图可部署地块。

部署前应显示：

- 蛊虫名称与转数。
- 核心能力。
- 作用目标与范围。
- 当前维持费用。
- 特殊食料需求。
- 不满足部署条件的原因。

### 9.2 设施信息面板

设施信息需要显示：

- 当前生产任务。
- 基础生产参数。
- 蛊虫修饰后的生产参数。
- 当前入驻蛊虫。
- 生效的范围增益。
- 当前实际资源消耗。
- 运行状态与受阻原因。

例如研究站：

基础研究时间：12  
智道蛊修饰：-1  
最终研究时间：11

或者：

基础研究时间：12  
宙道蛊修饰：速度 ×2  
最终研究时间：6  
材料消耗：×1.5

### 9.3 范围可视化

选中范围型蛊虫后，显示其影响范围，并区分：

- 可以受到影响的生产实体。
- 已经受到影响的生产实体。
- 处于范围内但标签不匹配的实体。

v0.1 只需要简单的地图格子高亮，不要求复杂的视觉特效。

### 9.4 经营成本提示

建议在蛊虫管理界面展示：

- 已部署后勤蛊虫数量。
- 当前周期元石维护总额。
- 休眠蛊虫数量。
- 需要特殊食料的蛊虫数量。

减少玩家逐只检查成本的操作负担。

## 10. v0.1 开发范围与验收

### 10.1 P0：必须完成

**生产系统**

- 支持生产配方的资源投入和产出。
- 支持环境条件检查。
- 支持生产速度修饰。
- 支持固定工作量减免。
- 支持材料消耗修饰。

**蛊虫部署**

- 支持设施入驻。
- 支持地图独立部署。
- 支持能力标签兼容检查。
- 同种不同实例可以分别部署。
- 同一实例不能重复部署。

**经济成本**

- 支持周期性元石结算。
- 支持蛊虫运行和休眠状态。
- 支持特殊食料的基础消耗接口。

**协同效果**

- 支持光照环境范围。
- 支持生产增益范围。
- 支持普通作物与蛊虫接收相同类型增益。
- 同类范围增益不累加。
- 不存在递归增强。

### 10.2 P1：核心完成后验证

- 凝露台及凝露蛊。
- 特殊配方解锁。
- 多种生产成本对比。
- 高转蛊虫的不同效果参数。
- 更详细的生产收益统计。

### 10.3 暂不实现

- 后勤蛊虫繁殖。
- 完整一至五转后勤蛊图鉴。
- 复杂特殊食物培养。
- 蛊虫技能相互增强。
- 复杂的效果传播网络。
- 战斗蛊虫参与生产。
- 自动生产布局优化。

### 10.4 验收场景

**场景 A：传统农业与蛊虫替代**

玩家分别使用金穗麦与饭袋草蛊生产粮食。

两条路线的肥料需求、副产物和元石成本必须能够正确结算。

**场景 B：环境协同**

玩家部署饭袋草蛊，在光照条件不足时无法正常生产。

在附近照明设施入驻明光蛊后，饭袋草蛊满足光照条件并开始生产。

**场景 C：范围增益**

玩家在饭袋草蛊与普通作物附近部署催生蛊。

两个生产实体均获得符合规则的生产速度增益。

**场景 D：研究站入驻**

研究站分别入驻智道研究蛊与宙道研究蛊。

两种配置产生不同的时间、材料和运营成本。

**场景 E：效果叠加**

两个催生蛊覆盖同一生产实体。

系统只应用更强的同类效果，不发生重复乘算。

**场景 F：资源不足**

玩家元石余额不足，相关后勤蛊进入休眠。

蛊虫不再提供生产或范围效果，不产生负数元石。

**场景 G：实例唯一性**

玩家拥有两只相同的一转后勤蛊。

可以将它们分别部署在两个位置，但不能将同一个实例部署两次。

## 11. 平衡性验证

第一阶段重点不在于精确平衡所有蛊虫，而是验证不同生产路线是否具有真实的选择价值。

建议重点观察：

| 维度 | 需要回答的问题 |
|---|---|
| 单位时间产量 | 后勤蛊是否普遍碾压普通生产 |
| 单位面积产量 | 玩家是否有理由使用蛊虫节省土地 |
| 元石净收益 | 扣除维护后，生产蛊是否仍有合理收益 |
| 材料投入 | 特殊生产路线是否真正改变资源需求 |
| 副产物价值 | 普通种植和养殖是否保留不可忽略的优势 |
| 布局价值 | 范围型蛊虫是否值得玩家围绕其布局 |
| 蛊虫重复部署 | 大量同种蛊虫是否产生明显的最优策略垄断 |

对于存在多种生产方式的同一资源，至少应在不同的资源环境下，各有一条具有实际价值的生产路线。

不要求所有生产方式在任意条件下收益相等。

## 13. 当前仍需验证的设计问题

以下内容不影响 v0.1 开始开发，但需要在原型测试后确定：

1. 后勤蛊虫的元石维持费用如何随转数与能力变化。
2. 不同来源的光照、水分等环境效果采用何种叠加规则。
3. 范围效果是否允许在独立部署蛊之间相互覆盖并动态变化。
4. 后勤蛊虫休眠与恢复时，尚未完成的生产任务如何处理。
5. 普通作物、养殖动物和独立生产蛊应当共享哪些生产接口。
6. 是否有必要为高转蛊虫引入更多槽位或特殊入驻规则。

这些问题优先通过实际原型与经济数据决定，不在第一版过早固定。

## 14. 第一版设计结论

后勤蛊虫系统的核心价值不是建立一套比普通建筑更高级的生产建筑系统，而是让玩家通过蛊虫能力改变生产方式。

建筑提供设施条件。

作物与养殖动物提供常规资源循环。

后勤蛊虫提供替代路线、特殊生产、环境改变和效率修饰。

玩家最终需要根据自己的资源储备、生产目标、土地空间、元石成本和已有蛊虫，选择适合自己的生产组合。

**v0.1 的核心验收标准：玩家是否能利用后勤蛊虫创造不同于传统经营的有效生产方案，并且普通生产体系仍具有独立存在的价值。**
