## 设计方向

动物通过可开关的地图视野叠层显示，每个地格最多提供四个显示槽位，放入对应个体的美术缩略图。四分区替代此前“物种头像＋数量”的首选展示方案。

```text
          .-------------------.
       .-'    A     |    B     '-.
      (------------+-------------)
       '-.    C     |    ·     .-'
          '-------------------'

       A、B、C：不同动物个体；·：空位
```

- 底盘适应既有35°机位，可用扁椭圆或其他清楚的四分区形状，具体外形未冻结。动物缩略图保持原比例；成体/幼体使用各自已选素材。
- 四槽是显示布局，不据此修改动物空间权重、区域承载、床位或每格逻辑容量。实际数据能否严格满足四槽、溢出如何处理，在P10.10实施前核对，不能隐藏多余个体。
- 视野关闭时隐藏底盘和动物小图，开启时叠加在正常地图上。未来计划设置类似F1～F12的视野控件，本次仅确认视野可开关；完整控件体系、各键用途和默认开关状态尚未确定，也不在当前P10.9实现。
- 动物无需新增移动、寻路、工作/休息行为动画；现有工作、排班、疲劳、成长、繁育与生产结算保留，用详情和状态标记表达。

## 地格到详情的交互

点击地格，显示多个可选择内容，再点击对应条目查看详情。列表复用既有右侧信息区域，呈现作物、设施、动物及区域入口；区分“本格内容”和“所属区域”，避免把区域名册误当作当前地格真实站位。

```text
点击地格 → 内容列表 → 点击动物条目 → 对应个体详情
             ├ 作物
             ├ 设施
             └ 动物 A / B / C / D
```

直接点击四分区小图进入个体详情、悬停高亮、显示槽位稳定保留，是后续交互建议，待P10.10样板验证。耕地、种植、建设等工具继续执行原操作；查看内容的入口不能抢占这些工具的输入。

普通动物目前没有统一逐格实时位置，后续需定义区域内稳定的展示格；已有固定anchor的物种沿用真实锚点，蜂群/菌毯关联所属设施。展示分配不写成新的实际移动或占地规则，不提前应用次日调度。

### 产物

- `tools/farming/export_p1010_animals.py`：从P10.9源图（animals/aquatic/living三类）alpha裁切→96px画布底边居中（anchor_uv [0.5, 92/96]），导出17物种×成体/幼体共34张运行时缩略图 + `assets/farming/p109/runtime/animal_manifest.json`。
- `scripts/farming/p8/p10_animal_view.gd`：核心模块。`display_slots(world)` 确定性槽位分配——固定物种占真实anchor格（缺anchor回退区域首格）；游走物种按uid排序填入区域展示格（`_zone_display_cells` 优先非设施格），每格≤4只，溢出并回末格并以"+N"角标表达，不隐藏个体。`draw_overlay` 绘制20点扁椭圆底盘（Color(0.16,0.20,0.16,0.30)）+四分区偏移（±11/-6/+5 ×readable）+17px等比缩略图；`animals_at/zone_at/show_detail` 支撑地格内容交互。
- `scripts/farming/p8/p87_scene.gd`：`draw_map` 尾部调用 `animal_view.draw_overlay`（绘制于既有地图内容之上）。
- `scripts/farming/p8/p8_scene.gd`：设置面板动物视野开关 + `--animals=off` CLI旗标；`_show_cell` 侧栏新增"本格动物（展示槽位）"条目（点击开个体详情）与"所属区域（畜牧名册）"入口，复用既有信息区，不抢占工具输入（工具路径守卫先期已由c331b5a修复固化）。

### 决策

- 展示槽位是纯显示布局：不改动空间权重、区域承载、床位或逻辑容量；分配算法稳定（同状态同结果），读档后按uid重排一致。
- 缩略图与详情共用同一张96px图，不引入第二套详情立绘；成体/幼体取各自阶段素材。
- 底盘为扁椭圆贴合35°机位；具体外形沿设计"未冻结"口径，样板验证后再议。

### 验收
