# Phase 6 — Demo体验与三槽存档

> 状态：**草案已展开，待实现**（2026-10-09）。
> 依据：[master-plan](master-plan.md)、[Phase 5](phase-05-喂养与经济闭环.md)及用户本轮答复。
> 定位：主要供自己测试，但按无开发者指导也能进入、操作、保存并回顾的标准验收。

## 1. 阶段目标与范围

将现有种植MVP整理成可独立体验的“灵田 Demo”。玩家通过开始菜单选择存档，完成可跳过的新手教学，自由经营前三个时节（45天）。第45天结束后显示经营回顾，无胜负条件。回顾关闭后继续经营，本阶段不生成第二份周期回顾。

### 用户已确认

- 俯视点击，不引入人物或寻路。
- 初始60元石；偏轻松经营，农业是主要经济来源。
- 四种现有作物与木属性规格保持；不扩容，不限制背包容量。
- 开始菜单与新手引导均实现。
- 普通/高级锄头、播种工具、采收工具；高级档必须购买，同类共用一个栏位，可自由切换已拥有档位。
- 高级工具以鼠标所在格为中心，操作3×3；成功操作的行动点成本减半，向上取整。
- 仅每日结束自动存档，不允许手动存档；三个独立槽，存档只能覆盖当前所属槽。
- 新游戏覆盖占用槽需确认；提供删除存档功能。
- 退出/返回主菜单时提供“结束当天并保存 / 放弃当天进度 / 取消”。
- 首次45天统计种植作物、收获次数和产量、出售收入、种子/材料/工具支出、净收入、期末余额及喂养材料消耗。
- 一张农场地图，暂不设市场摊位；继续通过面板交易。
- 美术新增及音乐暂缓；蛊虫主动能力另行设计，本阶段只保留现有喂养与扣减接口。

### 本轮不做

新作物、其他五行内容、养殖、NPC、战斗、蛊虫农事能力、动态市场、背包容量、昼夜美术、新音轨或音效、实际改写上游仓库。原有场景美术优化、内容扩容和大地图专项优化从本轮Phase6范围移出，后续另行立项。

## 2. 游戏入口与新手体验

### 6.a 开始菜单与场景流程

开始菜单：新游戏、继续游戏、设置、退出。游戏内菜单：设置、返回主菜单、退出。

- 新游戏/继续均先选择槽1～3。卡片显示空槽或日期、元石、最近保存时间；损坏档显示明确错误，不静默覆盖。
- 新游戏选择占用槽：明确显示被覆盖的槽与进度，确认后才创建。删除亦需确认，操作限所选槽。
- 新档初始化时建立所属槽的第1天基线；这是创建存档，不是可操作的手动存档按钮。
- 后续自动保存不提供“另存为”或槽位切换。切换存档必须返回菜单。
- 标题显示“灵田 Demo”。保留原应用内部标识以免改变现有user://目录；不因标题变化丢失旧档。
- 默认入口切换到开始菜单；自动化农场测试和历史demo/farm0仍保持独立显式入口。

### 6.b 可跳过的新手教学

按实际成功操作推进：选择工具→开垦→播种→休息与生长→采收→出售/买种→饥饿时喂养。无需固定经营目标；未达到喂养条件时允许继续经营，不强迫重复休息。

- 可跳过、可从帮助中重看；不会替玩家扣资源或赠送重复奖励。
- 教学状态属于存档，随每日快照保存。读档恢复相应步骤。
- 明确说明AP归零自动过日、每日饱食度下降、保存时机，以及高级工具购入后才开放批量功能。
- 鼠标可完成主要流程，现有工具、休息、面板快捷键保留；F5/F9手动存读入口及按钮移除。

## 3. 高级工具与批量操作

### 6.c 工具数据与购买

| 类别 | 普通档 | 高级档 | 价格初值（可调提案） |
|---|---|---|---:|
| 锄头 | 单目标开垦/清理，保留现有恢复土地方式 | 范围开垦/清理 | 30元石 |
| 播种 | 单株播种 | 范围播种当前选定作物 | 40元石 |
| 采收 | 点击成熟作物采收 | 范围采收 | 40元石 |

价格尚非用户冻结数值，实施时配置管理并按轻松种田试玩评估；不增加新美术即可用文字等级表示。普通档免费拥有，高级档一次购买永久解锁，不消耗耐久，不占普通物品库存；不可重复购买或回售。

同种工具共用栏位，可在普通/高级间切换；播种工具另选择四种种子，不为每级复制四个工具栏位。普通档不开放拖动/框选批量捷径，以保留高级工具的购买价值。

### 范围与结算契约

- 中心格为鼠标所在格，九格偏移为(-1,-1)到(1,1)；显示范围预览与可操作/不可操作区别。地图边缘截取有效格。
- 批量播种的目标是范围内的种植锚点，按上到下、左到右处理；大型作物仍校验完整footprint与介质，后续重叠位置跳过。
- 批量采收/清理按作物实例去重；范围触及大型作物任意占地格即能命中，一株只计一次成功操作、产量和统计。
- 高级锄头范围操作只开垦荒地、清理枯竭植株；不批量恢复已有耕地，以防误清介质。恢复土地继续使用普通档。
- 无效目标跳过，不扣资源；没有任何成功操作时行动点为0。
- 高级行动点：`ceil(成功操作原始AP成本总和 / 2)`，对整批合计取整，不逐格取整。当前原价均为1：成功1/2/3/9次分别扣1/1/2/5点。
- 资源不足时按固定顺序执行可负担的目标，剩余停止并反馈完成/跳过数量；每株种子照常扣1份，介质成本保持Phase5规则。
- AP不足时不跨天续做同一批：先计算本日可负担数量，完成这一批后统一扣AP，若归零才进入次日。
- 单次点击最多结算一批；双击、长按或事件重复不能让同一作物重复收获，也不能重复购买工具。

## 4. 三槽自动存档

### 6.d 存档结构与提交时机

钱包、库存、土地、作物、时钟、蛊虫、工具拥有/选择、教学状态、首轮统计和回顾状态同属一个槽。槽ID由加载会话绑定，不从UI临时选择项推导。

- 每日结束的最终状态写入当前槽，保存时间点是生长/饱食度推进及导致过日的完整操作结算之后。
- **特别处理AP耗尽自动过日**：当前代码可能在采收前扣AP并发出day_changed。不得在该信号中立即保存半结算状态；需要统一操作事务边界，或延迟保存至本次操作完整结束。
- 存档采用临时文件验证后替换；失败明确提示，不能静默显示保存成功，不能写入其他槽。保存失败时保留内存进度，并允许重试；“保存退出”只有成功才离开。
- 手动存档/读档快捷键与面板入口撤除。玩家重载仅从开始菜单选槽；测试可调用独立存档服务，不暴露玩家手动保存入口。
- 删除只针对选定槽，清理对应快照/备份；不删除其他槽或全局设置。

### 退出与旧档兼容

- OS窗口关闭、返回主菜单和退出按钮统一走退出决策。
- “结束当天并保存”：走一次正常过日与完整自动保存，再离开。第45天结束时回顾数据也必须保存。
- “放弃当天进度”：离开，不写当前内存状态；下次继续从最近成功保存的日初快照恢复。
- “取消”：返回当前游戏，资源/时钟/统计均不变。
- 现有schema2/3单档支持显式导入所选槽，遵守占用槽覆盖确认。只复制，不删除旧文件；导入后不重复赠种子、元石或工具。
- 旧档没有可追溯行为日志，不伪造历史统计。导入时说明首轮回顾从该档接入Demo后统计45个游戏日；新档严格对应第1～45天。

## 5. 首次45天经营回顾

### 6.e 统计模型与触发

新档窗口为游戏日1～45；在第45天结束且全部结算完成后冻结统计，并展示回顾。此时进入第46天的生长或饱食度变化不计作第45天经营行为。

| 数据 | 统计口径 |
|---|---|
| 种植作物 | 每种作物成功播种株数；大型作物不按占格重复计数 |
| 收获次数 | 每种作物成功采收次数；再生作物每次采收计一次 |
| 收获产量 | 实际入库的食材/返种数量，按物品统计 |
| 出售收入 | 成功出售实际获得的元石，不含初始60元石 |
| 支出 | 种子、生产材料、高级工具分别统计成功支付的元石 |
| 净收入 | 出售收入减上述支出，可为负；不等同余额 |
| 期末余额 | 第45天结束结算时的元石余额 |
| 喂养消耗 | 实际成功喂养消耗的材料数量 |

统计写在共享成功结算入口，不由UI点击次数计算。失败操作、引导检查、加载存档、免费初始资源不记收益；放弃当天时统计同世界状态一起回退。

- 冻结回顾保存在所属槽，可从经营记录重看；后续行为不修改这份报告，不自动生成第二份。
- 展示与数据生成分离，预留将来复用不同统计区间；本阶段不实现循环季度系统。这里“三个时节”为45天，不是现实三个季度。
- 若退出、读档或关闭窗口发生在回顾附近，不重复冻结、不重复结算；允许重新打开已生成的回顾查看。

## 6. 设置、平衡与Demo交付

### 6.f 常用设置

窗口/全屏、分辨率、垂直同步或帧率上限、显示FPS、操作说明、新手教学重看/跳过。音量可保留为配置项，但无音源时明确标注尚未启用，不播放占位音轨。高级工具范围预览和当前等级必须可见。

设置属于全局用户配置，不混入三个游戏槽；重启后恢复。分辨率更改不得导致按钮超出视口，关闭菜单后不得残留地图输入锁定。

### 6.g 轻松经营与交付

- 保留初始60元石；现有种子数、价格、产量和生长时间可配置调整，但应有45天试玩依据，不添加强制任务或失败倒计时。
- 检查买种→多轮收获→出售/喂养→再买种的可持续性，以及工具投资何时可负担；食材营养仍用标准种植成本公式，工具折扣不使同种材料价值随操作历史变化。
- 一个农场地图提供清晰的种植/菌床区域与通道；使用现有纹理和作物图整理布局，不新做小屋、摊位或装饰素材。
- 交付可直接运行的Windows Demo、操作说明、已知限制；无额外美术/音乐依赖。
