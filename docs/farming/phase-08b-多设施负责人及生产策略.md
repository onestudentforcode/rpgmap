# Phase 8.b — 多设施负责人及生产策略

> 日期：2026-10-11。状态：**已实施并验收通过（2026-10-11自动验收；见§8执行记录）。** 前置：[P8.a](phase-08a-数据配数与事务底座.md)。范围：[总纲](phase-08-生态产业网络与工艺研究.md)§5～6；下游：[P8.c](phase-08c-研究系统与依赖导航.md)。现行P7仍是一人一设施、不兼职，本稿不修改V2历史规则。

## 1. 目标与玩家流程

玩家从设施选择负责人，同一人可保留其他设施；在名册查看全部关联设施、优先级和当天负载。兼任农务默认关闭，开启后选择区域/工作类别及资源点；不自动帮全农场。持续生产默认关闭，选择配方与目标库存后才安排自动投料。

本阶段用既有羊圈、水场、木作台、藻槽和农务验证调度；研究、新生态及装置随后通过同一任务接口接入。人数不限、无招聘费/固定日薪，成功工作1元石，设施建造/拆除仍手动。

## 2. 数据与代码边界

现有`v1_workforce.gd`只在普通农务与专责巡栏之间选择，`v2_husbandry.gd`的`caretaker_facility`和指派会清除个人农务。本阶段在P8建立多设施调度，不把单值改数组后继续让每设施独立结算12次工作。

| 状态 | 建议职责 |
|---|---|
| 设施绑定 | 唯一`owner_worker_id`，未指派为无人；设施高/普通/低优先级 |
| 雇工策略 | 暂停、日预算、兼任开关/优先级、明确区域/类别，资源点归属 |
| 当日账户 | 按雇工UID＋日期共享成功次数、已收费、任务流水 |
| 生产策略 | 配方、开关、主要成品ID、目标数量 |
| 原料保留 | 全农场物品ID→最低剩余量，只挡自动加工投料 |
| 调度标记 | 任务稳定ID、等待起点/轮转游标、失败条件摘要 |

设施绑定作为唯一来源，名册关联列表派生，不保存两套可互相矛盾的关系。解除、改派、解雇或拆除清除对应绑定，不重置当天已收费/已服务；默认不删其他设施和全局农务标记。管理设置0AP/0元石，不立即执行工作。

## 3. 统一成功工作与计费

普通农务沿用成功地格动作，资源点沿用一次采集；整体养殖维护、一次换水、一次批次投料/收取、一次研究工作各占一次。活体多单位的一次启动/收取仍是一次设施动作。自动田间装置不占雇工次数、不扣玩家AP，只扣自身材料。

执行前校验绑定、目标合法性、日服务标记、库存、余额、剩余预算及共享12次上限。预检须保留本次1元石工资，再支付该动作其他费用，避免花完余额后免费成功；动作与工资在同一事务内提交，失败两者均不变。实际结束后追加可追溯流水，日结失败由P8.a整体回滚。

同人设施、研究、农务和资源点不得分别享有12次或各有预算。不同工人共享农场现金/原料；轮转每人一次成功行动后重新取候选，不能拿开局报价一直执行。手动完成的当日服务不收费；重新指派也不能让新负责人重复服务。

## 4. 排序、范围与积压

先过滤越权/无效任务，再按高→普通→低。设施使用各自设置；兼任农务/资源点共用个人兼任优先级，初值普通、可显式调整为高/普通/低，关闭兼任时不执行。农务任务的现有数值优先级保留作其内部排序，不直接与设施三级混算。同级先维持/必要换水与收取，再研究、投料、农务；相同类别按等待起点和稳定UID轮转。

每个设施/单位/日服务生成稳定任务ID，执行后重新检查状态，可以生成后续合法任务，例如先收取再开新轮；当日结算刚完成的产物到下一服务日才可收取。失败不占成功额度，同一条件未变不重复试；其他任务消耗/产生相关库存后可重新评估。

严格高优先级每天吃满额度时，低优先级可能长期积压；同级轮转只防同级独占，不能承诺低优先级永不等待。UI持续提示积压天数、预计超额和可调优先级/预算，不暗中越过玩家选择。

农务须同时满足兼任开关、区域、工作类别、全局标记/种子计划等原有条件；资源点须显式指派。关闭兼任保留选择以便重开，停止执行并说明；不自动撤销全局待办。花源手采接入后也须明确启用，不当作收获全选的隐含行为。

## 5. 目标库存与原料保留

定义主要成品的`有效存量＝仓库现货＋全农场已投料在制预计产量＋待收取量`。在制与待收取不重复累计；无投料的排队计划不算存量。启动前有效存量低于目标且配方/设施/物种可执行才开完整一批，允许最后批超目标；对活体选实际缺口所需的空闲成体单位，最后一单位可超额，不拆其配方。

多产物由玩家选定一个主要成品作目标，其他产物正常入账/出售，不虚构多目标最优调度。只管本设施的自动新投料，手动投料不受目标限制；关闭策略不取消在制，自动收取仍取决于负责人、额度和费用。

自动投料每项材料必须满足`库存－本批投入≥保留量`；同一任务重验全部投入后一次扣除，不部分欠料。保留不是仓储容量或锁库存，不约束手动、交易、建造、研究、基础维护及设备运行。活体特殊生产投料属于自动加工，须受保留量约束；基础维护不受其约束。

研究项目仍由玩家选择和启动，本策略不擅自购买样本或开启研究；持续生产只负责已选工艺的批次。无负责人时只保留设置并提示手动/指派，不能让加工台无工作免费启动。

## 6. 界面与保存

设施详情提供负责人、优先级、当前可执行动作；加工页提供持续生产开关、配方/主要成品/目标与全局保留量入口。名册显示实际已用次数/费用、各设施需求、可执行工作与条件满足后可能新增工作，能定位积压目标。

预估不算未成熟或未完成研究的工资；材料不足、预算不足、次数用完、无负责人、目标满足、保留量阻挡分别显示。兼任为空时说明此区域用途，不能显示成默认负责全部地格。

快照校验未知/重复绑定、无效优先级、负数目标/保留量、越界区域、重复任务流水和当日账户错误。读档只恢复策略与账，不能重新执行委托。派工/策略保存沿用所属槽日结保存，不新增手动存档按钮。

## 7. 验收与提交

| 场景 | 预期 |
|---|---|
| 一人多设施＋研究＋兼任合计13个可执行动作 | 最多12个成功，费用/预算共用 |
| 余额恰够工资、动作另需消费 | 动作被拒绝，不免费成功/负余额 |
| 玩家维护后改派、新负责人巡栏 | 不重复服务/收费 |

| 存档失败/重试、重复日结 | 实际次数、收费与任务标记不重复 |
