## 1. 日结与时节条目

每次日结按农务、收成、采集、加工、供货、建设、交易、支出、雇工提示输出条目，同类同资源合并数量。保留最近15天的结构化日报，条目文字由已保存计数生成，打开面板和重载不再次执行操作。

普通日结以地图上的小面板显示前三条，多余条目提示数量并可查看详情；可手动收起。保持当前侧栏，并更新该侧栏的库存、任务和生产状态。雇工预算/资金不足、缺料优先提示；等待成熟、未达养护阈值、日资源产能用尽属于正常等待，不作为停工告警刷屏。保存失败提示进入详情重试。

第15/30/45天的摘要增加所属时节收入、支出及净现金变化。三个时节的小计长期保存在首次回顾中，即使早期逐日条目不再位于最近15天列表，也能查看其汇总。

地格显示种植完整投入、缺料数量、完整占地、任务等待条件、生长进度、水肥和固定光照；设施显示投入/产物、完成所需天数及待收状态。任务状态查询为只读，不扣资源、不触发引导、不推进AP。

## 2. 操作提示

提示覆盖地格选种、框选派工、完整占地播种、设施加工、订单交付。通过真实成功行为登记，不锁定操作次序；失败、不适用框选和无效选种不完成提示。顶部显示下一条未经历内容，手册列出全部说明，可跳过/恢复提示，不奖励物资、不更改生产。

提示随所属槽每日保存；放弃当天同时回退提示修改和实际经营。日存档失败时阻断提示修改，重试只保存原已结算状态。

## 3. 首次45天记录

第1～15、16～30、31～45天分别计入三个时节。当天成功行为先记待结算账，雇工结果、生长成熟、加工完成全部进入同一天，再更新对应时节账与日报，最后一次存档。末AP与手动结束当天共用此顺序。

统计包含：四植物种植株次、收获次数/作物产量、开垦/养护、资源采集数量、加工启动/完成批次/收取产物、五行订单单数/交付材料、建设数量、雇工工作量，以及销售/订单收入和采购/建设/人工元石支出。手动与雇工成果合并计数，人工成功次数另列，不把包装层再次计为种植或收获。

第45天结束前完成本日全部结算，冻结三个时节账、期末元石及库存，并自动提供回顾。其后可继续经营，日条目继续更新，首次回顾不再变化；“记录”可重看总计及三个时节小计。

```text
收入 = 实际销售收入 + 实际订单回款
支出 = 实际采购元石 + 实际建设元石 + 实际人工费用
净现金变化 = 收入 - 支出
期末元石 = 记录期初元石 + 净现金变化
```

初始种子/赠物不计收入，仓库材料、行动点、时间不折算进现金支出；固定供养成本不重复计入账本。库存单独展示，不估值，不称净现金变化为利润。

## 4. schema 6兼容

新增`journal`包含记录开始日/期初现金、三个时节账、当日待结算账、最近15份日报、第45天期末现金/库存及操作提示。严格验证字段、合法ID、整数计数/金额、时节日期、日报连续日期、提示去重、冻结日期与现金等式。无效快照在修改活世界前拒绝。

旧V1 schema 1～5保留原有生产、订单、雇工与元石，从升级当天开始新记录；界面注明此前行为缺失。升级时已过45天的档明确不能生成首次回顾，仍可查看后续日条目。旧版本不能夹带新字段；V0存档仍隔离。
