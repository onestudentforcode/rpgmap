# 灵田交互界面

2026-10-09：本轮优化HUD与库存/集市/喂养，不更改世界资产、物价或喂养规则。

## 配色与层级

沿用灵田的叶绿与青玉意象，界面使用墨绿底、纸色文字；深色实底保证地形细节不会干扰阅读。色值集中在 `scripts/farming/rendering/farm_ui_style.gd`，独立于世界美术色板。

| 用途 | 色值 | 原因 |
|---|---|---|
| 面板底 | #172922 | 墨绿中性色，与草地明度区分 |
| 物品卡/按钮 | #223b31 | 比面板浅一档，形成可读层级 |
| 悬停/按下 | #315545 | 连续绿阶，标明交互状态 |
| 边线 | #627c62 | 区分卡片与焦点，不增加高饱和噪声 |
| 正文 | #f2ead3 | 暖纸色，兼顾东方灵田意象与对比度 |
| 辅助文字 | #b8c5b2 | 用于用途、库存不足说明，仍保持可读性 |
| 成功/焦点 | #a5dfad | 玉色强调，用于成功反馈及当前工具 |
| 失败反馈 | #ffb6a3 | 温暖浅赤，配合文字说明错误 |

明度阶：#172922 → #223b31 → #315545 → #627c62 → #a5dfad。正文与各背景对比度须达到4.5:1；禁用状态同时写原因，不只靠颜色区分。

## 布局与操作

- 640×360逻辑视口，默认窗口放大至1280×720。顶部显示日期/AP/元石/饱食度、菜单及地格提示；底部为可点击的工具、介质、休息和行囊入口。P6.b已将存读按钮替换为所属槽/菜单入口。
- HUD不再铺开全部背包；库存单独按种子、生产材料和食材分组。
- M打开/关闭行囊，Esc或点击遮罩关闭。面板打开时地图相机平移/缩放暂停，列表滚动不会操作地图。
- 集市数量可输入或快捷设为1/5/10；按钮显示数量和总价。元石/库存不足则禁用并说明原因。
- 喂养页列营养值与一餐份数；尚未饥饿或材料不足时说明原因。
- 交易、喂养反馈留在面板底部；农场操作提示显示4秒，鼠标移动不立即清除。
