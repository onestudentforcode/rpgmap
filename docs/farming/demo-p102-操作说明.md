# P10.2 农业区操作说明

当前版本使用 schema20，请新建 P8 存档。早期 P8 存档会明确提示不支持；旧文件保留，不会自动迁移或删除。

1. 通过 `play.bat` 或 Godot F5 进入游戏。完成「田间维护」研究，准备维护站材料与每日元石。
2. 打开顶部「农业区 · 地板与收获奖励」。选择耕地，在地图逐格开垦；右键退出铺设工具。上下左右相连的耕地属于同一田块，空耕地也计入，斜角接触不相连。
3. 普通地板每格耗原木1、1AP，可隔开田块，也可承载维护站。改铺、拆除各耗1AP，拆除不返料；占用地格须先处理占用物。地板不会刷新地格水肥或小数扣耗余量。
4. 在田块外建造1×1田间维护站，每座站一个蛊槽。在「后勤蛊 · 入驻、生产与维护」领取本档一次的试用蛊，分别将催生、锁水或节肥蛊入驻不同维护站。
5. 选中维护站设置朝向，查看3×3蛊服务区；转向耗1AP，次日生效。普通补水、施肥另有5×5范围和独立开关，仍消耗仓库清水、腐殖土，不会因为锁水或节肥自动产生物品。
6. 保证每日维护元石充足。农业区页面显示当日有效覆盖，提供覆盖缺口定位；刚部署或刚转向时，应同时核对次日范围。蛊停工会影响之后的合格进度，已经积累的贡献仍保留。

例如，一块3×3耕地可由左侧向东的催生站、右侧向西的锁水站、上侧向南的节肥站共同服务。三座站都在耕地外，不需要中心建筑。若以耕地左上角为 `(9,10)`，可使用以下布局；坐标仅是布局示例，建造仍受地权、地形与占用限制。

| 对象 | 坐标 / 范围 | 朝向 |
|---|---|---|
| 耕地 | x=9…11，y=10…12，共9格 | — |
| 催生站 | (8,11) | 东 |
| 锁水站 | (12,11) | 西 |
| 节肥站 | (10,9) | 南 |

催生＋锁水完整覆盖整个连通田块时是一级育种田；催生＋节肥是一级丰产田；三种齐全是二级复合区，同时拥有两条回报。不同维护站可以共同覆盖田块，但对2×2作物，每一种效果都需要至少一个来源完整包含该株，不能将两个半覆盖拼起来。

选中作物可查看本轮实际生长点、两种合格贡献和首次产种状态。全程合格时，首次成熟有25%概率获得种子1份；部分合格按实际贡献比例折算。结果在首次成熟时固定，首次成熟收获、砍伐或成熟清理时一并兑现，不另耗AP；留株再生不会重抽种子。

丰产奖励只增主产物。以基础收成 B 和合格贡献比例 q 计算 `E=B×25%×q`，先取整数份，再按小数概率加1份。每轮成熟独立计算，秸秆、花瓣等副产物不随之增加。收获提示及经营报告分别列出基础收成、育种奖励和丰产奖励；未领取权益不算实际入库。

扩展连通田块时，新增的空耕地同样必须受到完整覆盖，否则区域可能降级。普通地板可切断连通关系；铺设预览会提示合并、拆分与降级。硬质地板、管道、漏斗与传动留待后续阶段。
