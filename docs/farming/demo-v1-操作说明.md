# 灵田 Demo V1 试玩说明

这是生产、加工、五行供货与普通雇工的试玩版，已完成Phase 6.5明亮界面与交互改版。解压后运行`LingTianDemoV1.exe`；工作区运行`play.bat`或Godot F5。`play.bat v1`等价，`play.bat v0`保留旧版。UI使用统一矢量图标，地图上的作物与设施仍是示意图，完整场景美术另批制作。

## 开始与保存

在开始页选择三个V1槽之一新建或继续。初始60元石和基础种子，每天24行动点，每15天一个时节。每天结束自动保存，没有手动存档；返回菜单或退出会放弃当天未保存的操作。V1与V0存档目录隔离，不导入V0旧档。

## 点击与框选

- WASD或方向键平移，滚轮缩放；“查看”工具点击地格进入侧栏。
- 顶部与工具栏使用小图标，悬停或键盘焦点显示功能。0查看，1～9依次选择农务/区域工具；M交易、O订单、U雇工、B建设、J记录、F全图、R结束当天。
- 管理窗口一次打开一个，阻断地图输入。右键回到查看；Esc先取消当前工具/放置，再关闭窗口，再打开菜单。文本/数量输入时农务和日结快捷键暂停。
- 给地格分配种子，开垦完整占地后手动播种，或交给负责该区域的雇工。收获后选种保留，种子/培养料足够才重播。
- 展开“农务工具”，选择开垦、播种、收获、浇水、施肥、砍伐或清理，再拖动框选。符合条件的地格添加标记，日结才执行。标记优先级1～9。
- 收获包含麦/菌菇采收和留树采脂；砍伐取得树木材料；清理移除任何阶段作物，不返还投入。取消标记不会取消地格选种；想保持空闲，选“不播种 / 保持空闲”。
- 框选时预览有效/跳过地格与目标数，只添加待办。清理每次框选确认一次；取消零改动。成熟采收/砍伐直接执行。
- 点击泉水、石矿资源点，手动采集或单独指定一名雇工。资源点共享每日产能，不通过框选工具派工。

## 雇工与生产

最多两名普通雇工，无固定日薪；每人每日最多成功12次，每次1元石，不消耗玩家行动点。个人工作偏好0～5，0禁止，高偏好先于地格标记优先级。分配负责区域后才能接农务任务，资源点指派不受区域限制。

开局可先手动生产、建设，再雇佣并控制日预算；缺钱或缺料时跳过，失败不收费、不自动买料。浇水/施肥委托只在水分/肥力低于30时执行；低水低肥只使生长变慢，不致死。木腐菇更适合地图左下阴区，每轮投入菌种、木屑和清水。

从顶部建设图标选择木工台、炭化炉、堆肥箱或冶炼炉，再到地图放置。预览显示占地、冲突与完整造价，连续放置，右键退出。点击设施查看投入、产物、缺料与配方；投料后等待1～2天，完成后手动收取。设施建拆、加工启动和收取均手动；忙碌/待收设施不能拆除，拆除另确认且不退款。

“行囊/交易”按类别查看物品，选择数量或1/5/10，核对总价后买入/出售；资金或库存不足会禁用动作并显示原因。“订单”按五行和转数交付一种合格食材，卡片并列显示持有/必要数量、静态供养值、市价与溢价。未完成不罚款，同单只结算一次。收入可用于买种、建设与人工工作。

## 摘要、提示与回顾

日结以农务、收成、采集、加工、供货、交易和雇工条目展示摘要，重复事件合并数量。常规窗口显示前三条，紧凑窗口显示一条，可收起；摘要详情或顶部记录查看最近15天条目及工作日报。每15天增加时节收支小结。记录中的定位图标指向现存资源点、对应设施或成熟作物；汇总条目不补造历史坐标。

“手册”提供简短操作提示，可跳过或恢复，不锁住玩法、不赠送物资；提示状态随所属槽日存档保存。

第45天结束自动显示首次经营回顾，可选择45天总计及三个15天小计。销售/订单是收入，采购/建设/人工是元石支出；净现金变化为收入减支出，库存单列，不折算利润。初始赠送物资不算收入。回顾此后冻结，可继续经营并在“记录”重看。

旧V1存档从升级当天开始记录，并注明此前数据缺失；升级时已过45天的旧档不能补造首次回顾，但仍有后续日条目。

## 显示设置与故障恢复

菜单的设置图标可配置全屏、窗口分辨率、帧率、FPS及100%/125%/150% UI缩放。以2560×1440为主，兼容1920×1080、1280×720与960×540；窗口缩小时内容可滚动，地格详情可收起。UI缩放不改变地图缩放、选中地格或游戏进度。音乐尚未接入。

日存档失败时界面保留固定提示，生产、交易与日结暂停。打开记录点击重试，只保存已完成的那次结算，不重复劳动或收费。设置使用独立全局文件，V1三槽及旧V0存档路径均保留。
