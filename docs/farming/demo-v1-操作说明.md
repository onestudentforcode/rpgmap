# 灵田 Demo V1 试玩说明

这是生产、加工、五行供货与普通雇工的试玩版，作物和设施目前使用文字占位美术。解压后运行`LingTianDemoV1.exe`；工作区运行`play.bat v1`。

## 开始与保存

在开始页选择三个V1槽之一新建或继续。初始60元石和基础种子，每天24行动点，每15天一个时节。每天结束自动保存，没有手动存档；返回菜单或退出会放弃当天未保存的操作。V1与V0存档目录隔离，不导入V0旧档。

## 点击与框选

- WASD或方向键平移，滚轮缩放；“查看”工具点击地格进入侧栏。
- 给地格分配种子，开垦完整占地后手动播种，或交给负责该区域的雇工。收获后选种保留，种子/培养料足够才重播。
- 展开“农务工具”，选择开垦、播种、收获、浇水、施肥、砍伐或清理，再拖动框选。符合条件的地格添加标记，日结才执行。标记优先级1～9。
- 收获包含麦/菌菇采收和留树采脂；砍伐取得树木材料；清理移除任何阶段作物，不返还投入。取消标记不会取消地格选种；想保持空闲，选“不播种 / 保持空闲”。
- 点击泉水、石矿资源点，手动采集或单独指定一名雇工。资源点共享每日产能，不通过框选工具派工。

## 雇工与生产

最多两名普通雇工，无固定日薪；每人每日最多成功12次，每次1元石，不消耗玩家行动点。个人工作偏好0～5，0禁止，高偏好先于地格标记优先级。分配负责区域后才能接农务任务，资源点指派不受区域限制。

开局可先手动生产、建设，再雇佣并控制日预算；缺钱或缺料时跳过，失败不收费、不自动买料。浇水/施肥委托只在水分/肥力低于30时执行；低水低肥只使生长变慢，不致死。木腐菇更适合地图左下阴区，每轮投入菌种、木屑和清水。

点击空地建设木工台、炭化炉、堆肥箱或冶炼炉，点击设施查看配方。投料后等待1～2天，完成后手动收取；收取前不能再启动。设施建拆、加工启动和收取均手动；忙碌/待收设施不能拆除，拆除不退款。

“行囊/交易”购买生产投入或出售余料；“订单”按五行和转数交付一种合格食材，界面计算必要数量和回款。未完成不罚款，同单只结算一次。收入可用于买种、建设与人工工作。

## 摘要、提示与回顾

日结以农务、收成、采集、加工、供货、交易和雇工条目展示摘要，重复事件合并数量。默认显示前三条，可收起，不切走当前侧栏；“详情”或顶部“记录”查看最近15天条目及详细工作日报。每15天增加时节收支小结。

“手册”提供简短操作提示，可跳过或恢复，不锁住玩法、不赠送物资；提示状态随所属槽日存档保存。

第45天结束自动显示首次经营回顾，可选择45天总计及三个15天小计。销售/订单是收入，采购/建设/人工是元石支出；净现金变化为收入减支出，库存单列，不折算利润。初始赠送物资不算收入。回顾此后冻结，可继续经营并在“记录”重看。

旧V1存档从升级当天开始记录，并注明此前数据缺失；升级时已过45天的旧档不能补造首次回顾，但仍有后续日条目。
