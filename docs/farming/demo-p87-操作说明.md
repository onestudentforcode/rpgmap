# 灵田Demo P8.7 操作说明

运行解压目录中的`LingTianDemoP87.exe`，无需安装Godot、Blender、Python或外部素材。

本版将地面纵深与35°物件视角统一。逻辑地格仍为64单位方格，屏幕上显示为较扁的矩形；植物、设施与资源景物保持原比例。点击地格、建设占地和委托区域仍按原网格计算。

WASD或中键拖动平移，滚轮以光标为中心缩放，右键回到查看，F适配全图。小窗口侧栏开启时，定位会为侧栏和底部工具栏留出空间。低缩放用于总览，1.0附近查看经营，3.0检查近景。

原P8玩法、价格、人力、AP、研究与schema17三槽存档保持，使用既有P8档案命名空间；schema16旧档按原规则需重新开档。每日结束保存；当天未保存的行为在退出时丢弃。需要完整玩法说明时打开游戏顶栏“手册”。

营建选择设施后点击地面放置；播种前为目标地格分配种子；委托模式可拖选矩形区域。查看未购买的地块可打开购地窗口，关闭后返回地图。

本包不包含开发试样的F7/F8投影切换与标尺。动物新模型、工作特效及采后新形态继续留待后续。
