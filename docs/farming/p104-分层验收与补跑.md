## 常用命令

先选一个新证据目录；计划记录共享模型、配置与夹具源码指纹。历史计划和验收文件保留。

```powershell
test-p10-4.bat -Stage Plan -Root .art-work/p104-playtest/my-run
test-p10-4.bat -Stage Model -Root .art-work/p104-playtest/my-run
test-p10-4.bat -Stage Run -Root .art-work/p104-playtest/my-run
test-p10-4.bat -Stage Audit -Root .art-work/p104-playtest/my-run
test-p10-4.bat -Stage Probes -Root .art-work/p104-playtest/my-run
```

单个小环节出错只补跑对应分区；`-Rerun`将该分区原scenario和日志移入archive目录，不覆盖其他分区。此路径已用真实toy分区验证。

```powershell
test-p10-4.bat -Stage Run -Root .art-work/p104-playtest/my-run -Cases toy -Rerun
test-p10-4.bat -Stage Audit -Root .art-work/p104-playtest/my-run -Cases toy
```

审计器修正可直接重审原scenario，无需重玩。修改共享玩法/配置/夹具后，依赖它的旧场景失效，须用新目录建计划；UI和冒烟驱动不是短场景的输入，不因它们的独立修改重跑全部模块。早期计划过宽包含这两类文件，调度器只比较实际共享输入，保留原计划。

```powershell
test-p10-4.bat -Stage UI -Root .art-work/p104-playtest/my-run
test-p10-4.bat -Stage Accept -Root .art-work/p104-playtest/my-run
# 仅跨模块/存档里程碑安排一次，不放进日常默认检查。
test-p10-4.bat -Stage Smoke -Root .art-work/p104-playtest/my-run
```

`Accept`只汇总当前六个必需短场景与账本，不扫描archive，不代表已运行模型、GPU或长冒烟；完整阶段证据另由`collect_p104_evidence.py`核实并汇总至[验收JSON](phase104-validation.json)。该汇总工具的默认路径指向本次冻结证据，复用到新阶段应同时更新相应日志输入，不能将旧通过标记搬作新结果。

## 成本与局限

[成本对照JSON](phase104-costs.json)由当前配置和短场景生成。木板、木腐菌等不可购买物不能按买价0算免费，另列标准成本。藤球原料市价12元石，制作1日、开工/领取共2AP、安装1AP；使用不消耗材料。两蛊各1元石/日，闲置但启用仍付维护。

啮岩鼹普通圈养8日首次繁殖，安抚为6日；完整繁育贡献给180/1800初始成长。当前幼体购价8元石且不限购，繁殖的食料与设施投入更高，暂不改价。相同劳动与蛊的6日役使对照，三级系统使用35000个Q100工作点，即350普通工作点；这证明减少已支付劳动的浪费，未据此宣称短场景的实际成品吞吐提高。

新增建筑仍为占位美术，主观试玩未由代理代签；服务历史随存档保留，超长周期的压缩与性能另排。旧P10.1～P10.3和边界验收JSON保持原样，不恢复八条120日经营门禁。
