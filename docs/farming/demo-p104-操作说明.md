# P10.4 操作说明

当前开发版本需新开schema22档。旧17～21档保留原文件并拒绝加载，不做迁移。入口仍为`play.bat`/F5。

1. **先划边界。** 农业页登记田块，畜牧页划定五类功能区。成员内部上下左右连通即可；相邻区域不会合并，新铺地格也不会自动加入。
2. **建一级配套。** 农业维护站先铺普通地板，再关联相邻且至少4格的登记耕地，普通补水施肥不依赖蛊。畜牧各类配套见管理页；额外放牧区需空玩具站和至少8可用空间。缺结构时服务停，但动物禁工、疲劳等时钟继续。
3. **加入二级强化。** 后勤页一次领取15只试用蛊。圈养区安抚台入驻安抚蛊，工作区调度站入驻驭兽蛊；次日生效，各1元石/日，实际繁殖/劳动进度150%。每站每单位服务4空间，羊占2，鼹/岩腹兽占1。
4. **制作并安装玩具。** 木工台以树枝2＋秸秆2制作藤球，无研究门槛。选择抓娃娃机外观的玩具站装入，1AP；卸下也1AP并返还原物。长期使用，每个有效额外放牧单位有10%概率额外恢复1疲劳，在次日开日结算。
5. **明确组合系统。** 畜牧管理页编辑组合并提交1AP。二级圈养＋关联的一级育幼可积累出生初始成长贡献；二级工作＋同调度的一级维持＋二级额外放牧可确认劳动余量。两组并存即综合牧场，独立结算，没有额外总倍率。
6. **查看和领取。** 工作场完成批次仍需领取；余量只给原岗位同配方，下批支付材料并实际获岗后才用。降级封存，切配方或拆除前先明确放弃。出生需要目标育幼区实际有床和空间，成长赠送只按本轮实际贡献发一次。

育种田、丰产田、复合农业区现在都属于三级配置，种子25%与主产物增产25%的原算法保留。地图选择玩具站可直接装卸；畜牧页管理房间、动物、日程、工作配方、领取与系统关联，百科可查完整条件。首次建设优先保证基础口粮、床位和空间，再安排强化。
