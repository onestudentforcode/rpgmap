# 生产与经营系统设计纲要（V0.2）

> **状态：** 草案（2026-10-10 用户提案，本文为整理稿，待评审定稿）
> **V1落地口径：** 用户已确认范围及关键规则，见[Demo V1计划](demo-v1-plan.md)和[首批资源关系表](demo-v1-resources.md)。本纲要保留长期方向；未纳入V1的养殖、水产、特殊单位仍为后续设计。V0.2是本文修订号，不是Demo产品版本。
> **核心定位一句话：** 一款**以资源生产、物质转化和产业经营为核心，融合轻度生态模拟与奇幻生物养殖的休闲经营游戏**。
> **两条定位边界：**
> - 不需要严格遵守现实世界的物质守恒，也不要求玩家解决过于复杂的生存问题——**现实规律用于解释资源转换的合理性，奇幻设定用于创造新的生产方式**；
> - 核心目标是**通过经营产业获取货币，再用货币、资源和劳动力扩大产业规模**；玩家做资源分配决策，但不必承受《缺氧》式的高强度生存压力。
> **文档层级：** 本文是生产经营系统的**总纲**（定位 / 原则 / 优先级）；物种候选库见 [production-system.md](production-system.md)（v2，43 种），七大机制补充见 [economy-systems.md](economy-systems.md)（部分内容已由本文裁决收敛，见附录）。

## 1. 游戏的整体生产结构

四个主要生产模块：

| 模块 | 主要能力 | 玩法特色 |
|---|---|---|
| 种植 | 生产植物资源 | 水分、肥力、光照、生长周期 |
| 畜牧 | 通过动物完成资源转换 | 饲养、采集、繁殖、特殊食性 |
| 水产 | 生产水生资源和特殊材料 | 水体环境、养殖、繁殖 |
| 加工 | 对初级资源进行处理与转化 | 配方、设备、能源、工艺 |

四个模块不是彼此独立的：种植为畜牧提供饲料，畜牧为种植提供肥料，水产提供特殊原料，加工将初级资源转化为更高价值的商品。

另外需要三个支撑系统：

- **资源点系统**：提供稳定的初级资源来源；
- **劳动力系统**：执行采集、养殖管理、加工等工作；
- **经济与消耗系统**：负责货币收入、产业升级及特殊单位的资源供养。

整体经济循环：

```
资源点 / 种植 / 畜牧 / 水产          ┐
   获取初级资源和生物材料             │
        ↓                           │
     加工产业                        ├─ 内部生产：饲料与生产原料回流
   加工原料、转换属性、提高材料价值    │
        ↓                           │
     出售商品 → 获得货币              │
        ↓                           ┘
     发展消耗：建筑与特殊单位
   雇佣劳动力 · 建造设施 · 升级产业 · 扩张生产
        ↓
   收益重新投入生产，形成经营循环
```

**战斗定位**：不把战斗设计成资源生产的必经环节。战斗单位可以提供另一种发展方向，但**种植、养殖、加工、销售本身就应该形成完整的经营循环**。

## 2. 资源系统：从单一分类改为多维定义

"食物、建筑材料、可加工原料、最终产物"是一个好起点，但混合了两种分类标准——食物/建材按**用途**分类，可加工原料/最终产物按**生产阶段**分类（木材既是建材也是加工原料；谷物既可以是饲料也可以加工成高级商品）。因此不适合要求每种资源只选一个类别。

### 2.1 资源的用途分类：八种用途标签

| 用途类型 | 代表材料 | 主要用途 |
|---|---|---|
| 食物 / 饲料 | 牧草、谷物、鱼肉、菌菇 | 动物饲养、特殊单位供养 |
| 种植 / 培育材料 | 种子、菌种、肥料、培养基 | 生物繁殖、种植、养殖 |
| 建筑材料 | 木板、石材、金属锭、钢丝 | 建造、升级、维修 |
| 加工原料 | 木材、矿砂、纤维、油籽 | 进入其他生产配方 |
| 能源材料 | 木炭、植物油、松脂、储热材料 | 燃烧、供热、驱动设备 |
| 生产介质 | 水、盐水、营养液、溶剂 | 参与生产或改善环境 |
| 功能性消耗品 | 生长促进剂、特殊饲料、催化剂、战斗补给 | 额外增产、特殊单位支持 |
| 商品 / 高价值材料 | 珍珠、精制织物、特殊金属、工艺品 | 出售换取货币 |

三条设计原则：

1. **资源允许拥有多个用途标签**：`木材 = 建筑材料 + 加工原料 + 能源材料`；`谷物 = 食物 + 加工原料 + 商品`。
2. **大部分资源都可以出售**："商品"不是严格排他的资源类别——原木可以出售，钢绒也可以出售，只是不同加工阶段对应不同的经济价值。
3. **特殊生产需求主要用于奖励玩家，而不是设置强制门槛**：钢绵羊只喂基础草料也能产钢绒，添加含铁矿盐后产量或品质提高。保留生产链联系的同时，避免玩家因缺某一种材料而无法继续经营。

### 2.2 资源的生产阶段：三级分类

| 阶段 | 定义 | 示例 |
|---|---|---|
| 初级资源 | 资源点或生物直接取得 | 原木、牧草、岩石、原水 |
| 中间材料 | 至少经过一次转化 | 木板、木炭、金属丝、植物油 |
| 精制产品 | 经过进一步加工，具有较高价值或特殊功能 | 高级织物、机械组件、成品商品 |

注：阶段只描述资源位于产业链的哪个位置，**不意味着精制产品只能出售**——部分精制材料也可参与高级建筑和设施升级。

### 2.3 资源字段（第一版）

| 字段 | 作用 |
|---|---|
| `id` | 资源唯一标识 |
| `name` | 资源名称 |
| `element` | 金、木、水、火、土 |
| `form` | 固体、液体、气体、特殊能量材料 |
| `stage` | 初级、中间、精制 |
| `tags` | 八类用途标签，可多选 |
| `sources` | 资源从哪里取得 |
| `consumers` | 哪些生物、建筑或配方使用它 |
| `base_price` | 基础交易价格 |
| `stack_limit` | 单个库存单位的容量（可选） |

**品质、保质期、详细化学成分暂不进入第一版。** 当前最关键的不是资源属性数值，而是 **`sources` 与 `consumers`**——通过这两个字段可以知道哪些资源没有来源、哪些资源没有用途、哪些生产链尚未连接。

## 3. 种植环境系统：以现有 Demo 为基础扩展

**开发成本注记（2026-10-10 修正）**：当前 Demo **尚无水分、肥力机制**（`water` 仅作为 feed_tags 出现于 crops.json，无浇水/施肥逻辑），V1 的浇水与施肥是**新增功能**而非复用；仍不建议建立复杂环境模拟系统。种植环境控制在三个核心指标：

```
综合生长效率 = 基础生长速度 × 环境系数
环境系数 ← 水分（0~100）· 肥力（0~100）· 有效光照（0~100）
```

（公式仅说明交互关系；实际实现以新增的浇水/施肥动作为准，数值后续校准。）

### 水分

保留现有设计，以土壤含水量为核心：

- 浇水提高水分；随时间消耗水分；
- 不同植物耗水速度不同；
- **低水分降低生长速度，而不是立即导致死亡**。

### 肥力

肥料理解为**提高土壤肥力的资源**，而不是植物必须持续消耗的特殊物品：

- 普通种植缓慢消耗肥力；
- 有机肥、矿物肥恢复肥力；
- 高肥力提高生长效率或产量；
- 不同作物可有不同肥力消耗速度。

可以进一步区分肥料类型，但当前不必模拟氮、磷、钾等真实元素。

### 光照

采用最简化方案：每个种植区域拥有一个**有效光照值**，由地形、遮挡和设备决定。普通植物喜光，真菌可以喜阴，特殊植物可以有额外偏好。**初版可不引入真实昼夜变化，只计算稳定的光照等级**；不实现太阳角度、逐格光线追踪或动态阴影。

三个环境指标不必全部成为强制要求，保持"**普通条件能生产，优秀条件产得更好**"的原则。

## 4. 资源点系统：保留，但明确定位

资源点让玩家拥有**稳定、可预测、不会枯竭**的基础资源来源——非常适合轻松向经营游戏。风险在于：如果资源点能无限生产木材、矿石、草料、动物材料，种植、畜牧和水产的价值就会被削弱。

### 4.1 推荐定位：无限储量，有限生产效率

1. **储量无限**：不考虑矿脉枯竭；
2. **产能有限**：每个工作周期只能产出一定数量；
3. **只产出初级材料**：无法直接获得钢绒、木炭、珍珠等特殊资源。

有限产能不等于制造生存压力——产能可以通过**升级、增加劳动力、建造更多资源点**提高。

### 4.2 资源点与四大模块的差异

| 生产方式 | 核心功能 | 主要优势 |
|---|---|---|
| 资源点 | 获取最初级的天然材料 | 稳定、持续、容易自动化 |
| 种植 | 生物生长与资源积累 | 可再生、有生长周期、种类丰富 |
| 畜牧 | 特殊生物转化 | 独特产物、特殊副产物 |
| 水产 | 水生生物转化 | 水生材料、净水、矿物富集 |
| 加工 | 物质加工与价值提升 | 高价值产品、多路线转化 |

**资源点应当是产业链的入口，而不是替代生产产业链本身。** 初期开放三类：

| 资源点 | 产出 | 使用方向 |
|---|---|---|
| 采石点 | 普通岩石（土） | 加工石材、啮岩鼹破碎、岩腹兽分选、建筑施工 |
| 采矿点 | 低品位含矿岩石（土） | 岩腹兽富集、矿物分选、冶炼（初期不直接产出高级金属） |
| 泉水点 | 原水（水） | 种植灌溉、动物饮水、水产养殖、生产加工 |

后续可添加黏土点、盐水点、地热泉等，但不急于增加数量。

### 可建造资源点（两阶段）

- **初始资源点**：地图天然存在，玩家直接开发；
- **人工资源点**：中后期消耗货币和特殊材料建造（魔法采石场、人工灵泉、奇幻矿脉），两者都无限储量，人工资源点让玩家自由选择生产布局。

形成合理的成长过程：**自然资源点 → 初级产业 → 加工与经营收入 → 特殊材料 → 建造更多资源点 → 产业扩张**。

两条约束：

- 人工资源点的建造成本必须与经济价值匹配，否则玩家货币充足后无限建造，其他产业失去经济意义；
- **倾向：资源点主要覆盖无机初级资源**，普通有机材料仍以种植和养殖为主要来源——不提供无限产牧草的草料资源点、不提供直接生成原木的木材资源点，让四个模块各自拥有不可轻易替代的经济地位。

## 5. 劳动力系统：人力与特殊单位分离

劳动力系统把资源生产与货币消耗连接起来。保留两类：

| 类型 | 工作方式 | 成本 | 设计定位 |
|---|---|---|---|
| 普通人力 | 接受任务并完成工作 | 按工作量支付货币 | 通用劳动、填补产能 |
| 特殊单位 | 根据自身能力承担工作 | 后续设计资源消耗、培养等机制 | 特化生产、物流、战斗 |

现阶段只详细定义普通人力，特殊单位保留接口。

### 5.1 普通人力按工作量结算

不采用复杂的日薪、作息、饥饿和住宿系统，直接**按任务计费**：

| 工作任务 | 工作量计价依据 |
|---|---|
| 收割 | 收获次数或地块数量 |
| 采矿 | 采集数量 |
| 饲养 | 喂养、清洁、剪毛等任务次数 |
| 加工 | 完成的加工批次数量 |
| 建造 | 建筑对应的建造工作量 |

```
人工费用 = 工作量 × 单位工作量工资
```

避免玩家每天手动为大量琐碎任务指派人员，设计两种执行模式：

- **手动执行**：玩家直接操作，适合初期或重点关注的生产环节；
- **自动执行**：玩家配置雇佣人力和工作范围，人员自动执行任务、按实际完成的工作量结算。

普通人力本质上是**可以通过货币购买的自动化能力**。

### 5.2 特殊单位暂缓设计

特殊单位可参考《幻兽帕鲁》的思路，但不直接等同于劳动力。可能承担三种角色：**生产辅助、物流执行、战斗支持**——有的擅长搬运、有的辅助生产、有的没有生产能力而是消耗玩家生产的资源维持战斗能力。

当前只需明确：**特殊单位是生产系统的消费者和潜在执行者，但不应成为普通经营玩法的强制依赖**。后续单独设计时再讨论工作适性、移动方式、能力、成长和战斗系统。

## 6. 副产物机制：有用途才增加

如果每道加工配方都生成两三种副产物，库存很容易堆满几十种低价值材料。因此**副产物不是配方必须具有的内容**。

### 6.1 三种值得保留的副产物

| 类型 | 例子 | 设计意义 |
|---|---|---|
| 回收型 | 畜牧粪肥、木腐菇菌渣 | 返回种植模块 |
| 增产型 | 矿盐、特殊菌液、油饼 | 为其他生产者提供额外增益 |
| 加工型 | 木焦油、贝壳、谷物麸皮 | 进入新的加工配方 |

**增产型示例——榨油产业链：**

```
油籽花 → 油籽 → [榨油坊] → 植物油（火·主产物：燃料/加工原料）
                       ↘ 油饼（木·副产物）→ 制作优质饲料
油饼 + 基础草料 → 强化饲料 → 畜牧额外增产
```

这种副产物有两个优势：与其他产业产生联系；玩家即使不使用它，也不影响基础生产的正常运行。

### 6.2 副产物的筛选标准

后续每增加一种副产物，应确认至少满足一项条件：

- [ ] 可以直接出售，具有经济价值；
- [ ] 可以作为其他生产链的投入；
- [ ] 可以为其他生产者提供额外收益；
- [ ] 可以用于建筑、升级、特殊单位供养。

**四点都不满足，就暂时不要设计为独立资源**——可以直接吸收进主产物的产量结算，避免增加无意义的物品种类。

## 7. 经济系统：货币是主要目标，资源是经营手段

### 7.1 三种主要的资源消耗端

| 消耗端 | 主要消耗 | 对应玩法 |
|---|---|---|
| 商品销售 | 各类原料、半成品和精制产品 | 获取货币 |
| 产业发展 | 木材、岩石、金属、特殊材料及货币 | 建筑、升级、扩张 |
| 特殊单位供养 | 食物、特殊补给、装备材料 | 维持、培养战斗单位 |

出售资源本身不消耗劳动力，但生产和加工资源可以产生人工成本。引入简单的单位利润概念：

```
利润 = 销售收入 − 原料成本 − 人工费用 − 其他生产费用
```

不需要作为复杂财务系统呈现给玩家，只需能解释**为什么高级加工路线通常比直接出售初级原料更赚钱**。

### 7.2 不强制所有高级加工都更赚钱

保留经济上的取舍：

- 直接出售原木：加工少，收益稳定；
- 制造木板：需要加工工作量，但售价更高；
- 原木制木炭：获得能源，可支持其他生产；
- 木屑用于真菌养殖：资金回收较慢，但能建立持续经营的菌菇产业。

玩家不一定总选最高单价路线，而要根据当前产业的资源需求判断。**无限资源点通过劳动成本和产能控制经济收益，不引入资源枯竭、过高维护费等惩罚性机制。**

### 7.3 特殊单位创造持续性的资源需求

建筑建设是一次性资源消耗，特殊单位可以**持续**消耗食物、补给和装备维护材料。例如一支战斗队伍可能需要：

- **普通口粮**：通过种植、畜牧或水产获得；
- **特殊补给**：通过特定原料加工获得；
- **装备材料**：通过矿物、金属和纤维产业获得。

产业扩张由此不再是唯一的资源消耗端。战斗单位系统目前未设计，**只预留 `unit_supply` 这样的资源用途标签**，不急于确定具体消耗配方。

## 8. 畜牧与水产的生命周期

采用类似《缺氧》的轻量级设计，统一为以下机制：

| 机制 | 设计 |
|---|---|
| 生长 | 幼体随时间成长为成体 |
| 进食 | 消耗基础饲料，维持生长和生产 |
| 生产 | 成体按周期产出资源 |
| 繁殖 | 条件满足时产生幼体或卵 |
| 衰老 | 年龄增长后逐渐降低生产效率 |
| 死亡 | 寿命结束后离开养殖系统 |
| 特殊饲料 | 提升生产效率、繁殖效率或特殊产物概率 |

**不引入遗传与基因系统。** 为符合休闲定位：普通饲料满足基本生长、特殊饲料提供额外收益；**饲料短缺使生产暂停或效率下降，而不必让玩家立即面临大规模死亡**。

具有特殊采集方式的动物可加入不同生产周期——钢绵羊剪毛收集钢绒、矿鳞蜥蜕皮提供鳞片、珍珠蚌长期培养获得珍珠——动物有明显区别，但共用底层的生长、进食、繁殖和寿命逻辑。

## 9. 开发优先级

种植 Demo 已完成，不应一次性实现所有系统，按现有可玩内容逐步扩展：

| 优先级 | 工作内容 | 当前决策 |
|---|---|---|
| P0 | 资源分类与用途标签 | 本轮基本确定 |
| P0 | 种植环境系统 | **新建**水分、肥力（当前代码无此机制），光照用固定区域等级 |
| P0 | 资源总表 | 整理 43 种候选生物及其产物 |
| P0 | 原料加工关系 | 下一阶段重点 |
| P0 | 加工建筑与配方 | 下一阶段重点 |
| P1 | 资源点 | 保留机制，进一步验证产出范围和经济价值 |
| P1 | 普通人力 | 按工作量结算，支持自动工作 |
| P1 | 畜牧基础系统 | 生长、进食、生产、繁殖 |
| P1 | 水产基础系统 | 生长、进食、生产、繁殖 |

## 10. 三个值得讨论但不必立即决定的问题

1. **资源点与产业的经济关系**：无限资源点是否会过度挤压种植、畜牧和水产的收益？——倾向先采用"无限的初级矿石、水源等**无机**资源点"，暂不开放直接生产动物资源、特殊材料以及大量农作物的资源点。
2. **资源价格是否固定**：固定价格利于玩家规划生产线，动态价格能创造不同阶段的经营机会。——休闲定位下，建议首版采用**稳定基础售价**，之后再考虑订单溢价或小幅市场波动。
3. **生产过程是否需要玩家持续操作**：需明确未来玩家在畜牧、加工系统中是亲自完成任务，还是主要通过建筑配置与雇佣人力管理——直接影响整款游戏的**操作密度与节奏**。

## 11. 总结：现阶段的设计边界

- 五行是材料属性，而不是生克规则；
- 资源以多用途标签组织，而不是单一互斥分类；
- 种植、畜牧、水产是主要生物生产模块，加工负责转化与增值；
- 资源点无限供给最初级资源，但受产能与劳动效率约束；
- 普通生产条件宽松，特殊材料主要提供额外收益；
- 副产物只有存在明确用途时才单独设计；
- 货币是主要经营目标，建筑升级和特殊单位提供额外资源消耗；
- 普通人力按工作量付费，特殊单位另行设计；
- 生命周期借鉴《缺氧》，不加入复杂遗传系统；
- **已有种植 Demo 是后续扩展的基础，不为了新系统而整体重做。**

## 12. 下一步：资源总表与生产配方关系

先不继续拓展生物和资源品种，而是**正式建立资源总表与生产配方关系**：

1. 从 43 种候选生物中确定**首批实现名单**；
2. 逐个记录它们的**基础消耗、特殊增益需求、主产物、副产物和下游用途**；
3. 此时不急于设计加工建筑的外观和数量——资源流向明确后，再按"**哪些配方需要同类加工工艺**"归并建筑。

这样设计出来的加工系统是**生产需求自然推导出的结果**，而不是先创造大量建筑再为它们寻找用途。
