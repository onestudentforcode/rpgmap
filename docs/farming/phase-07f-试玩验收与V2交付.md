## 2. 两条45天经营路线

### 2.1 共用起点与记账要求

两条路线均从正式V2新游戏独立开始，初始60元石与正式赠送种子不变。使用独立测试槽目录，走同一世界操作、日结及存档接口；只允许正常购买、采集、种植、加工和养殖，不直接增现金/库存/AP、不调成长进度、不跳时钟或导入成熟个体。

每日可主动结束，但不能把现实等待当成长时间。末AP自动日结已发生时不再重复调用结束一天；界面日1对应服务日D=0，逐日台账统一注明显示日和实际结算日。

P7.a第1～10日台账可复用为起步依据，不把其采购预留当成实际动物。原期末30元石，买一羊＋两鱼需22，只余8；育成阶段负责人维护至少10次，故早托管不能只依赖这8元石。P7.d提出额外出售谷粒3增加12元石，属于待实测现金路线，不是直接补钱。

### 2.2 路线A：手动启动，再指派负责人

先用正常种植收入和采集建设圈舍、水场、藻料培养及必要堆肥设施，购入一只钢绵羊＋两尾滤藻鲤的初批规模。育成与首轮特殊生产由玩家手动完成，按实际动作支付AP、基础料、水与特殊投入。

至少完成一次剪毛和出塘并产生实际销售或订单收入，再根据现金/料覆盖指派专责负责人。记录切换日、当日原玩家服务和负责人日结结果，证明不会重复喂养/收费。鱼出塘后通过正常采购补苗，羊保留并进入后续周期；负责人不代买苗或启动藻料批次。

本路线重点验证开局可达、主动AP入口、手动与专责衔接、周期差异和再投资。保持可说明的经营选择，不规定所有设施在同一天切为自动化。

### 2.3 路线B：额外早售粮，尽早托管

复用正常早收麦的路线，在初批养殖投入外增加真实谷粒销售；按P7.d的额外3份谷粒方案先回放，再确认实际余额、首笔养殖收入和所需人工日数。若实际不足，记录具体缺口和正常经营调整，不能借未来收入预付工资或免费执行。

在幼体育成期指派圈舍/水场负责人，按各自设施独占工作，记录成功步骤、未完成原因、预算与共享现金。其他农务如有另聘人员也单独记费，不能把17次初轮养殖参考工作当成整个农场总人工预算。

持续补充基础料、清水和特殊原料，按实际收入再投资；本路线应验证扩至一座满容量羊圈及一座满容量水场的正常供料。数量只能通过购买新增，藻料不足可正常建设第二座培养槽/重启批次，不通过产量倍率或免费料解决。到4只/尾后的完整生产与后续补料日须有证据，不以第45天临时买满、尚未服务冒充持续经营。

本路线重点验证提前托管的现金门槛、4个体成本摊薄、水体维护和长期补料。若现有泉水额度/饲料产能/AP/现金无法支撑此路线，先报告逐日瓶颈和调整依据，修订后重跑受影响路线；不静默改数或降低验收范围。

### 2.4 每条路线都要覆盖

- 两种幼体实际育成、特殊投料、剪毛/出塘、后续羊周期及鱼重新购入，不仅完成首轮静态成本核对。
- 真实取得羊粪肥和鱼粪，各至少一次堆肥成腐殖土，并在种植上实际施肥；投入、完成和领取分日记账。
- 至少完成金、木养殖产物供货各一次，并通过正常路线覆盖五行供货；正常rank按营业收入解锁，指定rank测试不混入经营路线。
- 养殖出售/订单形成实际元石收入，之后购买种子/鱼苗/原料或建设，证明收入再投资而非只在仓库积累。
- 使用资源一览查看实际收支、关注材料并在日存档后恢复，养殖总览能定位设施，手动与负责人实际费用可查。
- 完成第15/30/45天结算、存读与回顾，续到第46天核对冻结边界；45日经营统计仍只包含首次45个完整日。

两路线比较期末元石、真实收入/支出及人工费，另列在养、库存、待收与在制差异。不能仅看期末现金判哪条“更赚钱”：托管/扩群投资时点与剩余资产不同，材料估值不加入现金利润。

## 4. 测试分层与回归范围

### 4.1 配置与模型

沿用`bake_v2.py --check`检查生成物与源数据一致，覆盖完整资源来源/消费者、成本分摊、固定价格、防采购供货套利、动物食谱/产出以及开放人数配置。终值供养值保持静态，实际手动/人工成本差异不改变已配置换算。

负责人检查一人一设施、不兼职、收取→必要修水→整体维护、单日自动至多修水一次、成功1元石、无工作0费、预算/现金不足和共享库存确定性。验证第3名及更多招聘/保存；V1仍使用自己的两人配置。四只服务算一次成功工作，个人12次/12元石是上限。

### 4.2 事务、快照与统计

三槽隔离、所属槽覆盖、未知/不支持版本提示、完整快照应用前验证及保存失败阻断均须覆盖。读档不劳动/推进/发料；失败原样重试不重复日结，放弃当天同时回退动物、周期、费用、账和关注清单。

损坏场景包括重复UID、超容量/非法进度、食谱和投入不符、周期重复权益、负责人多设施/与农务并存、账不平/日期断裂、重复/未知关注项以及45天冻结统计矛盾。使用隔离坏档夹具验证失败零改动，不接触玩家槽。

资源账逐项守恒，历史均值包含零活动日；未领不入库，采购与自产原因分开，净0含真实收支也有明细。日报最多15日与三个时节累计独立，第45天完整结算后冻结；第46天继续经营仍更新当前账和总览。关注清单初始空说明、更多、按槽保存与重载正确。
