## 2. P8.a — 数据、资源配数与事务底座

**工作：**

- 建立P8独立配置与存档命名空间，维持三槽/自动存档，保留V2显式入口与档案隔离。
- 登记6物种、8设施、38项资源/采购凭证、24有效工艺＋3变体、12研究；培养单位/幼体不重复进库存。
- 编译标准成本来源、共产品分摊和向上取整供养值；冻结新食材静态表，旧值不随回收重算。
- 审计研究DAG、样本来源、解锁建材、产物出口、液体损耗与铁份额；核实20×14陆地能安置首批设施与必要花田，资源点不可被堵占。
- 定义开日设备、手动/雇工/推进、日账冻结、次日/自动保存事务，加入实际换水污水记录；存读档不重复运行，保存失败可完整回滚。

**完成条件：**

- [ ] 配置ID/引用/数量/类别正确，研究可拓扑排序，无自锁样本。
- [ ] 成本表可复算且无环，共产品分摊和为1；新增供养值有来源，采购直交/加工交套利审计通过。
- [ ] 新旧存档隔离，三槽和失败回滚边界通过；45日快照不混入46日开日消耗。
- [ ] 布局与启动预算草案可执行；不把静态成本审计称为90日平衡验证。

## 3. P8.b — 多设施负责人、兼任与生产策略

**工作：** 将P7专责限制改为显式多设施，保留每设施唯一负责人。实现高/普通/低优先级、跨所有任务共享每日12次成功额度和个人预算、兼任默认关闭与指定范围、稳定调度与积压解释。提供目标库存、全农场在制预计量和自动投料保留量；可先用既有藻槽/木作台回归，随后接新设施。

**完成条件：**

- [ ] 一人多设施不复制额度或预算，不自动参与未授权地格/资源点。
- [ ] 重新指派/关闭兼任保留已完成工作，失败不收费，优先级及同级轮转可重复验证。
- [ ] 一次日结多机竞争原料不超扣，目标达到不再开批，在制批次仍完成。
- [ ] 保留量只挡自动加工，不阻碍手动或基础维护；UI显示实际收费与缺口。

## 4. P8.c — 研究系统与依赖导航

**工作：** 建研究台、三层12项目、样本一次扣款、暂停、有效日和手动/雇工入口，完成研究全场共享。研究图和物品获取路线使用数据驱动，保留P7默认工艺。

**完成条件：**

- [ ] 同台每日一次、同项目全场最多一在研/一完成；重复点击/存读不多推进、不二次扣费。
- [ ] 无工作暂停，费用/AP/成功工作账一致；多台可研不同项目但不能重复领解锁。
- [ ] 前置、样本、解锁及暂停原因可见；手动研究实际扣1AP，雇工实际付1元石。
- [ ] 未实施生态路线不伪造免费样本或宣布整网可经营。

## 5. P8.d — 花源、蜂群、油料与饲料

**工作：** 实装两植物、蜂箱/蜜盏蜂、供花份额与手采竞争、授粉上限；农产加工台R01～R07、油饼/废滤炭堆肥及陆养/水养食谱。T01/T02/T03/T06实际生产通路打通。

**完成条件：**

- [ ] 花期/环境/覆盖正确，日额度不因恢复水分、存读或重新配置刷新。
- [ ] 同份源不能手采又供蜂；多个蜂箱不叠加授粉，仓库花蜜不绕过花源条件。
- [ ] 群为标准单位、容量4含幼群，无免费繁殖；缺料恢复和混龄服务记录通过。
- [ ] 油、蜡、饼及复合饲料有实际消费者/出口，日粮与共产品成本能对拍。

## 6. P8.e — 水场污水、菌毯净化与藻料回流

**工作：** 净水菌床/菌毯R10/R11、木作台滤料R09、藻槽R12、污泥堆肥；独立水场状态、实际换水污水和净化维护接入研究、负责人及库存策略。

砂砾由f的R13产出；e先通过T04/R10/V02基础路线，T08/R09/R11/R12的正常经营证据在f后补齐。夹具可测进阶边界，不能据此勾选自然经营闭合。

**完成条件：**

- [ ] 空池/满状态/重复维护/失败不产污水，只有真实扣清水换水产生规定数量。
- [ ] 菌毯育成/成熟不同投入，处理缺服务暂停，清水/营养液返回小于污水投入。
- [ ] 水场彼此状态独立，鱼粪不再次复制成污泥；待收取不计清水增长。
- [ ] 旧泉水/藻料能启动新水路线，T04/T08不要求自身解锁后的样本。

## 7. P8.f — 岩兽破碎、选矿与材料回用

**工作：** 岩兽工作场、啮岩鼹/岩腹兽、R13～R18、矿质补料R08及羊食谱。建造面板支持明确选择复合石板/再生填料替代普通石材；已有直接冶炼继续可用。

产生砂砾后补e的T08研究与进阶水循环真实来源联验，记录e/f联合关闭证据；T11补光灯实际运行仍在g。

**完成条件：**

- [ ] 日粮和矿料分开扣记，单场单物种、容量与混龄正确；无矿不产矿。
- [ ] 破碎/富集/冶炼/矿质饲养的铁份额逐批不增加，尾砂/炉渣不再提铁。
- [ ] 选矿路线与直接冶炼都可经营，实际成本不遗漏育成/日粮/有效维护。
- [ ] 建材替代由玩家选择、整次预检，不暗中替换研究样本或特殊矿料。

## 8. P8.g — 自动维护、补光与五行灵食

**工作：** 田间维护站、补光灯、厨房R19～R24、T09/T10/T11/T12完整解锁；覆盖/材料/次日生效说明；资源一览与关注承接新实际流量、内部生态流及设备消耗，多设施管理可定位。

**完成条件：**

- [ ] 每格服务实际扣料；同项目重叠站不重复，每台吞吐上限与轮转正确。
- [ ] 光照不叠加，喜阴作物有提示，缺油暂停、空范围不耗油；存读不开日二次扣料。
- [ ] 五行灵食资格与燃料资格分离，厨房明确扣木炭，rank需求值不随工艺改变。
- [ ] 实际账、7日均值、成熟待收和预测分开；首45日回顾冻结后持续经营不改写。

## 9. P8.h — 90日经营、回归与交付

不注入元石、样本、物料或研究进度。两条**独立新档各90日**，从60元石开始：

1. 手动建立花源/蜂群/油料，逐步启用多设施负责人与田间装置，再补齐水循环和选矿。
2. 先经营水循环或岩石路线，以既有种植/牧渔/供货盈利，显式兼任和多设施调度，再补齐花源、高级加工。

两条都检查第45天回顾、46日继续账、第90天全部12研究、三组生态真实投入产出、五行供货、至少一批新高级灵食、收入再投资及人工费。脚本走正常生产接口并保留逐日原始台账，不能通过测试入口直接完成研究；rank1/3/5单独边界测试可指定，不用注入冒充经营解锁。

**完成条件：**

- [ ] 两路线可发展，所有研究/产业真实可达；现金与材料流、订单次数、人工工作可复算。
- [ ] 专门检查失料/抢料、研究重复、花源双用、换水刷物、水回收、矿料守恒、装置重叠与存档失败重试。
- [ ] 按变更运行P8和V2/V1/V0、历史phase00/demo selftest回归；测试入口分开，不让旧内容混入玩家流程。
- [ ] 2560×1440及已有兼容窗口/缩放做事件验证与截图审核；手动AP入口、锁定说明、覆盖、积压和危险操作清晰。
- [ ] 导出/解压Windows独立包、manifest/哈希/说明与冒烟通过；旧显式入口保留。
