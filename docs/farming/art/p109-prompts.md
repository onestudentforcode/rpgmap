# P10.9 生图与脚本建模提示词 v0.1

> **工具：** ChatGPT 图片；AI 编写 Blender Python 脚本。
> **当前状态：** 方向已确认，实际视觉母版未选定。本文已可用于首次探索；“匹配母版”的模板仅在真实母版提供后可执行。
> **相关：** [阶段计划](../phase-10.9-美术回填与母版验证.md) · [母版和空间契约](p109-master-spec.md)。
> **本轮只写提示词。** 文中的输出路径、图片和脚本名称是交付约定，不表示它们已生成。

## 0. 使用顺序与拼装方式

1. 先把 **B00** 交给能执行 Blender 的 AI，制作空间标定板；查看投影报告与图像。
2. 将无标签标定图作为空间参考，使用 **G01** 生成第一只钢绵羊候选。没有标定图也可用 G01 做审美探索，但不算机位通过。
3. 必要时用 **G02** 仅调整绘制感，得到第二张候选；向用户展示独立原图及同尺寸对比。
4. 用户选择后，保存实际图片与选择记录。用 **G10＋G11** 做采毛台，以验证跨类别风格。
5. 羊和设施共同组成选定母版；随后用 **G10＋各对象块** 制作芦苇、鲤鱼、鱼栅，逐张出图。
6. Blender 对象建模使用 **B10＋对应 B11～B15 对象块**；两部分合并为一条完整请求，同时附已选母版与标定资料。
7. 用 **R01/R02** 定向返工；成熟植物经用户接受且空间检查通过后，才启用 **G20**。

ChatGPT 图片每次请求的构成为“公共约束＋一个对象块＋本次参考角色说明”。对象块不应单独发送，否则会丢掉机位、透明、风格与背景约束。所有 `{变量}` 必须替换成真实值；生产请求有未填项时先补齐，不能让模型猜测批准结论。

“不要……”的句子是自然语言约束，不是单独的负面提示词接口。不使用权重括号、采样步数、CFG、种子锁定、ControlNet 或 IP-Adapter 开关来冒充 ChatGPT 图片可用参数。

## 1. 参考角色说明卡

下面按实际附件填写；只有一张图时删去其余行并说明缺失。不要对未附的图片写“严格参考”。

```text
本次输入图片的角色：
图1＝空间标定参考，仅规定正交机位、地面方向、尺度关系与接触方式。
图2＝用户选中的风格母版，版本{STYLE_VERSION}，规定体积、用色、边缘、笔触与材料语言。
图3＝同一对象的身份母版，规定轮廓、器官/构件数量、比例和标志性特征。
图4＝本次需要修改的上一版图片，只有它是编辑目标。
如果角色由同一张图承担，具体为：{ROLE_MAPPING}。
本次缺失的角色：{MISSING_ROLES_OR_NONE}。
遇到身份、机位与风格参考互相冲突时，请先说明冲突；不要把不同相机混合成新视角。
```

## 2. G01：首次钢绵羊母版探索（完整提示词，可直接使用）

```text
请生成一张用于东方仙侠生态经营游戏《灵田》的独立动物美术候选。
这是尚未冻结的母版探索，不代表已确定的正式画风。对象是“钢绵羊”，内部标识steel_sheep。

【画面任务】
只画一只成年、健康、安静站立的羊，完整全身，固定朝向，头朝画面右侧。
这是可放入俯视经营地图的静态世界物件；不做海报、场景插画、头像、图标框或动画表。
采用清淡雅致的仙侠生态风：三维体积明确，表面有克制的绘制感，形体柔和但结构清楚。

【造型候选】
羊的躯干厚实、头与身体比例自然且略作概括，四条腿结构可信，站立重心稳定。
羊毛组织为连贯的几大体块和少量方向明确的毛束；毛团之间有柔和转折，不做等大的球粒堆。
“钢”的身份用浅青灰/暖银灰毛色、较结实的蹄部、少量有韧性的毛束形态暗示。
整体仍是温和的活体羊，不改成机械羊、盔甲羊、刺猬、岩石雕塑或金属玩具。
角、耳、眼、鼻、尾采用简洁可信的羊类结构；角形属于本次待审候选，选定后后续版本必须保持。
不得增加鞍具、服装、项链、铃铛、法器或背景道具。

【机位和空间】
正交视图，相机俯角为相对水平面35度，无广角透视、近大远小或镜头倾斜。
地图地面横向边水平，纵深边在屏幕竖直方向压缩；不将地格旋转成菱形。
看得到羊背和朝向相机的一侧，羊身体自身可有转折，不能为了展示正脸另换相机。
四足落在同一地面，接触中心明确；耳、角、尾、腿全部留在画布内。
如果本条请求附有空间标定图，只参考其机位、方向、体积比例，不复制灰模材料和标尺。
如果未附标定图，按上述条件做候选；不能声称已准确匹配游戏相机，后续还会校准。

【色彩和光照】
主要颜色为暖米白、浅银灰和低饱和青灰，少量较深暖灰用于蹄部、面部和体块分离。
气质清淡雅致，但不能全身苍白到与浅草地无法区分；明暗至少能读出受光、转折和遮蔽三层。
主光来自画面左上，柔和、宽阔；保留体积，不使用全身均匀泛白的照明。
表面高光克制，不做镜面、湿亮塑料、强轮廓光、舞台射灯或耀眼灵光。
毛面有柔和的色块组织，内部小细节服从大形，不使用密集噪点或全图油画滤镜。

【背景与交付】
主体独立，真实透明背景，保留平滑alpha边缘。
不要棋盘格图案、白底、灰底、草地、土台、浮岛、站台、水印、文字或标签。
保留主体自身的明暗和局部遮蔽，不绘制落在地面上的大投影；统一接地影将在游戏中另层处理。
画布周围留适量透明空间，主体清晰且不裁切；单张图只有这一只羊，不并排多种角度或多个方案。
优先保证实际游戏显示尺寸下的轮廓、材质和器官识别，再提供放大可看的细节。
```

候选图生成后检查：是不是活体羊、毛是否像毛、机位是否可信、正常尺寸是否可读。批准前不把 `style_master` 写入下一条请求。

## 3. G02：第二方向候选，只改变绘制感

输入：上一张羊作为唯一编辑目标；标定图如有则另附。

```text
请编辑附图中的同一只钢绵羊，制作第二个画法候选。
只允许改变表面绘制感：将现在的平滑三维表面调整为更明确但克制的手绘色块和柔和笔触。
保持羊的轮廓、大小、四肢位置、角/耳/尾形、相机俯角、朝向、光向、毛色分区、原画布及接触点不变。
仍然要有扎实的体积，不变成平面贴纸；不要用粗描边、画布噪声或满面笔刷纹理替代材料结构。
维持清淡雅致、暖米白与浅青灰；不增加饱和度、花纹、装饰或全身金属感。
保留真实透明背景和完整主体。不要制作对比拼图，只输出编辑后的独立羊图。
```

若用户要求相反方向，可把唯一变更替换为“减弱可见笔触，保留材料色块，提高柔和体积的连续性”。其余约束原样保留。

## 4. G10：选定母版后的生图公共约束

**启用条件：实际选中母版已附图；不得仅填写一个版本号。**

```text
请为《灵田》制作一件独立的非像素2D游戏资产。本次对象与允许变化范围见后面的对象块。

【母版一致性】
严格沿用已附、已选中的{STYLE_VERSION}母版的视觉语言：清淡雅致，体积明确，表面有适度绘制感。
匹配母版的大中小形关系、边缘软硬、明暗层次、主光方向、材料高光宽度、细节密度与色彩克制度。
参考物种的毛发不能直接变成木材或植物的表面纹理；继承绘画语言，各材料仍须表现各自结构。
不得给新物件另换成摄影写实、像素画、粗描边卡通、低模切面或亮面塑料风。
本次如果有身份母版，保留其已确认的{IDENTITY_SIGNATURES}；不借“优化”改变身份。

【空间】
使用附图的35度正交机位，相对水平面35度，无相机横滚、透视收缩或地面45度旋转。
地面逻辑横轴水平、纵轴竖向压缩；1格的显示比例约为64宽、36.71深。
主体竖直高度保持正确投影，不把整张主体压成地面比例。
对象朝向、占地、接触点、外伸范围、状态均以对象块为准。
看清顶部与近侧面的比例须与标定图一致，不能为了多展示一个侧面而改变机位。

【形体和材料】
先保证完整、明确、好识别的轮廓，再用主要部件解释功能。
材质通过色块、转折、边缘与少量纹理区分，避免靠高频噪点制造精致感。
主光统一来自画面左上，体积阴影柔和、透明外边缘干净。
自身遮蔽可保留；地面大投影、水面效果、状态角标与选中框均由独立层处理。

【颜色】
匹配选中母版的实际颜色关系。自然灰绿、暖米、青灰、淡木棕为基础；功能重点少量使用玉青或旧铜色。
清淡不等于全部接近白色：保留必要深部，使轮廓在现有浅草地、水色和纸色背景上可辨。
不整体拉高饱和度，不新增荧光色、纯黑描边、大面积金色或发光符文。

【输出】
仅输出对象块指定的一件主体/一个状态，真实RGBA透明背景，不画棋盘格或色底。
原始画布建议{CANVAS_SUGGESTION}；完整主体和约定根部不得裁掉，边缘留合理透明空间。
实际像素尺寸和根点由后续导出检查，不能用“看起来合适”替代。
不得添加文字、标志、数字、边框、背景风景、随机道具、展示台或多角度图。
不把地面、池水、接地投影或操作标记粘进主体；仅保留对象自身确实存在的结构。
```

## 5. G11：采毛台对象块

用途：跟随选中羊图检验硬表面语言。具体构件是本轮设计候选，第一次选中后登记身份特征。

```text
【对象】采毛台，wool_station，陆地设施，游戏占地1×1。
【状态】空载、静态、健康可用；不把羊、工作人员、产物图标或工作特效烘焙进去。
【结构候选】低矮稳固的木制工作台，清晰台面、厚度适当的木梁与脚架，少量青灰石脚或金属连接件。
一个与台体相连的简洁梳毛工具架，以及一个固定在台侧、可辨识的浅收纳槽，作为功能特征。
工具与容器不能大量堆叠；不增加屋顶、院墙、传送带、机械臂、蒸汽动力或装饰花园。
【材料】主体浅旧木棕，接缝略深，石脚青灰，金属为克制的暖灰铁或旧铜；最多一个小面积材料重点。
【形体】保留足够的台面厚度和倒角，脚与台面连接可信；横梁有形，不像几根无厚度线条。
【占地】四脚/基础落在一个逻辑格内；少量上层工具外伸可接受，但不扩成2×2庭院。
【镜头】与羊的空间标定一致。台面边沿匹配逻辑横纵方向，不额外旋成菱形等距台。
【根点】台体占地中心的地面投影点；无独立整块土台或大石板底座。
【读图重点】正常游戏尺寸能看出“木台＋梳理工具＋收纳槽”，不依靠文字说明功能。
【画布建议】方形高分辨率透明候选，最终尺寸与根点在导出时登记。
```

## 6. G12：成熟芦苇对象块

```text
【对象】芦苇，reed，水生作物，根部玩法占地1×1。
【本次仅做】成熟期一丛。不要幼苗、生长期、采后、枯萎形态或多阶段拼图。
【结构候选】一丛有前后层次的芦苇，少量主要竖茎构成疏密节奏，长而略弯的叶片形成中等大小形块。
成熟穗为低饱和浅米金/灰褐色，形态蓬松但简化；茎叶灰绿，叶片有明确着生点和朝向。
避免杆杆等高、等距、同角度；也不要生成碎密到缩小后只剩噪点的草堆。
【身份】保留芦苇的高茎、狭长叶与成熟穗；不变成小麦、香蒲棒、竹林、荷花或装饰花束。
【接触】根部集中在合法占地内，下端有清晰的水面接触高度；水面线本身不烘焙进主体。
不画池水方块、水纹、圆形水盘、泥土团、花盆、岸边碎石或倒影。
【体积和颜色】遵循选中母版的柔和转折与细节密度；穗部不纯白，深部不纯黑；茎叶与浅青水面可区分。
【尺度】根部占地是1×1，叶尖可以有限外伸；高度由标定图与同屏样板协调，不为填满画布无限拉长。
【画布建议】竖向透明画布，完整保留穗尖、叶尖与根部接触点。
```

## 7. G13：滤藻鲤对象块

```text
【对象】滤藻鲤，filter_algae_carp，一条成年、健康、静态鱼。
【姿态】身体自然舒展、近水平，头朝屏幕右侧；不跳出水面、不翻肚、不做游动帧表。
【结构候选】清晰的鲤鱼身体轮廓，头腹尾比例可信，尾鳍和主要胸/背鳍可辨。

【画布建议】横向或方形透明候选，所有鳍和尾端完整，留白不改变最终显示尺度。
```

## 8. G14：鱼栅材质与单模块对象块

精确拼接优先用 B14 建模；本模板用于已给结构参考上的表面语言验证。每次只指定一个模块，不请求生成整座池塘后拆分。

```text
【对象】鱼栅的{SEGMENT_ID}模块，用于水域真实地格边界。
本次仅生成{MODULE_DESCRIPTION}。结构参考已经规定端点、立柱位置、横梁数量和水面高度。
【结构】严格保持参考图的轮廓、端点和连接位置，只按母版改善材料与绘制感。
候选材料为浅旧木/竹质框与少量绑扎或金属连接，构造紧凑，水面以下部分不自行无限延伸。
不增加无法与邻段接续的斜杆，不新增装饰挂件、牌匾、绳网团或随机柱子。
【接触】立柱与水面接触的高度遵循结构图；水纹、水体底色、阴影和边界高亮另层处理。
【投影】保持固定35度正交机位；横向段和纵向段必须由对应结构图分别约束，不把同一张图直接旋转90度冒充另一方向。
【输出】单个模块，真实透明背景；不画封闭方池、岸边草地、鱼、整片水或网格文字。
端点不得被柔化、裁切或随机改变长度。外观改善若与端点精度冲突，优先保留端点。
```

## 9. G15：第二轮复现对象块

两项分别请求，均与 G10 合用。未通过第一轮样板前，不批量启动。

```text
【对象】蚕架，silkworm_rack，陆地1×1，空载静态设施。
沿用已选采毛台的木材、连接件、边缘和光照语言，设计一架低矮、稳定、分层清楚的养蚕架。
```
