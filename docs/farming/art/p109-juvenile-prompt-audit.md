# P10.9 幼体提示词核查

2026-10-22：用户指出动物幼体与成体缺乏区别。暂停后续批量生图，现有11张幼体标记为需要修正年龄差异，不能算作已验收。

## 核查结果

- 11张已归档幼体PNG与各自成体的SHA256均不同，没有把成体文件直接复制为幼体。
- 其中9种保存了本轮成体生图原始提示词，逐字比较均与幼体提示词不同。钢绵羊与滤藻鲤沿用了已选原图，不能把本轮不存在的成体请求作为文本比较依据。
- 幼体请求都直接使用对应成体图作为参考，没有误用成体提示词中的“只做成年/成熟”指令。
- 但幼体请求反复强调保留成体解剖、轮廓、材质，年龄差异主要依赖“约为成体60%”“更短的角/腿”“年轻比例”。这不足以强制模型改变年龄形态。

实际例子：钢绵羊提示词只要求 `around 60 percent adult body size, shorter legs and smaller curled horns`；矿鳞蜥只要求 `around 60 percent adult length ... sparse tiny pale mineral scales ... youthful proportions`。输出中成年盘角、成片成熟鳞甲等特征仍占主导，视觉上接近成体重绘。

## 后续修正原则

1. 幼体必须依靠头身比例、躯干厚度、口鼻长度、角/鳞甲/壳等器官发育程度区分；缩放不能作为唯一年龄差异。
2. 明确区分保留项（物种、配色、材质语言、机位）与必须改变项（年龄形态、器官大小与密度）；禁止保留成年轮廓。
3. 对每个物种写可观察的幼体形态。例如钢绵羊使用短小角芽、较大头部、短圆口鼻、纤细躯干、短绒与少量金属毛尖；矿鳞蜥使用较大头部、纤细躯干、未成片的小鳞芽，不能仍是完整成年大片矿鳞。
4. 每个物种的个体/群体表达与已验收成体保持一致；不能用增加个体数量来代替年龄变化。
5. 已出图保留供核查，未修正前不接入运行场景。此次核查没有重新生成图片。
