# P8.7投影与阴影指导

2026-10-15定版。沿用[P8.6色板](p86-visual-direction.md)的明亮柔和、灰茶绿/暖土/谷金，不新增全场调色。本阶段用空间关系与接触层改善接地。

| 部分 | 定版约定 | 审阅重点 |
|---|---|---|
| 地面 | 35°正交俯角；逻辑64×64，显示约64×36.71；不水平旋转 | 耕地、占地、水岸及操作格对应 |
| 主体 | 原完整PNG/alpha/mipmap，按统一32显示单位/Blender单位定位 | 主体不随地面纵向压扁，根点位于模型地面原点 |
| 根点 | 占地中心；按实际地面深度排序 | 树木/设施邻接不按立绘下边或高度排序 |
| 接触阴影 | 暖深色`#4a4938`，陆地原透明度×1.12、上限0.27 | 根部清楚，密植不形成黑团；资源接触尺寸跟随校准标尺 |
| 柔和投影 | 同一右下方向；树木随阶段增加，设施和矿石保持轻量 | 投影透明度约0.065～0.115，全部在主体之前绘制 |
| 水域 | 保留透明中心的水色接触环 | 水场和泉眼不增加陆地投影；幼苗stage_0不叠加投影 |
| 屏幕标记/UI | 保持字号与图标原比例，位置跟随地面映射 | 侧栏和工具栏留出可操作空间 |

禁止把整张世界图纵向压扁、按alpha包围盒填满地格、重复压缩已投影阴影，或用不透明灰地板替代接地。校准源见[p87-camera-calibration.json](p87-camera-calibration.json)，配置在`p87_projection.json`与`p87_shadows.json`。

用户先接受35°A样板；全量画面反馈为“适当补充一些阴影，最终画面基本上接受”。上述阴影补充已实现，并重新进行代理GPU审阅、专项及独立包验证；不声称用户另外逐图审阅过补影后的60张画面。
