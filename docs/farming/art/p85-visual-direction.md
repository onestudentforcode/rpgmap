# P8.5 同屏美术指导

沿用已确定的明亮柔和方向：灰茶绿植株、谷金与蜜桃器官、暖土和浅石板。建模造型与材质保持源母版；主体有体积，地面承担低对比背景。

| 层次 | 方向 | P8地形中间调 | 用途 |
|---|---|---|---|
| 草地 | 柔和灰绿 | `#a4ba91` | 主要环境背景，减少旧纹理的高频噪声 |
| 泥土 | 温暖浅褐 | `#b9a183` | 区分原始土区，避免金穗麦被土粒抢走注意力 |
| 石板 | 浅灰橄榄 | `#b4b7a7` | 保留不可耕边界，与建筑基座相容 |
| 耕地 | 深暖灰褐 | `#998a71` | 明度低于未耕土，让新播种区能辨识 |
| 主体 | 继承建模母版 | 不统一染色 | 用轮廓、生产器官和成熟标记识别 |

P8地形层使用跨地格连续的平滑噪声，原纹理RGB权重为0，保留原alpha和拼接。草地采用低对比宽幅起伏与细纹，泥土和石板进一步压低细节；耕地使用极浅圆润垄沟，避免旧像素颗粒与硬横条。灰绿/暖土配色保持上述中间调。水库及UI不调色，旧V1/V2保持原地形表现；不改源图、不量化、不改变地格。参数独立于UI令牌，存放于 `content/farming/p8/world_visuals.json`。

用户已拒绝第一版40%旧纹理混合，并明确要求「改材质风格，减少像素噪声和耕地条纹」；第二版平滑纹理又被反馈为过于平滑。当前补回大小、方向与疏密有变化的草叶短纹，以及圆润土粒/低对比石纹，提供两种细节强度对照，尚未定版。见[地面材质计划](p85-ground-material-plan.md)。保留的旧alpha边界仍有像素轮廓；本次材质调整不代表地形过渡图已全面重绘。

运行图以Blender重新渲染提高分辨率，小植物256²、树512×768、单格设施256²、双格设施512²。画布归一根点和逻辑显示尺度不变；不按阶段单独裁边、放大或锐化。采后整图与设施工作特效未交付的状态用既有标记表达。

验收：在实际游戏截图中比较彩色与灰度层次；主体轮廓应高于背景噪声，耕地与草地仍可区分。密种时选中边框/成熟点/再生圈和任务标记最后画；UI文字沿用已验收令牌。禁止全场拉高饱和、白底抠图、把总览当SpriteSheet或把烘焙地板合进主体。

Shader保留顶点调制色与原纹理alpha，具体COLOR/TEXTURE语义参考[Godot CanvasItem官方文档](https://docs.godotengine.org/en/stable/tutorials/shaders/shader_reference/canvas_item_shader.html#color-and-texture)。
