### 2.2 其他资产与钢绵羊的关系

钢绵羊是已选身份与世界材料参考，不要求其余对象复制偏写实的微纹理。其他对象继承柔和体积、清雅色彩和局部特殊材料的设计方式，同时进一步概括表面。下一张采毛台用于检验跨类别协调，不能把羊的选择扩大成全部资产画风已批准。

奇幻感优先落实到少量、有功能或生态联系的形态/材料：云梳形工具、温润玉质叶面、轻柔舒展的鳍尾等均是候选。每件对象一个主要重点；玉质、珠光不默认自发光。允许适量玉青、淡藕紫点色，不通过全场高饱和、悬浮粒子或法阵制造奇幻。

| 维度 | 候选语言 | 检查方法 |
| --- | --- | --- |
| 形体 | 大形完整，中形解释功能；适度夸张、卷曲和舒展，关键器官/工具可辨 | 缩到实际显示尺寸、看纯轮廓 |
| 体积 | 清晰受光面/转折面/遮蔽面，过渡柔和且不浑浊 | 灰度、相邻材料接缝 |
| 表面 | 其他对象减少写实微纹理，宽色面与简化细节表达材料；羊保留已选版本 | 不用摄影纹理、细密毛丝或全图模糊制造“精致/手绘” |
| 边缘 | 主轮廓明确，内部转折柔和；草叶和毛缘有选择地简化 | 深浅背景检查边缘和缩放后的闪烁 |
| 配色 | 灰茶绿、暖米色、青灰、淡木棕为主体；少量低饱和金属色 | 与现有草地/水面并置；不把主体全部压成同一浅灰 |

| 状态 | 统一的独立角标、描边或叠层 | 不改变健康母版的永久外观 |

## 5. 空间契约

依据：`content/farming/p8/p87_projection.json`、[P8.7 指导](p87-projection-direction.md)、`p87-camera-calibration.json` 的现行坐标事实。旧校准报告自身状态保留，不借用其历史状态宣称 P10.9 已批准。

| 项目 | 约定 |
| --- | --- |
| 相机 | 正交；俯角相对水平面35°，不是相对竖直轴35°；无相机横滚 |
| 设施朝向 | 建筑/设施正面朝镜头，沿正面中轴俯看；相对地图轴绕竖直轴偏转0°，不作三分之四斜角展示 |
| 设施屏幕线向 | 矩形台面/地基前后横边水平、纵深边竖直，立柱竖直；各附件同轴；曲线装饰与真实斜撑除外 |
| 地面 | Blender XY，Z向上；正方格沿逻辑轴排列，不做水平45°旋转 |
| 轴映射 | Blender `-X` → 逻辑横轴/屏幕向右；`+Y` → 逻辑纵轴/屏幕向下 |
| 尺度 | 每逻辑格64单位；每格2 Blender单位；每 Blender单位32显示单位 |
| 地面投影 | 一格约64×36.7089显示单位；`sin(35°)=0.573576` |
| 高度投影 | 1 Blender单位竖直高度约26.2129显示单位；主体不随地面再次压扁 |
| 根点 | 设施/作物以逻辑占地中心的地面点为根；动物用四足接触中心，鱼用定义的水面投影参考点 |
| 光向 | 屏幕左上柔和主光；大范围投影向右下，由统一接地/投影层管理 |
| 朝向 | 相机固定；羊按已选图头朝屏幕右，鱼暂建议同向；模型在统一渲染时校准整体朝向 |

以模型原点为基准，忽略屏幕平移时，校准目标为：

```text
view_x = -32 * X
view_y = 32 * sin(35°) * Y - 32 * cos(35°) * Z
```

可用相机位置 `(0, d*cos(35°), target_z+d*sin(35°))` 朝向 `(0,0,target_z)` 起步，镜头局部 `-Z` 看目标、局部 `Y` 向上；最终必须用投影测试点检查轴符号和比例。相机距离 `d` 不改变正交比例，输出构图由目标点、正交范围和画布决定；不要通过旋转相机改善某件物体的外观。

具体画布、目标点/留白可以因对象高度不同而不同，但世界到屏幕尺度和方向须一致。记录根点 UV 和绘制尺寸，让画布变化不影响物体大小。

### 5.1 建筑/设施正面轴对齐补充（2026-10-22）

**全类别强制适用。** 所有现有和未来建筑/设施、陆地与水产设施、大小占地、各级与各状态版本均继承此规则。每次生图请求必附[提示词H00](p109-prompts.md)，按H01的类别检查；不能只在采毛台/蚕架的对象块中写，也不能靠“沿用上次视角”省略。

用户指出采毛台候选呈斜角，与既有横平竖直的建筑/设施不匹配。此前仅约束俯角和地面未充分约束设施自身绕竖直轴的旋转；正交镜头同样可以拍出斜转物体。

设施的前后横向结构沿模型X轴、纵深沿Y轴、直立沿Z轴，正面朝相机所在的+Y方向，整体不额外绕Z旋转。根据现行投影，X边投影为水平，Y边与Z边投影均为竖直（长度及正负方向不同）。矩形台面因此呈轴对齐的压缩矩形，主要显示顶面和正面，不额外展示大面积左右侧面。不是将相机改成90°正俯视。

台面、梳毛架、横梁、台脚与托槽遵循同一朝向；不能为多展示侧面而单独旋转某部件。弯曲梳齿、云纹、叶形构件可保留设计曲线，规则只约束主体结构轴。羊、鱼和植物不强行变成横竖轮廓。

当前采毛台图为待修正的造型候选，未批准为设施空间母版。修正应整体重投影，允许遮挡/轮廓改变，保持身份与材料；不得把二维成图旋转或扭曲来伪装校准。见提示词R02。即使图生3D能在最终渲染纠正朝向，生图模板也要明确这条要求，以便直接同屏比较。

按类别判断，不能把“画出一个矩形台面”当成所有设施的共同结构：

- 工作台/柜箱：台边、框架、门窗及已有功能面正向；附件同轴。
- 圆形炉、罐、池、巢窝：水平圆口的投影椭圆长轴水平、短轴竖直；有既定入口时朝正面，无入口不新增；完全轴对称物件核查模型主轴。
- 棚架/房屋/多层架：墙脚、门框、檐口和层板轴对齐；屋面真实坡线、斜撑和曲线饰件可有斜线，不因此旋转整体。
- 床组/食槽：长边沿已定横轴或纵轴，组内同轴，不斜摆或扇形展开。
- 灯柱/农业站：支撑竖直、底部占地轴向不变，定向功能构件不带动相机转角。
- 水产台/站：水上平台仍同轴，不因介质改成俯视或斜角码头展示。
- 围栏/鱼栅：横段水平、纵深段竖直，接角共享同一投影；不能旋转成图代替方向正确的模型投影。

H01已按当前内容完整列出39个设施定义（含退役保留的水场）；未来新增条目自动继承。此覆盖仅规范视角，不扩大全量回填范围，不为检查视角给圆体强加方底座。视角错误的任何类别均先修正，不能因材质或造型好看跳过。

## 6. 标定板与参考角色

空间检查沿用既有P8.7投影和实际相机数值。必要时可用简单几何标尺复核，不将其列为脚本从零建模生产的前置。图生3D结果导入后调整整体尺度、朝向、根点与统一相机；图片中的角度描述不代替最终渲染验证。技术标尺与文字不进入资产图。

参考角色固定区分：

- `camera_reference`：只规定空间、尺度、接触；灰模不规定材质风格。
- `style_master`：规定绘制语言、材料、色彩与光照，不强制复制参考主体。
- `identity_master`：规定同一对象的轮廓、器官/构件、比例与辨识特征。
- `edit_target`：本次唯一需要修改的图片。

一张图可承担两个角色，但要明确说明。钢绵羊已有已选身份参考；其他类别初创时没有自己的已选母版，仍标记为探索。引用羊图时明确只继承哪些因素、哪些写实表面因素需要降低，不要求模型盲目复制整张图的画法。

## 7. 各类资产的空间与文件边界

### 7.1 生物与植物

动物尺寸由代表性的真实显示样板确定，羊的“2空间”不是2格精灵矩形。四足/鱼体结构保持正常；静态姿态不隐藏全部腿或尾鳍。鱼可以置于单独水色层下，避免把水面方块烘焙进鱼图。

植物只出成熟期；芦苇为1×1根部占地，果桑树为2×2。树冠/叶片允许合理外扩，根部和拾取区域仍按游戏定义。采集次数或再生状态不由画面新增器官决定。

### 7.2 设施与鱼栅

采毛台、蚕架、捕鲤台均为1×1，结构基础应适配2×2 Blender单位。少量上层外伸需同屏验证，不可为塞下漂亮庭院而改占地。

鱼栅是由真实地格集合确定的边界，不是固定方形池模型。横向段、纵向段、端点/转角应能复用；原点、端点坐标和遮挡分段固定。水体底色、状态色和岸线接触分开，不重新画一整幅湖面插画。

### 7.3 文件建议

候选图片优先使用工具支持的清晰输出；1024方形可作单体审阅建议，竖长物件按比例选择更高画布。它不等于最终贴图尺寸。进入运行清单前核对现有 `canvas_px/draw_size/anchor_uv`，不要统一缩成64×64。

主体采用真正RGBA透明底，连续alpha；保留柔和轮廓，不套历史像素二值alpha规则。无白边/黑边/棋盘格伪背景。原始候选、修整版和运行版分别保存，记录裁切/缩放与根点变换。非像素运行设置沿用 Linear 与 mipmap，实际导入仍以接入检查为准。

主体可以保留自身明暗和局部遮蔽；地面大投影、接触影、水环、状态标记分层。不要同时在主体和引擎叠加同一份阴影。

## 9. 返工原则

一次只改变一个问题类别：机位、轮廓、材质、配色、边缘或状态。返工附上一版作为编辑目标，重复列明其余不变项。关键根点和投影存在偏差时先修结构，不靠加阴影或调饱和掩盖。

某项语义修图连续不能稳定保持结构时，记录问题并改用模型/人工修绘约束；不要将“再多生成几次”写成已证明有效的量产方案。

## 10. 当前制作路线
