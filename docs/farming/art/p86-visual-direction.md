# P8.6 同屏美术指导

方向：用户已接受的35°正交物件、矩形地格、明亮柔和。灰茶绿与暖土承担环境，谷金、蜜桃及青釉器官突出交互主体。世界与UI分别管理色板。

| 层次 | 中间调/令牌 | 用途 |
|---|---|---|
| 草地 | `#94ad7f` | 连续世界纹理、疏密有变化草叶，保持低对比 |
| 裸土 | `#b0987a` | 暖土颗粒，区别已耕区域 |
| 耕地 | `#8c795f` | 明度低于裸土，幼苗轮廓可见 |
| 石面 | `#a9af9e` | 浅灰橄榄，低对比石纹 |
| 水域 | `#8fb7ae` | 灰青静态波纹，岸线负责湿边/接触层次 |
| 接触 | 陆地`#4a4938`、水域`#507d78` | 缓存柔边，按物种/阶段/设施配置透明度和面积 |
| UI | 纸`#fbfaf3`、卡片`#f1f0e5`、边界`#c7ceba` | 保留原导航和布局，以面层次与主体缩略图协调 |
| 正文/辅助 | `#334238` / `#58665a` | 与面板对比度至少4.5:1，状态保留文本/形状提示 |

明度参考坡道：草地`#536447 → #72875e → #94ad7f → #b2c39b → #d3dfbc`；水域`#507d78 → #709d95 → #8fb7ae → #b7cdc0 → #d8e4d5`。坡道用于后续材质层次，不整体覆盖主体母版色。

接地层先于所有主体；主体按真实地面根点排序；成熟/再生/派工/选择最后画。鱼塘采用透明中心的水色接触环。根点、画布和64单位玩法占地分开，世界图不按bbox塞满格子；仅UI缩略图裁去统一留白。

幼苗通过叶宽/茎径/器官展开修形，四阶段保持成长差异。RGBA连续alpha、透明边修正、Linear+mipmap适用于本批非像素资产；旧V0/V1/V2继续各自规范。

验证顺序：默认1.0识别空格/幼苗/成熟；3.0看边缘、邻接和岸线；0.1只看概览。彩色与灰度同镜头比较，浅中深背景合成检查毛边；全屏色彩丰富度不作审美硬阈值。禁止全场拉饱和、像素alpha配平滑RGB、整块灰底替代接触阴影、大面积发光及用装饰填满经营空地。

用户证据：A样板后明确回复「效果验收通过，继续完成」。全量新增部分由代理在实际三窗口GPU画面和独立包中复核，未伪称用户逐图复审。
