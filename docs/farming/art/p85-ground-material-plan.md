# P8.5 地面材质迭代计划

日期：2026-10-14。范围：P8.5.e；状态：e1规格及e2对照试样已完成，待用户选择，尚未定版。

用户反馈：第一版需要减少像素噪声和耕地条纹；第二版地面过于平滑。目标是在建模植物和设施周围补回自然材质感，并控制高频细节及重复横条。配色继续沿用灰绿草地、暖土、浅石面。

| 地面 | 目标细节 | 禁止表现 |
|---|---|---|
| 草地 | 疏密有变化的草叶短纹、宽幅柔和色差 | 整格重复噪点、密集高对比草线 |
| 裸土 | 大小/明暗有变化的圆润细土粒、轻微起伏 | 均匀点阵、硬像素颗粒 |
| 耕地 | 细土粒为主，极浅且断续的垄沟 | 连续抢眼横条、整块平涂 |
| 石面 | 低对比细纹及少量颗粒，与建筑基座协调 | 高对比裂缝、抢主体的光斑 |

## 分阶段

1. **e1规格**：固定上述细节语言及现有色值。保留地格、经营/存档和UI规则。
2. **e2试样**：同一夹具制作A（细节适中，强度0.65）和B（细节稍丰富，强度1.0），分别检查默认/最大缩放；截图之外记录GPU日志。比较后由用户选择或指出剩余问题。
3. **e3全场验收**：选定版本后补密种、混种、设施邻接、负坐标扩地及三个窗口尺寸。检查可辨性与接缝；旧alpha边缘单独判断，必要时再做局部边缘调整。
4. **f收尾**：材质试样、定版接入、发布收尾分批提交。适当回归后重建独立Windows包；验收未完成前不关闭P8.5。

## 实现与证据

植物和设施继续用Blender离线渲染透明PNG；地面试样用P8专用Shader，沿用旧atlas的alpha与拼接，只替换RGB细节。纹理位置使用世界坐标，避免每64单位重置图案；草叶/土粒采用平滑轮廓，缩放使用导数抗锯齿。旧V1/V2与水面不受此材质控制。

试样截图：`.art-work/p85-ground-candidates/A/`、`B/`。场景含真实开垦/种植/建造操作，研究、材料和目标成熟状态为夹具，不代表自然经营进度。通过`--ground-detail=`覆盖视觉强度，不写生产数据。

接受标准：默认缩放能看到材质差异而不抢主体；最大缩放有自然细节、不露硬像素噪点与明显重复横条；幼苗、选择框、成熟标记仍清楚。截图检查与用户接受分别记录。

e2验证：A/B各10张GPU截图，20张实际尺寸均为2560×1440，两份日志均含`P85 VISUAL PREVIEW OK`且无脚本/Shader错误。已查看默认/最大缩放对照；草叶与土粒可见，横条不再主导地面。用户选择待记录，本检查不能替代画面接受。
