# 灵田 Demo 操作说明

解压 Windows x64 压缩包，双击 `LingTianDemo.exe` 即可开始，不需要安装 Godot。选择“新游戏”和一个存档槽；已有进度可在“继续游戏”中选择。

## 自由经营

初始有60元石与四类种子。没有必须完成的任务，可以种植凝露草、赤纹果、青玉果树和月华菇，出售收获赚取元石，也可留下木属性食材喂养测试蛊虫。首次45天结束时显示经营回顾，之后仍可继续经营；Esc菜单可重看记录。

## 操作

| 操作 | 方法 |
|---|---|
| 开垦、播种、采收 | 点击底部工具和种子选择框，再左键点击地格 |
| 切换种子 | 下拉框或数字1～4 |
| 更换工具 | 点击工具按钮，或H轮换 |
| 准备介质 | 选择地格后B；月华菇需要购买菌床材料，树木占2×2土壤地格 |
| 行囊、集市、喂养、工具购买 | 点击“行囊 / 集市”或M |
| 休息过日 | 点击“休息”或R；行动点耗尽也会自动过日 |
| 菜单、设置、教学与经营记录 | Esc |
| 移动与缩放视野 | WASD、方向键和鼠标滚轮 |

成熟作物可以收获。赤纹果和青玉果树能有限次再生，枯竭后用锄头清理。初次可跟随顶部提示；随时可跳过或从菜单重看教学。

高级锄头、播种器和采收器需在集市的工具页永久购买。每种工具仍只占一个栏位，可切换普通/高级；高级操作以鼠标地格为中心覆盖3×3，成功操作的行动点总成本减半并向上取整。无效目标会跳过，种子、材料或行动点不足时停止。

木蛊饱食度上限6，每日降低1。只有饱食度为0时才能喂养，成功后恢复到6；界面会显示食材需求数量。出售前可以留一些食材。

## 保存与设置

三个存档槽互相独立，每日结束自动保存到本次游戏所属槽。游戏没有手动存档按钮。返回菜单或退出时，可以选择结束当天保存、放弃当天进度或取消；放弃会丢弃上次日存档后的行动。覆盖和删除已有槽均需确认。

设置支持窗口/全屏、分辨率、帧率与FPS显示，重启后恢复。无音乐和音效，音量尚未启用。

## 本版范围与限制

- 单张农场、四种木属性植物；没有角色、战斗、摊位、畜牧、水产或土地扩容。
- 蛊虫仅演示饱食度和食材消费；实际战斗使用由上游游戏后续接入。
- 只记录首轮45天，不自动生成下一轮报告。当前价格为试玩初值，尚待个人自由试玩反馈。
- 存档保存在 Windows 用户目录，与解压目录分离；更换压缩包不会清空进度。

开发者排查位置：`%APPDATA%\Godot\app_userdata\Sisyphus Mall MVP\farm_demo_slots`；显示设置为同目录的 `farm_demo_settings.cfg`。旧应用目录名保留以兼容已有进度。
