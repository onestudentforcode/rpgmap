# Phase 8.f — 岩兽选矿及材料回用

> 日期：2026-10-11。状态：**已实施并验收通过（含P8.e进阶水路线联验；见§7执行记录）。** 前置：[P8.a](phase-08a-数据配数与事务底座.md)～[P8.e](phase-08e-污水净化与藻料回流.md)，其中T06样本来自[P8.d](phase-08d-花源蜂群及油料饲料.md)。配数/铁份额：[资源表](phase-08-资源与工艺表.md)§2/5～6。下游：[P8.g](phase-08g-自动维护补光及五行灵食.md)。

## 1. 目标和范围

啮岩鼹用菌菇/水维持，处理普通石材或铁矿；岩腹兽用草料/水维持，处理碎矿得到富集矿砂及尾砂。旧冶炼炉加工富集矿砂，木作台加工石板/再生填料，农产加工台制矿质补料给羊。只做普通石材/铁矿，不做石灰岩、多金属、自动采矿建筑或挖掘地图。

本阶段新增岩兽工作场与两物种，负责R08、R13～R18及羊矿质食谱，正常经营完成T05/T07/T11。补光灯虽由T11解锁，运行/界面留g，不记为f已交付设备。

R13砂砾出现后补P8.e的T08、R09/R11/R12真实来源联验，不能忘掉此前进阶水回流的未完成项。旧矿石直接冶炼始终保留，选矿不是强制替换或蛊虫成长。

## 2. 工作场与单位状态

单场只能养啮岩鼹或岩腹兽一种，容量4含幼体；为同时跑两路线须建两场。幼体采购直接入场，预检价格/容量/研究；非空场不直接换物种，先清退且明确说明丢失动物及未收物料，不退已消费矿料。

基础食谱、生产工艺分开显示。啮岩鼹菌菇/水、岩腹兽牧草/水或已解锁复合陆养食谱只维持成长/有效日；**加工石材/碎矿不是普通食物**。选择暂不生产可以只育成或待机，不因喂草就产生矿砂。

复用活体逐单位批次：空闲成体启动一次实际工艺，按选中数一次扣料，整体启动/维护/收取各按设施动作收费。已付矿料保存到周期收据，每天基础维护另扣该单位日粮、有效推进一次；缺日粮/工作暂停，不重扣矿料。日结成熟单位不能同日再加工一次。

待收单位无重复收费维护；收取发对应产物且保留动物。切石材/铁矿配方只影响未开批单位，已开批投入/产出不可改写。明确清退在制单位时该批终止、已付材料不退、不产生回收铁份额，确认文本列丢失进度和待收产物。

## 3. 普通加工、羊补料与守恒

| 路线 | 执行模型 | 关键约束 |
|---|---|---|
| R13/R14破碎 | 啮岩鼹有效维护日 | 石材/矿料一次投，菌菇/水按有效日 |
| R15选矿 | 岩腹兽有效维护日 | 碎矿一次投，草料/水按有效日 |
| R16新冶炼 | 旧冶炼炉普通日 | 富集矿砂与木炭全量扣，炉渣无再提铁 |
| R17/R18建材 | 旧木作台普通日 | 树脂作石板结合料，尾砂/炉渣/石粉共同消耗 |
| R08矿质饲料 | 农产加工台普通日 | 矿料＋草粉＋谷粉，不与旧羊矿料双扣 |

每批按资源表的铁份额计算`可回收输出≤实际输入`，破碎/富集/精炼不能复制金属；羊新补料的一轮钢绒份额同样受投入约束。份额是审计系数，不生成可交易代币，不用所有物品份数相等假装重量守恒。

尾砂、炉渣、再生填料和普通石材的本阶段可回收铁为0，禁止隐含转换回原矿/碎矿。关停、复制设施、切物种、存读、放弃批次都不能既退矿料又留输出。无需模拟更细矿物比例，但实际已付收据和配置输出须匹配。

羊矿质特殊食谱只在新轮支付，产物/去留仍沿用旧钢绒/羊粪；改餐不重扣已开始轮，不重算旧钢绒供养值。矿质补料有土标签但不满足订单供养资格，不能因含铁自动视为金食材。

## 4. 建材替代与自动生产

普通设施建造石材项允许玩家明确选择原石、复合石板或再生填料方案，按资源表整组兑换；不能静默在库存不足时替换。预览显示原需求、替代投入和最终报价，执行重验、整次成功，材料来源记到建造收据。

替代只影响原建造配方里的普通石材，不替代铁锭/木板、不满足研究“石材样本”、不用于动物矿料，不新增拆除退款或付费扩地。石板用于补光灯的专用材料需求不能用再生填料绕过。

R08/R16～R18与活体加工复用P8.b目标/在制/保留量，日粮仍是基础维护，不受加工保留量锁住；自动新周期的矿料受保留量约束。开局资源点依旧手动/显式委派，不能因建工作场自动无限采矿。

## 5. 界面和数据验证

工作场详情显示物种/成长、日粮、已付加工料、有效日、待收、主要成品目标及负责人。矿料来源可定位采矿点/破碎场；同物品被羊/冶炼/选矿竞争时只显示实际可用量，不当作三份库存。

成本来源包含幼体、育成维护、周期日粮/水、启动/有效工作/收取和时间；比较旧直接冶炼与新选矿的矿料节约、人工、空间和食物成本。没有经营价值时调整初值，不引入未经范围确认的额外金属、品质或成长奖励。

保存兽UID/阶段、活体批次和服务/推进日期、食谱/工艺选择及绑定；普通批次继续严格校验投入产出。快照拒绝单场混物种、超容量、共享批次ID、无已付料却待收及非法建材替代凭证，加载失败不部分改变库存。
