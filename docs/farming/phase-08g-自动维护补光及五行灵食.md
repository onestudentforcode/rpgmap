# Phase 8.g — 自动维护补光及五行灵食

> 日期：2026-10-11。状态：**开发设计稿，未实施、未验收。** 前置：[P8.f](phase-08f-岩兽选矿及材料回用.md)及[P8.e进阶联验](phase-08e-污水净化与藻料回流.md)。配数：[资源表](phase-08-资源与工艺表.md)；解锁：[研究关系](phase-08-研究与生产关系.md)。下游：[P8.h](phase-08h-90日经营验收与交付.md)。

## 1. 阶段范围与玩家流程

实现田间维护站、补光灯、厨房R19～R24，让T09/T10/T11/T12的剩余能力实际可用。玩家研究→制造建材/购建→配置范围/开关→按日消费投入获得维护或光照，再把三组生态与既有牧渔产物制成五行合格灵食。

装置自身运行不需要负责人、不收工资、不扣玩家AP；玩家建造/拆除仍手动1AP。厨房由玩家或负责人实际启动/收取、批次自动按天完成。研究和材料不足暂停，不引入电网、管线、热量/天气模拟、人类饥饿、蛊虫成长或手动高级批量工具。

本阶段把花源内部流、净化/矿石路径、研究费用、设备消耗与人力积压接入现有资源一览/关注/条目报告，不重新设计一套资源库存或强制90日结束页面。

## 2. 开日装置与配置生效

P8.a统一开日调用装置执行，顺序拟为有效灯光→田间服务，再开放玩家动作。每装置保存服务日标记、已用材料/动作数及覆盖结果；读档恢复，不重新燃油/浇水。当天新建或改变开关/阈值次日开始运行，UI显示生效日。

拆除有效灯立刻取消该实例剩余光照效果，已用燃料不退；重新建造是新实例、次日启用，不能当天通过重建获取免费光。田间站已做的环境改善不因拆除倒扣，也不返材料。配置报价只读，不能临时开关触发第二次开日。

装置运行共用真实库存，按稳定设施UID顺序执行、逐动作重验材料；每站保存轮转游标。原料保留只约束自动加工，不挡设备消费，设置页明确这一点。材料不足只暂停相应分支，灌溉缺水不必阻止有肥料的施肥，不提前扣未执行地格费用。

## 3. 田间维护站

| 项目 | 契约 |
|---|---|
| 范围 | 占地矩形向外扩，裁剪地图边界；按地格服务，不按作物锚点代替全部占地 |
| 目标 | 范围内已开垦地格且该项数值低于阈值；可服务空耕地，不服务原野/水域/设施占地 |
| 消耗 | 每次成功地格服务扣该项材料，增量/每日最多次数由资源表读取 |
| 重叠 | 同格同项目同日最多一次装置服务，浇水与施肥是不同项目 |
| 公平 | 格/项目稳定轮转，前一站已服务的目标不占后一站吞吐 |
| 记账 | 只有实际扣料/改善算运行；无目标/缺料/达到阈值不消耗、不收费 |

既有浇水/施肥是每格动作，2×2树木若四格都服务就是四次材料，不能一份清水改善整个占地。玩家在日间仍可用AP继续合法改善，装置的“一次”仅约束装置重复服务，不限制原手动浇水。

显示覆盖格数、当前低于阈值的格/项目数、最多可做数、预计材料及未覆盖/等待项。开日实际水分/肥力改变由同一环境接口供作物生长和供花查询，不保存另一套“自动灌溉增益百分比”。

## 4. 补光灯

按资源表范围和灯光值运行，开启且覆盖内至少有作物、燃料足够才扣该日精炼油；空范围不耗油、不激活光照。光照取自然与有效灯的最大值，重叠不加亮，但各实际启用灯仍消耗自身油，提示重复覆盖成本。

缺油不保持昨日免费灯光；读档不能据当前油量重新判运行导致二次扣料。中途种植只能使用当日已激活灯，不为原本空范围停机灯追加免费开日。效果日标记和燃料收据一致，翌日再根据新作物重新判定。

范围内喜阴木腐菇等可能因亮度偏离适宜值而降效，放置/选择/设置时显示受影响作物与适宜/预计光照，不自动排除它们或偷偷降低灯亮度。植物生长与蜂源正常度复用同一有效光查询，不能各计算一次光叠加；既有藻槽及R12不新增光照门槛。

## 5. 厨房与五行供货

R19/R20由T09开放，R21～R24由T12开放，按资源表完整扣食材和木炭、普通加工日完成、启动/收取各1AP。配方不因为玩家有火属性食材就自动省燃料，也不把用火烹制的全部产品判成火属性。

六灵食均走静态物品定义，五行与供养标记分别验证；它们供订单/上游材料消费，不增加本模块饱食度、AP、经验或战斗效果。矿质补料/营养液等未标供养的材料不能在需求面板提交。

延续rank1～5、自动必要数量、订单一次结算和10%溢价，只把实际已收取合格成品加入可选材料。旧食材的静态供养值、rank需求和既有订单回款规则保持；新值来自P8.a已审计表，g不能临时按售价估算或按当前消费者rank改值。

厨房持续生产与负责人使用P8.b统一账户/目标/在制/保留量；未领灵食是待收权益，不是库存/销售收入。金属灵食的铁份额含真实铁锭输入，废料配方不能绕过。进阶灵食出售/供货值需要在h真实经营调定，不单凭高售价认定工艺有价值。

## 6. 信息、报告与保存

资源页沿用实际入库/出库/净值和7日历史均值，净值≥0在增长栏、<0在负增长栏。内部花源转移、研究已付样本、装置实际消耗和待收权益分清；历史均值不作为今日保证产量。主界面关注初始空、可勾选新物料、随槽保存。

管理总览可定位研究台/蜂箱/菌床/岩兽/厨房/装置，筛选无负责人、缺料、等待工作、待收、库存目标达到等状态。人工报告显示一人的全部设施与兼任成功数/费用，设备材料消耗不列成工资。

条目日报与时节累计采用既有报告形式，第45日回顾在设备D+1消耗前冻结；之后继续实际账，不改写首次回顾。保存设备生效配置/当日运行/游标/有效光收据、关注和全场服务标记；恢复不执行运行或厨房收取。
