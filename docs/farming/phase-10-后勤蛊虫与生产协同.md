## 1. 阶段目标与设计方向

让玩家通过后勤蛊虫改变生产路线、提供环境条件、组织范围协同，并在普通生产与蛊虫生产之间做成本选择。

阶段完成后，玩家应能：

- 将同种不同实例的蛊虫分别入驻设施或部署到地图，同一实例不能重复使用。
- 比较金穗麦与饭袋草蛊的肥料、副产物、占地、工作量和元石成本。
- 用明光蛊改善生产环境，用催生蛊加快适配目标；普通作物与独立生产蛊共用效果查询。
- 在研究台的一格蛊虫槽中选择固定工作量减免或速度倍率，并看到材料与维护差异。
- 从受阻原因、维护账单和百科中查清生产为何暂停、何时恢复、实际扣了什么。

### 1.1 对旧方向提案的调整

[方向征求意见稿](phase-10-方向征求意见-蛊虫与新物种.md)保留讨论历史，本次设计不再以其中的“复用养殖、幼蛊成长、火炉/急思/华盖三只试点”为实施依据。

| 议题 | 本次设计依据 |
|---|---|
| 蛊虫定位 | 特殊生产与生产辅助单位；可以改变配方、条件及效率，不只作为劳工或养殖物种 |
| 获取与成长 | 购买、捕捉、炼制和转数提升归上游；本模块消费可派遣实例 |
| 日常照料 | 大部分不设独立普通喂养；配方损耗、元石维持、特殊食料分别结算 |
| 部署 | 设施入驻与地图独立部署并存 |
| 首批原型 | 饭袋草、明光、催生、智道研究、宙道研究；凝露为备选 |
| 新物种扩充 | 按后续产业需求另排，不自动作为P10.c起的必做波次 |

P8“蛊虫本体留上游”的历史边界在本阶段拟细化为：**上游拥有获取与成长，下游管理后勤部署、运行与经营成本。** 战斗蛊继续只作为资源需求方，不能转作生产蛊；既有五行供货也不等于已连接上游真实喂养。

## 4. 实例与部署契约

### 4.1 数据职责

以下字段为拟议职责，具体键名和文件拆分在P10.a确定。

| 数据 | 应包含 | 不应混入 |
|---|---|---|
| 蛊虫定义 | 模板ID、名称、后勤/战斗类别、转数参数、部署方式、能力标签、效果、维护与特殊食料 |
| 可派遣实例 | 唯一实例ID、模板ID、转数、上游来源/可用资格 | 以库存堆叠数量代替独立实例 |
| 部署记录 | 实例ID、设施UID/地图占地、启用意图、生效日、休眠/受阻原因 | 多个系统各存一份权威占用 |
| 效果定义 | SELF/HOST/AREA、目标标签、效果类别、数值、范围、同类组 | 将流派直接当作唯一兼容条件 |
| 生产任务 | 执行实体、配方、已付投入、目标工作量、进度、锁定蛊虫、修饰快照、待收权益 | 用当前定义重算已扣材料 |
| 运行收据 | 服务日、费用与食料、效果激活、工作/产出、操作结果 | 读档后依据当前余额重新判断过去是否付费 |

原文要求“设施类型＋能力标签”共同判断入驻。目标标签与能力标签分开；`biological_production`不自动等于所有活体、所有养殖单位或所有后勤蛊。

### 4.2 状态与操作

原文规则：未部署、已部署启用、已部署休眠、运行受阻；同一实例只占一处，同种不同实例可以并行，运行任务中不得直接更换入驻蛊。

接入建议：

- 研究台首版一个`research_assist`槽，与人类负责人分开；装蛊不替代玩家/雇工工作。
- 独立蛊占用逻辑地格，沿用原子占地与恢复前状态机制，不允许覆盖作物、设施、资源点或未购买土地；默认占地建议1×1。
- 放置、撤回与入驻报价先统一检查，失败不扣AP、材料或元石。建议成功部署/撤回各1AP，查看和启停设置0AP；最终操作成本在P10.a冻结。
- 新部署/恢复启用次日开日生效；停用立刻停止后续效果，当日已付维护不退，同日重开不重复生效或收费。
- 当前批次/研究未结束时拒绝换蛊、撤回或拆除宿主。允许暂停；若提供取消操作，先明确已投料不退、进度清零，再解除锁定，不能通过取消返料套利。
- 独立生产蛊有待收产物时先收取，再撤回；不能清理部署记录时顺手把产物自动入仓。

启用意图、付费资格、环境条件是不同维度；UI可合并显示主要状态，但应列出全部受阻原因。自动欠费休眠与手动休眠需保留原因，以便恢复规则可解释。

## 5. 生产与协同结算

### 5.1 工作量与取整

原文公式：`预计有效时间 = max(最小工作量, 基础工作量 - 固定减免) / 工作速度倍率`。材料倍率独立定义，不因速度提高自动增加材料。

接入建议：

- 日推进采用固定精度工作量，保留累计余数；例如×1.2每个有效生产日推进1.2基础工作量，不逐日截成1。
- UI预计有效日向上取整，至少1日；暂停日不计入有效日，不承诺自然日完成时间。
- 每类材料分别`ceil(基础数量×材料倍率)`，启动时一次扣除，不能先扣基础材料、以后每天补扣差额。
- 研究启动锁定入驻蛊实例、固定减免、速度/材料倍率及最终样本；原有一次性研究元石费用不自动受“材料×1.5”影响。
- 研究依旧每天最多一张有效收据；无收据不推进，有收据按锁定速度推进。倍率提高不额外扣AP或多计雇工成功次数。
- 任务仍需有效蛊资格；锁定蛊休眠或缺必要食料时不允许登记成功工作。已登记当日工作后主动休眠的处理须在P10.a与日结收据冻结规则一并定稿。

智道/宙道研究原文算例可得12→11/6；现行2日研究在“-1”和“×2”下都为1有效日。6日研究则为5/3日。不能只展示12日算例就判定现行研究已经形成明显分工。

### 5.2 参数快照与动态条件

原文要求按生产任务结算，同时允许持续环境变化导致暂停。接入建议区分：

| 内容 | 建议生效时点 |
|---|---|
| 研究方案、入驻蛊、一次性材料、固定减免与宿主倍率 | 任务启动锁定，完成/取消前不重算 |
| 当日范围速度增益 | 每个有效生产日建立快照，只影响未来推进，不改已完成工作 |
| 光照、水分等条件与蛊启用资格 | 环境/状态变化时刷新受阻信息；日结按唯一有效日收据结算 |
| 扣料、完成、收取 | 分别记一次，恢复/读档/重试不补扣、不重发 |

原文的通用范围增益在本期先作用普通作物与饭袋草。研究台的倍率来自锁定入驻蛊，不叠加催生范围效果，避免研究中临时换覆盖改变报价。

### 5.3 范围、环境与叠加

原文规则：SELF/HOST/AREA；逻辑格判范围；同类范围增益取最强；不同类型可并存；不递归增强和传播。

接入建议：范围采用占地矩形向外扩r格并裁剪地图边界，与现有装置口径一致。首版范围判断沿用目标锚点命中；地格环境则逐格查询，多格作物沿现行聚合规则读取。部署预览、实际计算和百科使用同一规则。

- 有效光照取自然光、已付费有效补光灯、明光蛊光照的最大值，不叠加亮度；喜阴目标可能被过强光照降效。
- 催生效果按稳定同类组（如生物生产速度）取最大倍率。×1.2与×1.3重叠只得×1.3，不能变为×1.56。
- 生物生产目标可以接受光照条件和速度修饰；效果源的强度、范围、维护费和食料消耗不被催生增强。
- 扩展补光灯的目标判定，使普通灯与明光都能实际服务独立生产蛊；灯的原有耗油规则仍单独记账。
- 光照和水分是环境值，不伪造“光/水分物品”进入仓库；环境效果不计为实物产出。

## 6. 维护、食料与日界事务

### 6.1 成本口径

原文三类成本分别为生产投入、周期元石维持、少数蛊的特殊食料。生产配方已包含的原料/损耗不得作为普通食料再次扣除。未部署及休眠暂按免维护设计。

接入建议统一按游戏日开日结算：

1. 按稳定实例ID处理已到生效日、要求启用的后勤蛊。
2. 检查本日元石与必要食料，单实例全额同时满足才原子扣除并生成服务日收据；缺任一项则两者均不扣。
3. 元石不足自动休眠；缺食料显示受阻。多个蛊争用资源时按上述稳定顺序服务，余下逐只显示未支付原因，不整组透支。
4. 已付费且启用的蛊获得当日资格，再计算光照、维护服务、生产条件及效果。不因今日缺水/无任务而自动退维护费；“启用但闲置仍付费”须在预览中明确。
5. 自动欠费休眠后建议由玩家申请次日恢复，避免收入回流后自动吞掉全部现金；不另增每日手喂操作。

维护优先级、闲置收费及恢复方式均为拟议默认，待P10.a定稿。饭袋草2元石/日、明光3元石/日仅来自原文测试值，不可直接作为正式经济配数。

### 6.2 接入既有事务

延续服务日D的唯一顺序：D开日→玩家动作→D日结雇工/工作与生产推进→D账目/回顾冻结→D+1开日→候选档提交。

- 在既有开日入口中明确蛊维护、普通灯、蛊光源、田间维护的稳定执行顺序；所有效果须在对应生产评估前就绪。
- 日结使用D的资格、环境与工作快照，不因时钟已变为D+1就提前套用新日维护结果。
- D+1开日扣费属于D+1，不能写进D的经营账或已冻结45日回顾。
- 最后1AP操作触发日结时，部署/工作收据须先进入候选状态，再提交存档；失败恢复整笔操作前状态。
- 保存重试只提交已生成候选，不重新开日、维护、雇工、完成或发产物；读档恢复已结算收据，不重新判断过去的资源是否足够。
- 新的蛊实例、锁定关系和付费日必须严格规范化；重复实例、非法宿主、越界占地、未知效果、进度与收据矛盾须拒绝，不能静默修复成额外收益。

现金和库存分别满足期末＝期初＋实际收入/入库－实际支出/出库；待收权益、环境变化和预测收益不计实物入库。

## 7. 首批原型与内容缺口

| 原型 | 原文核心规则 | 本项目需落实 |
|---|---|---|
| 饭袋草蛊 | 独立部署、光水条件、无肥料、稻米、无秸秆、元石维护 | 水分承载与补水入口、生产周期/产量、启动/收取操作、稻米下游用途 |
| 明光蛊 | 入驻照明设施、区域光照、无实物产物 | 宿主与普通油灯关系、亮度/范围、两类生产目标共用环境查询 |
| 催生蛊 | 入驻辅助设施、`biological_production`速度×1.2、不增强效果源 | 辅助宿主建造与解锁、范围、每日小数进度、成熟/待收状态不继续生产 |
| 智道研究蛊 | 单槽入驻、固定工作量-1、材料不变 | 最低1日、现行2/4/6日研究报价和实际完成一致 |
| 宙道研究蛊 | 速度×2、材料×1.5、元石与特殊食料 | 按材料向上取整、食料来源与扣费周期、休眠时任务暂停 |
| 凝露蛊（P1） | 专用凝露台、无蛊不产水 | 配方授权、凝露与普通产水成本对比，核心闭环后再排 |

### 7.1 饭袋草的水分与产物

接入建议：独立蛊虽不需要农田，仍由地格承载水分；占地前状态保留，但不能以开垦/播种为部署前提。提供占地蛊的浇水入口，并把其占地纳入田间维护站可服务目标。水分阈值与每日扣减由蛊定义，肥力完全不参与其资格与扣减；不得暗中复用普通作物的肥料消耗。

明确区分“地格水分点”与“浇水实际消耗的清水份数”；须先检查占用地格能否被现有环境存取，再确定实现方式，不能只改维护站的显示名单。

原文产物为“稻米”，现有主粮物品为“谷粒”。此项尚未裁决：若新增稻米，必须同步可达的加工/交易/供货用途和百科，不做孤立资源；若作为谷粒的一条新来源，须明确告知名称与资源抽象的调整，不在代码中悄悄替换原文。

### 7.2 明光与现有补光灯

建议首版复用现有补光灯设施，增加兼容槽与互斥运行模式：普通模式耗精炼油；蛊模式由明光蛊提供光照，支付蛊维护，不再对同一模式重复收油。切换次日生效，原研究/建造门槛保留；失去蛊资格当天停止蛊光，首版不自动回退耗油。此为接入建议，独立照明宿主亦可在定稿时替换该方案。

### 7.3 获取与食料来源

原文的真实获取归上游，本项目尚无已接通的可派遣后勤实例来源。实现不得以“上游会给”为由跳过可玩验证，也不能擅自复用战斗供货面板生成生产蛊。

建议先定义同一只读实例适配契约；专项测试使用明确的测试供给。面向玩家的原型采用**一次性本地试用配给**作为候选方案，写明是独立Demo替身，不包含培养与升转，不伪称已经连上上游。实例应有保存的发放标记，不能读档/回菜单反复领；长期获取方式留待另案。

宙道特殊食料必须有可正常取得的本地来源，且不能依赖“先完成待加速研究才有该食料”形成自锁。具体复用既有灵食还是新增食料在配数前确定，不默认现有五行食材天然就是宙道食料。

### 13.3 操作、日界与保存

- 成功部署、撤回、收取各1AP；启停/取消在制0AP，查看与报价不产生资源副作用。失败不扣费用。独立部署不需开垦，但不能覆盖作物/设施/资源点、水域或未购地。
- 部署/申请恢复在次日开日生效；停用即时取消未来效果，已付当日维护不退。元石不足自动休眠，须手动申请恢复；缺食料保持启用意图并受阻，后续开日重验。
- 开日顺序为蛊维护→普通灯→田间维护站；同实例每服务日最多一次。元石与食料全额同时满足才原子扣除，按稳定实例ID顺序处理争用；闲置启用照收维护。
- 独立生产按当天已付资格、实际光水条件推进。完成后待收，不继续耗水；收取可在休眠时领取已有权益。取消在制清空进度、不退投入；待收不能直接取消。
- 研究启动锁定实例与工作量/速度/材料方案，仍每日最多一张工作收据。休眠/食料受阻时不允许新工作；已登记当天工作后不能撤销其资格或取消项目，日结后再处理。暂停不撤销已做工作。
- 范围内目标锚点命中，环境逐格查询、多格作物沿既有平均口径。每有效日建立实际推进结果，普通作物100点/日与饭袋草100点/日可被催生改为120点/日。
- 蛊占地使用统一网格占用，恢复时重建并保留原耕地状态。水分仍是地格环境值，清水浇水与田间站均可服务占用格；田间站不为饭袋草施肥。
- schema18严格保存实例、占地、资格、付费/食料收据、最近15日维护、累计费用、在制/待收任务及研究修饰。schema17只添加空后勤与中性研究方案，不改旧文件或删除档案；更早P8档继续拒绝。
- 保存失败回滚整笔触发操作，重试仅发布保留候选；独立实例/研究状态/材料账/维护费同时恢复。次日开日维护记入新日采购支出，不能并入前一日或已冻结45日回顾。
