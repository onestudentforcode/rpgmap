# 灵田P10.1农业辅助蛊试玩

运行项目根目录`play.bat`或按Godot F5，仍使用原P8入口与三槽。当前存档schema19可逐级无损读取schema18/17，下一次正常日存档保存为新版本；不会自动删除原档。历史V0/V1/V2仍用各自入口与独立档案。

1. 新游戏或进入现有P8档，悬停顶栏找到“后勤蛊”。领取一次试用配给共11只：饭袋草、催生、锁水、节肥各两只，明光、智道研究、宙道研究各一只；已领取过P10配给的旧档升级时自动补发新增五只。
2. 选择饭袋草的“地图部署”，点击空闲陆地。它不需要农田或开垦，成功消耗1AP。优先放在光照80的区域，例如空闲的(10,11)；左下阴影区需要补光。
3. 次日开始每日支付1元石。水分至少30、光照至少60时推进，每个有效日扣水分8。启用后完成3次有效生产日结即可收稻米4，收取1AP后才进仓。
4. 水分低时在蛊详情补水，每次耗清水1、1AP、加水分30。田间维护站也能自动给独立蛊补水，且不会给它施肥。稻米可出售、木行供货，或在农产初加工解锁后磨为谷粉。
5. 建好兼容设施后，可在管理页选择具体宿主入驻，或选择“地图选择兼容设施”并点击高亮目标：明光→补光灯；催生/锁水/节肥→田间维护站唯一蛊槽；两种研究蛊→研究台唯一辅助槽。
6. 智道工作量−1；宙道速度×2、样本逐项×1.5向上取整，另需每日2元石和宙道食料1。食料可在市集2元石购买。研究每天仍需一次玩家或负责人工作。
7. 农业三蛊的服务区是宿主朝向侧的3×3：建造页可选朝向（默认东），建成后“转向”按钮1AP提交、次日开日生效，当日已付维护不退。作物的全部占地都要落在同一个3×3内才生效；跨两个来源的半覆盖不叠加。选中作物可看实际生长倍率、水肥保留比例、采用与被覆盖来源。
8. 催生把当日生长点推进×1.5（同tag只取最高转有效来源，不叠加）；锁水/节肥分别让目标水/肥扣耗保留50%，按每格百分之一余量跨日累计，收获、重种、转向或读档都不清除。饭袋草无肥耗，节肥对它无效。

休眠不收费，启用但闲置仍收费。元石不足会自动休眠；补足资金后申请次日恢复。缺食料时元石与食料都不扣。运行中的任务/待收产物锁定实例；先收取或取消在制，才能撤回，取消不退投入。

明光替代入驻灯的精炼油模式，休眠不自动回退燃油；光照取最大。管理页可看当前条件、费用与效果来源；百科新增“后勤蛊与协同”与规则“农业辅助蛊”，完整规则与产消用途均可跳转。

首批形象是可替换的矢量原型。真实上游获取/捕捉/炼制/升转尚未接线，凝露台与完整高转图鉴留后续。查看[新手手册](demo-p8-新手手册.md)、[百科全书](demo-p8-百科全书.md)或[本期执行记录](phase-10.1-农业区与辅助蛊.md#13-起草记录)。
