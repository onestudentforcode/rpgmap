# 生产经营系统补充设计：七大机制与推进路线

> **状态：** 草案（2026-10-10 用户提案，本文为整理稿，待评审定稿）

> **裁决状态（2026-10-10 V0.2）：** 本文部分内容已由 [design-outline.md](design-outline.md)（生产与经营系统设计纲要 V0.2）收敛或修改——资源模型定为八用途标签+三生产阶段；"有限地质资源"改为**资源点储量无限、产能有限**；优先级以纲要 §9 为准。逐项对照见纲要附录。

## 1. 资源的多维模型

资源只有五行属性，对经营游戏来说不够：

- 木材和牧草都是**木**，但前者是建材、后者是饲料；
- 木炭和植物油都是**火**，但一个是固体、一个是液体；
- 岩石和腐殖土都是**土**，但一个适合建筑、一个适合种植。

建立多维资源模型：

| 维度 | 举例 | 影响的机制 |
|---|---|---|
| 五行属性 | 金、木、水、火、土 | 资源分类、特殊配方 |
| 物质形态 | 固体、液体、气体、能量载体 | 运输、存储、设备类型 |
| 用途标签 | 饲料、燃料、建材、矿物、有机物 | 配方兼容性 |
| 品质 | 普通、优良、精制 | 产量、效率、价值 |
| 保存特性 | 易腐、稳定、易挥发 | 仓储和损耗 |
| 来源成分 | 铁含量、含水量、有机质等 | 特殊生产过程 |

**两条注记：**

- **不模拟所有化学成分**，仅记录需要实际参与玩法的成分。例如含铁岩石（土）可被破碎为碎矿石、经岩腹兽富集为高品位矿砂、再冶炼为铁锭（金）——它不需要因为含铁从一开始就归为金属性。
- **火属性双轨约定**：区分"可燃物"与"能量"。燃烧产生**热量**，可通过特殊装置收集成**储热晶 / 火种**，成为火属性资源；木炭、植物油属于可燃物，同样归火属性。这样既保留幻想设定，也能解释不同材料为什么具有不同用途。

## 2. 环境系统：让种植与养殖不只是消耗配方

**最重要的补充之一。** 目前生物设计大多是"消耗 A → 等待一段时间 → 产出 B"。如果所有生物都这样运行，花草、树木、动物、水产在本质上没有区别，只是资源转换器的外观不同。

四个模块应有不同的生产逻辑：

| 模块 | 关键环境条件 | 主要玩法特色 |
|---|---|---|
| 种植 | 光照、温度、水分、土壤肥力 | 土地经营、长期生长、轮作 |
| 畜牧 | 饲料、温度、活动空间、健康 | 食性、繁殖、周期性采集 |
| 水产 | 水温、溶氧、盐度、水质 | 水体生态、循环用水、混养 |
| 加工 | 能源、设备、原料、产能 | 配方选择、效率、自动化 |

**示例：钢绵羊的三层需求。**

| 层次 | 需求 | 状态与后果 |
|---|---|---|
| 基础生存 | 牧草、水、适宜温度 | 缺一不可，长期缺乏则健康下降、停止生产、可能死亡 |
| 特殊生产 | 含铁矿盐 | 矿盐不足：能存活，但钢绒生长缓慢或停止 |
| 正常运转 | 饲料+矿盐充足、环境适宜 | 正常生长钢绒，定期产出粪肥 |

这种设计让**"喂什么"和"如何养"成为两个不同的问题**。不需要复杂生态模拟，生长效率可归纳为：

```
P = P₀ × f(环境) × f(营养) × f(健康)
```

各系数用较简单的**分段规则**计算，不需要连续物理仿真。

## 3. 可再生与不可再生：资源来源与守恒约束

**整个生产系统经济平衡的基础。**

木材可以种树不断获得、牧草可以重新生长，但地下铁矿、天然岩石是否无限生成？假如岩腹兽吃 10 单位岩石产出 8 单位金属、金属又能用某配方转回 10 单位岩石，玩家很容易循环获得无限资源。因此需要定义资源来源：

| 来源类型 | 典型资源 | 生产约束 |
|---|---|---|
| 自然可再生 | 木材、牧草、果实 | 光照、水、养分、时间 |
| 环境采集 | 雨水、露水、盐分 | 天气、气候、采集效率 |
| 有限地质资源 | 天然岩石、金属矿石 | 矿脉储量、开采能力 |
| 生物制造 | 钢绒、珊瑚石、珍珠 | 食物、矿物补给、时间 |
| 加工转化 | 木炭、金属锭、植物油 | 原料、能源、设备 |

**尤其重要：让矿物从环境中进入生产系统，而不是凭空从生物身上生成。** 例如礁骨珊瑚能长期产出珊瑚石，但需要消耗水体中溶解的钙质；钙质不足时生长减缓，玩家需补充石灰质材料或引入新的矿化水——水产模块由此与岩石产业形成联系。

## 4. 资源物流与存储

经营类游戏的重要挑战：**有资源 ≠ 资源能顺利到达需要它的地方。** 例如种植区每分钟生产 100 单位牧草、钢绵羊牧场消耗 80 单位、但实际运输能力只有 40——玩家面对的不是生产不足，而是**物流瓶颈**。

| 问题 | 可以产生的玩法 |
|---|---|
| 固体如何搬运？ | 仓库、搬运工、传送带 |
| 液体如何传输？ | 水槽、管道、泵 |
| 气体如何使用？ | 通风设施、储气罐 |
| 热量如何传递？ | 热源、储热装置、热量损耗 |
| 食物如何保存？ | 仓储、冷藏、干燥、防腐 |
| 废料如何处理？ | 自动收集、回收、堆肥 |

**不建议一开始就做完整物流模拟。** 若游戏侧重资源经营而非工厂自动化，可先用简化方案：**区域共享仓库 + 建筑自动取料 + 有限运输能力**；后期再决定是否加入可视化管道和传送带。

## 5. 生产链的副产物、损耗与回收

**可以成为游戏区别于普通合成经营游戏的核心特色。** 现实工业生产不是 `A + B → C`，而是：

```
A + B + 能源 → C + D + 废料 + 热量
```

所有重要加工过程都采用这种结构。示例——**木材干馏**：

| 项目 | 内容 | 归属 |
|---|---|---|
| 输入 | 木材 10（木）＋ 启动热量 | — |
| 设备 | 炭化炉 | — |
| 主产品 | 木炭 3 | 火 |
| 副产品 | 木焦油 1 | 火 |
| 副产品 | 木醋液 2 | 水 |
| 能量回收 | 可燃气体 | 火 |

> 产量仅为玩法示意，实际配方需统一质量、含水量和能量核算口径。

玩家可以选择普通炭化炉只收集木炭，也可以升级设备额外回收木焦油、木醋液和可燃气体。**加工建筑之间的区别不只是"高级建筑加工速度更快"，而是加工工艺、资源回收率和能源利用方式不同。**

## 6. 资源的最终消耗端

**当前方案中最明显的缺口**：设计了很多资源如何生产，却还没确定这些资源**最终为什么值得生产**。钢绵羊产出钢绒、钢绒加工成钢丝——然后呢？如果钢丝没有足够的消耗场景，生产线建立后仓库迟早堆满钢丝。需要建立真正的经济需求：

| 消耗方向 | 可能需要的资源 | 目的 |
|---|---|---|
| 建筑建设 | 木板、石材、金属 | 扩大生产规模 |
| 设施升级 | 钢丝、精制金属、特殊材料 | 提高效率 |
| 土地维护 | 肥土、石灰、水 | 维持农业产能 |
| 动物培育 | 饲料、矿盐、专用材料 | 繁殖、提高品质 |
| 能源系统 | 木炭、植物油、蓄热材料 | 维持加工设备 |
| 商品订单 | 珍珠、织物、食品、精制材料 | 货币、解锁奖励 |

确定两种资源用途：

- **内部循环型**：牧草、肥土、矿盐、木炭——用于维持与扩大生产；
- **最终消费型**：珍珠饰品、高级建材、纺织品——用于商品交付、建筑建设或游戏目标。

两者可以兼顾，**但不能让所有产物都只是其他产物的中间材料**。

## 7. 生物生命周期与繁殖

可稍后实现，但应**提前预留设计空间**——否则畜牧与水产只是"植物种植的另一个版本"。生物最少具有以下状态：

| 状态 | 行为 |
|---|---|
| 幼体 | 消耗饲料 |
| 成体 | 资源生产 |
| 老年 | 效率下降 |
| 繁殖 | 成体数量、环境和营养条件达到要求后产生幼体 |

不同生物围绕基础模型差异化：钢绵羊成年后定期剪毛；矿鳞蜥在蜕皮时集中产出鳞片；蜜盏蜂以蜂群为生产单位、不需要单独模拟每只蜜蜂。

**不建议给所有动物设计遗传和基因系统**，除非繁殖培育本身是游戏的重要玩法。

## 8. 推进优先级

| 优先级 | 系统 | 当前状态 | 建议 |
|---|---|---|---|
| P0 | 五行属性与资源模型 | 初步确定 | 补充形态、标签、储存方式 |
| P0 | 资源来源与守恒约束 | 部分确定 | 区分天然输入、生物转化、加工转化 |
| P0 | 资源最终用途 | 明显不足 | 定义建造、升级、销售等消耗端 |
| P0 | 加工配方与建筑 | 尚未系统设计 | 下一阶段重点 |
| P1 | 生产环境与生物需求 | 初步设想 | 建立简化环境模型 |
| P1 | 仓储与物流 | 尚未确定 | 先确定抽象层级 |
| P1 | 生命周期和繁殖 | 尚未确定 | 简化实现 |
| P2 | 品质、培育、工艺升级 | 可延后 | 在基础循环稳定后增加 |
| P2 | 自动化和复杂物流 | 可延后 | 根据实际玩法需求决定 |

## 9. 核心设计方向：同一种资源的竞争性用途

**这款游戏最值得挖掘的特色，不是"五行资源转换"，而是同一种资源拥有多种竞争性的生产用途。**

以 100 单位木材为例：

```
100 单位木材（木）
├─ 建筑路线：木板 → 建造设施
├─ 能源路线：木炭 → 冶炼与供热
├─ 养殖路线：木屑 → 真菌 → 动物饲料
└─ 农业路线：碎木料 → 堆肥 → 改良土壤
```

每一条路线都有收益，但**木材的总量有限**。玩家可能为了扩大种植规模消耗大量木材制堆肥，结果没有足够燃料冶炼金属；也可能为制造机械设备大量消耗木炭，导致冬季供热不足。**这才是经营玩法的决策核心。**

**最终设计目标**：每种物种都有值得养殖的理由，每种资源都有明确的去向，每条生产链都有成本与收益，每项扩建决策都需要权衡。

## 10. 下一步：先做三件事

1. **建立资源总表**：确定每种原料的属性、形态、用途和初始来源，形成统一的资源 ID；
2. **建立资源需求表**：确定建造、升级、养殖维持、加工消耗和商品订单分别需要什么——**此项应放在加工建筑设计之前**，否则很容易做出几十种复杂材料，却发现不少并没有实际用途；
3. **建立加工配方图**：连接资源生产端与消耗端，再根据实际需要设计加工建筑。
