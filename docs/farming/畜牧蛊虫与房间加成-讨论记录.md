# 畜牧蛊虫与房间加成：讨论记录

> 日期：2026-10-18。状态：设计讨论，不是实施定稿。
> 前置：[P10.3陆生动物分区与日程](phase-10.3-陆生动物分区与日程.md)已交付，现行schema21。
> 本文区分用户确认、后续预留和待讨论项；不改变当前游戏规则、内容或历史验收证据。

## 1. 用户确认的三级结构

| 级别 | 条件 | 功能 |
|---|---|---|
| 一级 | 特定设施与满足数量要求的地板组成连通区域 | 允许对应设施发挥基础功能；房间不成立则对应设施不能运行 |
| 二级 | 一级基础上，宿主入驻tag正确的蛊虫 | 允许蛊虫发挥自身作用，仍受实际供给、服务范围与承载限制 |
| 三级 | 多个一级、二级房间按规则组成统一系统 | 获得额外的系统作用 |

育种田、丰产田、复合农业区均归三级农业系统的不同配置，不将复合农业区另算更高一级。畜牧三级配置待基础设施和二级宿主确定后再设计。

同时保留已确认的边界：

- 一级、二级是单个房间，三级是房间组成的系统，不强制所有地板连成一体。
- 房间失效可使设施停工，但动物维持失败、禁工、疲劳等仍须继续结算；设施在制进度保留。
- 二级不会自动把蛊虫能力扩展到整个房间，仍须满足实际服务条件。
- 蛊虫断供只关闭对应能力及依赖它的协同收益，不关闭仍合格的一级基础功能。
- 三级需要明确组合条件；多个宿主或多只蛊放在一个房间内，不自动形成三级。
- 系统失效时各组成房间独立判断基础功能与蛊虫能力，避免无关设施一起停工。

## 2. 本轮畜牧方向

用户认可一级房间的基础设施划分；额外放牧区的“休憩亭”方案由动物玩具及其管理设施方向替代。

| 房间 | 一级基础构成 | 本轮二级方向 | 状态 |
|---|---|---|---|
| 育幼区 | 圈舍、供食槽、适配床位、合格地板和空间 | 暂不做 | 一级保留，二级后置 |
| 圈养区 | 圈舍、供食槽、适配床位、照料台、合格地板和空间 | 仅新增安抚台作为蛊虫宿主 | 安抚的具体能力待讨论 |
| 工作区 | 调度站、工作设施、合格地板 | 调度站入驻奴道蛊虫，提高工作效率，加快积累工作进度 | 方向确认，数值与服务规则待定 |
| 维持放牧区 | 供食槽、适配床位、合格地板和空间 | 本轮不做；保留食道、梦道两条设计方向 | 仅记录，不实施 |
| 额外放牧区 | 合格活动空间；新增玩具管理设施方向 | 玩具不依赖蛊虫，本轮不因此认定二级 | 设施细节与玩具机制待讨论 |

### 2.1 圈养区：只开放安抚台

本轮不开放照料台入驻，不取消其已有的一级配套地位与基础功能。

原因：动物的产出方式可能不同，直接把照料加成绑定各动物的具体产出流程，可能随新动物推出反复修改。先将安抚台作为独立宿主；不提前确定其影响繁殖、特色产物还是其他通用环节。

安抚台无蛊时是否具有基础功能、接受什么tag、如何定义服务对象，以及如何避免逐物种特判，均待后续讨论，不能视为已定机制。

### 2.2 工作区：奴道调度

调度站入驻适配奴道蛊，能力为提高实际工作的效率，增加单位有效劳动贡献的工作进度。原料、岗位和设施批次仍遵守P10.3规则，不能无料生产或凭空增发矿物。

本轮未提出减少劳动疲劳、延长工作日程或取消维持要求，不把这些列作该蛊的附带能力。具体倍率、维护费用、覆盖/承载和多个调度站的重叠规则后续确定。

### 2.3 维持放牧区：保留两条后续设计

- 食道蛊：减少口粮消耗。
- 梦道蛊：动物睡眠时做梦，缓解疲劳。

目前均不接入；具体宿主、入驻tag、数值与生效条件尚未确定。尤其梦道能力会改变当前“基础维持不恢复劳动疲劳”的口径，须作为将来的明确强化另行设计，不改写P10.3现行基础规则。

### 2.4 额外放牧区：玩具与工业生产

取消拟议的休憩亭，改为面向动物的玩具，由一类专门设施管理。玩具无需是蛊虫，可以有独立配方与工业生产路线。

以下尚未决定：管理设施名称与占地；玩具是否为一级成立必需物；空置设施能否提供基础活动服务；玩具的服务容量、适用对象、具体收益、耐久/消耗、补充方式，以及材料与加工链。

按当前三级定义，非蛊虫玩具本身不会把一级房间提升为二级；它们可以改善一级房间的服务，也可在未来作为三级系统的配套条件，具体收益另议。

## 3. 入驻资格只维护一套规则

用户要求尽量避免同一用途同时由房间类型和tag共同约束，以免后续维护重复判定。

采用以下设计原则：

1. 房间负责检查结构条件，决定设施能否运行。
2. 宿主统一检查其接受的入驻tag，决定蛊虫能否入驻。
3. 不再为同一种宿主按所在房间另设一份tag白名单，或按房间类型切换同一只蛊的能力。
4. 蛊能力作用于宿主实际服务的对象与事件，范围、承载、供给仍正常校验。

“设施须处于合格一级房间”是统一运行前提，不是针对同一用途再叠加一份入驻限制。具体tag命名及道途与用途标签的关系，留到实例设计时统一确定。

## 4. 接下来的讨论顺序

1. 安抚台的作用对象、生效环节与单一主要能力。
2. 调度站奴道蛊的倍率、服务对象、承载与维护成本。
3. 玩具管理设施的一级功能、玩具收益及首条生产路线。
4. 在上述模块确定后，组合畜牧三级系统及额外收益。

以上顺序为讨论建议，不代表已经开始实施。食道、梦道方向继续作为预留。
