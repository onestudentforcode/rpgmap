# 畜牧蛊虫与房间加成：讨论记录

> 日期：2026-10-18。状态：设计讨论，不是实施定稿。
> 前置：[P10.3陆生动物分区与日程](phase-10.3-陆生动物分区与日程.md)已交付，现行schema21。
> 本文区分用户确认、后续预留和待讨论项；不改变当前游戏规则、内容或历史验收证据。
> **后续入口：** 已汇入[P10.4草案](phase-10.4-畜牧蛊虫与三级生产系统.md)，包含三级组合的候选收益、首轮建议参数及分层验收；本页保留讨论来源，不将候选数值改写为已确认。

## 1. 用户确认的三级结构

| 级别 | 条件 | 功能 |
|---|---|---|
| 一级 | 特定设施与满足数量要求的地板组成连通区域 | 允许对应设施发挥基础功能；房间不成立则对应设施不能运行 |
| 二级 | 一级基础上，宿主入驻tag正确的蛊虫，或装入适配的特殊道具 | 开启对应蛊虫或特殊道具的能力，仍受实际供给、服务范围与承载限制 |
| 三级 | 多个一级、二级房间按规则组成统一系统 | 获得额外的系统作用 |

育种田、丰产田、复合农业区均归三级农业系统的不同配置，不将复合农业区另算更高一级。畜牧三级配置待基础设施和二级宿主确定后再设计。

同时保留已确认的边界：

- 一级、二级是单个房间，三级是房间组成的系统，不强制所有地板连成一体。
- 房间失效可使设施停工，但动物维持失败、禁工、疲劳等仍须继续结算；设施在制进度保留。
- 二级不会自动把蛊虫或特殊道具的能力扩展到整个房间，仍须满足实际服务条件。
- 蛊虫断供或道具服务失效只关闭对应能力及依赖它的协同收益，不关闭仍合格的一级基础功能；道具是否消耗、是否有耐久另行设计。
- 三级需要明确组合条件；多个宿主或多只蛊放在一个房间内，不自动形成三级。
- 系统失效时各组成房间独立判断基础功能与蛊虫/道具能力，避免无关设施一起停工。

## 2. 本轮畜牧方向

用户认可一级房间的基础设施划分；额外放牧区的“休憩亭”方案由动物玩具及其管理设施方向替代。

| 房间 | 一级基础构成 | 本轮二级方向 | 状态 |
|---|---|---|---|
| 育幼区 | 圈舍、供食槽、适配床位、合格地板和空间 | 暂不做 | 一级保留，二级后置 |
| 圈养区 | 圈舍、供食槽、适配床位、照料台、合格地板和空间 | 安抚台入驻安抚蛊，提高繁殖进度积累速度 | 能力确认，数值与服务规则待定 |
| 工作区 | 调度站、工作设施、合格地板 | 调度站入驻奴道蛊虫，提高工作效率，加快积累工作进度 | 方向确认，数值与服务规则待定 |
| 维持放牧区 | 供食槽、适配床位、合格地板和空间 | 本轮不做；保留食道、梦道两条设计方向 | 仅记录，不实施 |
| 额外放牧区 | 合格活动空间；新增玩具站管理玩具 | 玩具站装入适配玩具，按特殊道具路线形成二级 | 名称与抓娃娃机外观确认，具体收益待定 |

### 2.1 圈养区：只开放安抚台

本轮不开放照料台入驻，不取消其已有的一级配套地位与基础功能。

原因：动物的产出方式可能不同，直接把照料加成绑定各动物的具体产出流程，可能随新动物推出反复修改。用户进一步确认，未来会细分剪毛、清洗等照料方式，由各自的专用设施承载；相关功能较复杂，本轮不设计或实施，也不将它们合并进安抚台。

**安抚能力已确认：提升繁殖速度，即加快繁殖进度积累。**不把特色产物增产或精细照料列作其附带能力。

设计建议：强化已有合格照料时间产生的繁殖进度，保留成体圈养、开日疲劳为0、维持有效等基础资格；具体作用算法在实施草案中确定。安抚台无蛊时是否具有基础功能、接受什么tag、倍率/承载/维护费用仍待讨论。

### 2.2 工作区：奴道调度

调度站入驻适配奴道蛊，能力为提高实际工作的效率，增加单位有效劳动贡献的工作进度。原料、岗位和设施批次仍遵守P10.3规则，不能无料生产或凭空增发矿物。

本轮未提出减少劳动疲劳、延长工作日程或取消维持要求，不把这些列作该蛊的附带能力。具体倍率、维护费用、覆盖/承载和多个调度站的重叠规则后续确定。

### 2.3 维持放牧区：保留两条后续设计

- 食道蛊：减少口粮消耗。
- 梦道蛊：动物睡眠时做梦，缓解疲劳。

目前均不接入；具体宿主、入驻tag、数值与生效条件尚未确定。尤其梦道能力会改变当前“基础维持不恢复劳动疲劳”的口径，须作为将来的明确强化另行设计，不改写P10.3现行基础规则。

### 2.4 额外放牧区：玩具与工业生产

取消拟议的休憩亭，改为面向动物的玩具，管理设施确定命名为**玩具站**，外观为**抓娃娃机**。本轮只记录外观方向，不生产或接入美术资产。

玩具无需是蛊虫，可以有独立配方与工业生产路线。根据本轮扩展的二级定义，玩具作为特殊道具装入玩具站，允许额外放牧区走非蛊虫的二级强化路线；撤销此前“非蛊玩具不能形成二级”的讨论判断。

以下尚未决定：玩具站占地、一级结构是否必须包含空置玩具站、空置时的基础活动服务；玩具槽数、服务容量、适用对象，以及配方材料数量和加工时间。藤球已确认为装入后长期使用的耐用品，不按使用次数消耗。普通基础配套或随意放入任意物品不会自动形成二级，须是宿主接受并能提供强化服务的特殊道具。

#### 首种玩具：藤球

**用户确认：**

- 首批只做一种简单玩具，名称为藤球。
- 在现有木工台制作，不需要解锁配方。
- 效果为10%概率额外恢复1点疲劳。
- 装入玩具站后长期使用，是耐用品，不按每次玩耍消耗藤球；本轮不自行追加磨损或破损机制。

**触发口径建议，待确认：** 每只动物每完成一个有资格、有空间且实际获得玩具服务的有效额外放牧单位，独立判定一次10%；成功记额外恢复1点。原基础恢复为2点，触发后该单位合计恢复3点；计入当天恢复账，仍在次日开日统一更新疲劳，不在日内改变等级。

基础维持、等待、无空间或维持资格无效的活动不触发建议中的判定。同一动物同一单位不因多个玩具站重复判定；具体服务容量与分配规则仍待确定。

藤球材料/数量和工时尚未确定；不把制作环节已确认误写为完整配方已冻结。随机判定须随有效服务留证，日结失败重试和读档不能重复领取同一单位的恢复。

## 3. 入驻资格只维护一套规则

用户要求尽量避免同一用途同时由房间类型和tag共同约束，以免后续维护重复判定。

采用以下设计原则：

1. 房间负责检查结构条件，决定设施能否运行。
2. 宿主统一检查其接受的入驻tag，决定蛊虫能否入驻；特殊道具也由宿主统一检查适配资格。
3. 不再为同一种宿主按所在房间另设一份tag白名单，或按房间类型切换同一只蛊/同一件道具的能力。
4. 蛊虫及道具的能力作用于宿主实际服务的对象与事件，范围、承载、供给仍正常校验。

“设施须处于合格一级房间”是统一运行前提，不是针对同一用途再叠加一份入驻限制。具体tag命名及道途与用途标签的关系，留到实例设计时统一确定。

## 4. 接下来的讨论顺序

1. 安抚台繁殖加速的作用对象、倍率、承载和维护成本。
2. 调度站奴道蛊的倍率、服务对象、承载与维护成本。
3. 玩具站的一级功能，以及藤球的判定时机、配方材料/工时与服务容量。
4. 在上述模块确定后，组合畜牧三级系统及额外收益。

以上顺序为讨论建议，不代表已经开始实施。食道、梦道方向继续作为预留；剪毛、清洗等专用照料设施及其规则后置。
