# 灵田 Demo V2 · 试玩说明

这是种植、加工、供货与养殖相连的经营试玩版。首次体验以45天（3个时节）为一轮，第45天结束后查看回顾，之后仍可继续经营。没有强制胜负。地面沿用既有素材，作物、动物与设施暂用程序占位表现；没有新增音乐。

## 启动和存档

解压后运行 `LingTianDemoV2.exe`，无需安装 Godot。新游戏选择三个存档槽之一；初始60元石。每天结束自动保存到该槽，无手动存档。离开前可结算当日；放弃当日会回退到上一次自动保存。V2使用独立存档、schema 11；开发阶段不转换旧版存档。

推荐2560×1440；设置支持分辨率、窗口模式、UI缩放等。小窗口会限制实际UI缩放以保证至少960×540的可用布局，所选缩放仍保留，扩大窗口后恢复。图标按钮悬停显示用途。地图可拖动、缩放；右侧详情和弹窗内可滚动。

## 经营入口

- 手动工具由玩家立即操作，成功消耗AP；工作标记供雇工日结执行。不要将这两种入口混淆。
- 种植：开垦→购买种子→播种→浇水/施肥→成熟收获。麦、杉、松脂树、菌菇和牧草构成种植与回收路线。
- 资源点：点击采石、采矿、泉水采集。储量无限，每日产能有限。
- 加工：选择设施建造位置，点击设施投料，按天推进，完成后收取。原木加工、炭化、堆肥、冶炼及藻料生产均使用共享库存。
- 养殖：圈舍建在陆地、水场建在地图下方20×8水库，均占2×2。每设施同种最多4只（幼体计数），幼体只能购买，不繁殖。
- 设施三栏为动物、基础食谱、特殊食谱；默认选择会明确提示。选择不会扣材料。基础维护维持成长，特殊食物启动成体产出；可选择“暂不生产”。缺料暂停、补齐恢复。水产还需注意水体状态并补充清水。
- 负责人：从雇工名单指派，一人只负责一个设施，退出其他农务。整体收取/投喂/换水按实际成功工作收人工费，失败不扣费，不消耗玩家AP；材料由共享库存进出。
- 市场与供货：购买种子和投入、出售自产材料；订单按五行和转数选择合格食材，自动计算必要数量，只支付一次，并有10%溢价。经营收入自然解锁更高转数。

## 摘要与资源一览

顶栏养殖总览能定位设施；资源一览区分增长/平衡和负增长。默认“当日实际”：周期产物只在收取当天入账；可切换最近7日平均，不将未收取产物当收入。点击资源名称展开来源和去向。勾选关注后才会显示在主界面，初始为空；多项可通过“更多”查看。

每天结束可查看实际收支、人工费及养殖条目；时节摘要按条目回顾，45天回顾包含三时节实际累计。第46天不会改写首次回顾。

## 建议起步

保留部分元石购买幼体和支付后续人工费。先种牧草、麦和速生杉，采石与清水，再建圈舍、水场及藻料设施。手动养出首批产物后再指派负责人较容易理解资源流向；也可提前出售少量粮食、早日托管。羊粪、鱼污分别堆肥为腐殖土，再回田施肥；钢毛与鱼肉可供货，收入可再投幼体、种子和设施。

## 已知范围

没有繁殖、寿命、疾病、动物死亡、人物实体、搬运、管道或付费扩地。缺食物不会致死。当前水库属于固定基础地图；蛊虫实体与战斗属于上游项目，此处仅实现五行/转数供货接口。世界美术仍为占位，不代表最终画面。
