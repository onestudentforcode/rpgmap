## 1. 目标和本阶段可玩边界

玩家建研究台，查看三层工艺、前置与样本来源，选项目支付启动费，然后每天手动或委托一次研究工作。完成研究后全农场获得能力，仍需购买/建造/实际加工，不直接发设施和产物。

本阶段实现12项目的数据与全套状态机；自然经营可先用默认路线取得T01/T04/T05样本并研究，其解锁的生态执行分别在d/e/f落地。研究和能力是否已实现分开，开发入口不得伪称整网已能经营；最终P8.h不得留未实施解锁。不能用开发注入作为真实样本获取证明。

研究台本身默认可建，旧P7工艺默认掌握。不重新锁住农田、泉水、木材加工、炭化、堆肥、牧渔或普通冶炼，也不添加玩家食用灵食或蛊虫成长功能。

## 2. 数据与状态机

建议独立研究模块管理全场已完成项目、在研项目→研究台归属；设施保存当前项目/状态、已接受工作日期与有效日进度。样本/元石扣款收据进入经营记录，研究完成后只增加完成集合和解锁事件。

| 状态 | 可以做什么 | 不允许什么 |
|---|---|---|
| 锁定 | 查看前置/样本与用途 | 启动、支付或工作 |
| 可启动 | 选择空研究台并获取最新报价 | 报价不扣款/不占项目 |
| 在研 | 当天最多一次工作；暂停 | 同项目第二台并行、重复支付 |
| 暂停 | 保留投入/进度，恢复 | 取消退款、跨台转移或重新开同项目 |
| 完成 | 全场共享能力，研究台恢复空闲 | 重复领取、重复研究或再次扣样本 |

先验证样本、余额、前置、研究台占用和全场项目唯一性，再原子扣款/样本并登记。启动初值0AP，仅支付研究表的元石/样本，不产生有效日；工作手动1AP，雇工1次工作＋1元石。科研工资不能代替项目启动费。

研究台当天工作标记绑定**台UID＋服务日**，不能因项目完成、暂停/恢复或同台新开项目清除。研究项目也保存已接受工作日期，防止异常重放。项目进度只在日结依据当天唯一工作收据增加1；达到有效日自动解锁，无收取动作、无额外领奖AP。

手动最后1AP先登记收据再进入P8.a日结；雇工复用P8.b统一成功事务。暂停发生在当天成功工作之后不会撤销这份收据，只阻止尚未完成的未来服务。无收据不按日历时间推进，不能既在点击时增加进度、又在日结增加一次。

忙碌/暂停的研究台不能拆除，先提示当前研究与进度；首批不做转移/取消。空台和完成后可手动拆除，保持无退款规则。实例删除不能把已完成的全场知识删除。

## 3. 研究依赖与解锁校验

全部前置满足才能启动，样本只来自默认工艺或祖先工艺。研究表T09依赖同层T06，不按“整层完成才开放下一层”另加门槛。T11所需铁锭可用旧冶炼，解锁补光灯所需石板先用旧木作台R17制造；T12高密度藻样本不要求灯或自身灵食。

购买、种植、设施建造、配方启动和新食谱选择都调用统一能力判断，不能只把UI按钮置灰而让世界接口绕过。报价只读；执行重验刚变化的前置/库存/台占用。旧在制批次保存它实际支付的投入，不因其他研究完成重算产出。

全场完成项目集合用于派生能力，不同时保存一套可篡改的“所有配方已解锁”真值。快照检查：前置闭包合法、在研项目唯一、绑定研究台存在、进度在范围内、服务日不超时钟、已完成不能同时在研。正常恢复只恢复状态，不再扣款/推进/发事件。

## 4. 页面与信息导航

沿用明亮柔和UI和小图标。研究页以三层网络为主，提供模块/五行筛选；选择项目仍显示必要前置，不因为筛选把锁的原因隐藏。侧栏显示样本现货/需求、元石、有效日、已完成日、是否已工作及下一步。

样本可点击“获取路线”查看生产者/配方/研究并定位已有设施。锁定提示区分前置未达、样本不足、元石不足、他台在研、研究台忙碌；暂停说明人工未安排或负责人预算/额度/暂停，而不是统一显示“不能研究”。

研究台详情提供启动/手动工作/暂停恢复/负责人入口；名册预估只有当前在研且当天未工作才列1次研究需求。持续生产不自动选择下一研究，结束后显示“研究完成，等待选择”。

## 5. 验证场景

| 前置/样本不足、未知项目、重复启动 | 不扣款、不占台，理由准确 |
