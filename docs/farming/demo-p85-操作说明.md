# 灵田 Demo P8.5 · 操作说明

解压后运行 `LingTianDemoP85.exe`。游戏自带图片和数据，运行无需安装Blender或复制美术工作区。

本次更新七种植物的成长画面、油籽花花期和十五种设施的外观，改善放大清晰度与地面背景。经营规则继续沿用P8；游戏顶栏“手册”提供完整种植、加工、研究、养殖和购地说明。

- WASD或按住鼠标中键拖动：平移地图。
- 鼠标滚轮：缩放地图；缩得很小时适合看全场，逐株操作时请放大。
- 左键点击地格：执行当前工具或查看详情；右键切回查看工具。
- 委托模式可框选区域；手动模式点击单个目标。
- 日结执行雇工待办并自动保存；请在游戏里选择对应卷册继续经营。

松脂树采脂、蜜铃灌木采集后保留成熟株体，等待再产时显示空心圆；成熟可收取使用实心标记。砍伐和采后移除仍按原作物规则处理。

本次换图可继续现行P8档案；扩地更新之前的旧版档案仍按原提示新建。设施内部特效和额外地板尚未启用，资源点继续使用已有图标。

画面以2560×1440为主，兼容1920×1080和较小窗口。小窗口可关闭右侧详情页后查看更大的地图。
