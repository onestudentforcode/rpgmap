# Farming 正式资产风格表

唯一色值来源：`tools/farming/palette.json`；移交工具把当前色值写进每条提示词。

| 对象 | 色彩身份与结构 |
|---|---|
| 草地 | 低饱和草绿，中低频草簇，避免每格出现独立大草团 |
| 泥土 | 暖棕土块，明暗变化收敛，避免散落高亮石头 |
| 石板 | 灰绿石板，32px 周期拼缝（128 原图为 64px），避免透视收缩 |
| 耕地 | 暗暖棕，16px 周期水平垄沟（128 原图为 32px） |
| 凝露草 | 细长青绿叶簇，附着叶片的露珠蓝亮点，无漂浮光效 |
| 赤纹果 | 圆润叶簇与赤红果，成熟/无果/灰褐下垂状态可区分 |
| 青玉果树 | 扭曲老干、层叠云形树冠；青玉灵果用玉石状天然纹理，小面积浅玉高光 |
| 月华菇 | 银紫菌盖、浅玉菌褶；菌盖附着天然月牙纹，不添加漂浮月亮或粒子 |

共同风格：像素风、低饱和、东方仙侠灵植；地面低对比，作物轮廓与果实承担视觉重点。
占位图只参考结构与命名；不能将占位图视作正式质感目标。

后续素材适量加入东方玄幻元素：造型参考灵芝、古松虬干、玉石与如意云形；
纹样必须附着主体，优先用叶脉、果皮、菌盖天然纹理表达。每株只突出一至两种意象，
保持植物轮廓与阶段差异清晰，不画文字、符咒字形、悬浮法阵、光晕或大面积高饱和金色。
色彩坡道：玉色`#3e6e64 → #5fa08f → #8fd0b8 → #d8f0e4`；
月华`#575978 → #8586a5 → #b8bfd8 → #d8f0e4`。地面沿用现有低饱和环境色。

**作物母版模板：** 单株独立 Sprite，斜俯视侧后 45° 的非等距 2.5D 观感，主光左上
10–11 点方向；画布为目标尺寸2倍（普通作物128×128、青玉果树256×384），
成熟主体高度约 55–75%，左右居中、底部留 4px。
不画地面、土堆或接触阴影。两种母版并排审核后再衍生。

**阶段衍生模板：** 使用已审核母版作为 img2img/参考图，保留叶形、色相、视角、
光照与触地点；seed→sprout→growing→mature 高度递增。采后只去果，枯竭改灰褐并下垂。
每张独立生成，禁止依赖 AI 输出完整 SpriteSheet。

**地面模板：** 128×128 正方形，正俯视平面四向可平铺纹理，2–4 色阶，中低频细节；
不做每块砖独立投影或整张明暗渐变。回传后本机 NEAREST 降为 64px 并无缝化。

**负面提示词：** isometric, perspective scene, environment, ground under plant,
contact shadow for sprite, text, watermark, bloom, glow, translucent edges,
anti-aliasing, photorealistic, smooth gradients, sprite sheet。

验收：目标原尺寸及放大 NEAREST 图、地面 3×3 平铺、作物阶段排图与场景截图。
机器 QC 通过后仍需视觉审查。主体占比按 bbox 高度/画布高度计算，锚点按 bbox 底部中心计算。
色板越界为告警；无缝混合可能产生中间色，需要审核细节密度，不强制自动量化。
