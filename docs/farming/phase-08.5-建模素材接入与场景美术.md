# Phase 8.5 — 建模素材接入与场景美术

> 日期：2026-10-14。状态：**草案，待实施；各项验收尚未完成。**
> 目标：合理使用美术工作区的 Blender 建模素材，建立可复现、可校验的「3D 建模 → 离线渲染透明 2D 图片 → Godot 2D 场景」管线，分批改善 P8 世界画面。
> 基线：[P8 分阶段实施与关闭记录](phase-08-分阶段实施计划.md)、[总规划](master-plan.md)。本阶段复用 P8 的玩法、数据、地格和档案，不新增经营系统。

## 1. 策略与范围

美术生产采用 Blender 参数化建模，以固定机位、灯光和材质生成成长阶段及必要状态图。Godot 运行时继续使用 2D 地形与精灵，只接入选定 PNG 和视觉元数据。生图模型可用于概念探索和参考，不再作为本批植物整图生产的默认入口。

本次策略更新覆盖新资产的生产方式，不恢复 `archive/old-farming/` 的运行依赖。`project.godot` 的 `import/blender/enabled=false` 保持：游戏运行、导入和发布不依赖本机 Blender 或美术工作区。

**本阶段必须完成：**

- 七种 P8 植物的四阶段与油籽花独立花期接入。
- 统一根点、等比尺度、透明边与植物/设施遮挡次序。
- 成长、采后、操作及读档的视觉映射与反馈。
- 建模设施资产的可用性审计，并按确认清单分批接入具备完整规格的素材。
- 同屏、密种、扩地、缩放及独立 Windows 包的资源验证。

**范围边界：**

- 64 单位逻辑地格、真实 footprint、占地判定、点击与寻路契约保持不变；不迁移为实时 3D，也不在本阶段重构为等距坐标系。
- 保持 P8 生长、产量、花源、研究、预算、日结和存档语义；不因素材不足改生产规则。本阶段原则上无需升级 schema17。
- UI 工具、市场、资源和任务图标沿用现有接口，世界图片使用独立视觉清单。
- 地面先沿用现有素材进行拼装验证；全面地形重绘、全设施建模、动物独立地图实体及旋转镜头另排。
- 松脂树无脂采后图、蜜铃灌木无蜜/闭花采后图尚未交付，本阶段用状态标记表达等待再产；新增整图另开美术批次。

## 3. 共同接入契约

### 3.1 文件与清单

游戏目录使用 `assets/farming/crops/<真实crop_id>/stage_0..3.png`，油籽花另有 `flowering.png`；运行清单建议为 `assets/farming/crops/plant_manifest.json`。保留物种、阶段路径、画布、`anchor_uv`、绘制尺寸和来源校验信息。来源记录与运行配置可分开保存，运行时不得依赖工作区绝对路径。

只搬运选定的游戏资源；`.blend`、脚本、主图、带标签对照图和QC记录留在美术侧或开发资料侧。导入工具核对源哈希和尺寸，先验证整批再写入；失败应报告具体文件，不混合新旧阶段。重复执行相同输入应得到相同清单与PNG。

### 3.2 根点与尺度

根点采用 Blender 世界原点在图片中的投影，读取精确 `anchor_uv`，不能用 alpha bbox 底部代替。默认地面根点为玩法占地矩形底边中心：

```text
ground_root = ((origin.x + footprint.x / 2) × 64,
               (origin.y + footprint.y) × 64)
top_left = ground_root - draw_size × anchor_uv
```

保留负数 `origin.x`。建模标定为1格＝2 Blender单位，以32 Godot单位/Blender单位计算初始绘制宽，绘制高按图片比例计算。

| 物种 | 初始完整画布绘制尺寸（Godot单位） |
|---|---|
| 金穗麦、油籽花 | 75.2×75.2 |
| 木腐菇 | 70.4×70.4 |
| 青牧草 | 67.2×67.2 |
| 蜜铃灌木 | 72×72 |
| 速生杉 | 123.2×184.8 |
| 松脂树 | 115.2×172.8 |

以上为拼装起点。需要调整时按物种设置统一倍率，四阶段与花期共用该倍率。禁止逐阶段裁透明边、重新居中、按bbox填满地格或非等比拉伸。

35°斜俯视正交是本批物件的渲染机位，不直接推导为游戏地格需要做投影变换。物件与现有地面的接地感需实际拼装验证；如不协调，先检查根点、尺度和出图机位，另开地面试样，不直接改坐标系。

### 3.3 显示与降级

纹理在初始化或首次访问时缓存；绘制循环不重复读PNG。缺图保留可见占位并给出物种、阶段、路径诊断，同一错误避免每帧刷屏。原UI图标接口继续可用。

新图片允许连续alpha、渐变和抗锯齿，采用无损导入；过滤在视觉层明确配置。是否启用mipmap及是否派生128/256尺寸，通过真实缩放截图决定，不把1280主图直接作为全批默认运行资源。

地面先画；植物与设施按地面根点共同排序，同根点采用稳定次序；选择、成熟、缺水和任务标记最后画。一个Node2D内的自定义draw命令需显式排序，不能仅靠打开Y-sort解决。
