## 1. 五行材料定义

**这里的五行不是相生相克关系，而是物质的五种游戏分类。**

| 属性 | 材料的定义 | 典型材料 |
|---|---|---|
| 木 | 生物组织、有机纤维、未精炼植物资源 | 木材、牧草、果实、菌体、丝 |
| 金 | 提炼出的金属、金属丝、特殊矿物晶体（与土属性的分界规则见 §1.1） | 铁、金属丝、矿盐、珍珠 |
| 水 | 水、溶液、凝胶及可流动液态资源 | 清水、露水、盐卤、凝胶 |
| 火 | 燃料、可燃物、热能载体 | 木炭、油脂、树脂、储热物 |
| 土 | 土壤、腐殖质、黏土、岩石、砂砾与松散沉积物（v2 三分类，见 §1.1） | 肥土、菌渣、砂岩、花岗岩、砂子、矿砂 |

两条核心设定：

1. **物种不固定归属某一种属性，同一物种可产出多种属性的材料。**
   - 松脂树：木材（木）、松脂（火）
   - 钢绵羊：钢绒（金）、粪肥（土）
   - 珍珠蚌：珍珠（金）、软体组织（木）
   - 木腐菇：菌菇（木）、腐殖质（土）
2. **尽量遵守物质与能量的来源约束。** 钢绵羊需要从饲料或矿物补充剂中摄取铁才能长出钢绒；凝露生物需要空气湿度才能收集水。这使经营系统有真实的生产逻辑，而不是凭空生成资源。

### 1.1 土属性三分类（v2 扩展）

此前土属性定义过于偏向农业（围绕土壤、肥料、淤泥展开），缺少岩石、砂砾、矿层和石质建材这一大类资源，扩展为三个类别：

| 分类 | 代表原料 | 核心用途 |
|---|---|---|
| 土壤类 | 泥土、沃土、腐殖土、淤泥、黏土 | 种植、堆肥、烧砖 |
| 岩石类 | 砂岩、石灰岩、花岗岩、玄武岩 | 建筑、粉碎、矿物提取 |
| 砂砾类 | 砂子、碎石、石粉、矿砂 | 建材、过滤、矿物分选 |

**金/土分界规则**：天然岩石和未经提炼的矿石归**土**属性；提炼出的金属、金属丝以及特殊矿物晶体归**金**属性。

例：铁矿石（土）→ 冶炼 → 铁（金）。

## 2. 种植模块：24 种候选作物

### 2.1 花草类（6 种）

| 物种 | 产出 | 特点与用途 |
|---|---|---|
| 青牧草 | 牧草（木）、草籽（木） | 基础饲料作物，生长快、成本低；牧草喂草食动物，多余堆肥 |
| 金穗麦 | 谷粒（木）、秸秆（木） | 谷粒供动物食用或发酵；秸秆作菌菇培养基、垫料或低级燃料——多产业链基础原料 |
| 纤麻 | 麻纤维（木）、麻籽（木） | 纤维用于绳索织物，麻籽可榨油；偏加工工业的作物 |
| 油籽花 | 油籽（木）、花瓣（木） | 油籽榨植物油（火），榨油残渣制蛋白饲料；兼顾能源与畜牧 |
| 露滴草（幻想植物） | 露水（水）、草叶（木） | 叶面特殊凝露结构；环境湿度越高露水产出越多，可与集露装置组合 |
| 盐蓄草 | 富盐茎叶（木）、盐卤（水） | 盐碱地生长、富集盐分；盐卤蒸发结晶得矿盐（金） |

六种功能分别是：**基础饲料、谷物、纤维、油脂、集水、盐分富集**——尽量避免同一类作物只是产量不同。

### 2.2 灌木类（6 种）

灌木的特色：**持续采摘、不必频繁重种**，产出偏向特殊果实、汁液与精细材料。

| 物种 | 主要产物 | 生长特点 | 主要用途 |
|---|---|---|---|
| 蜜铃灌木 | 花蜜（木）、花粉（木） | 开花期持续分泌花蜜 | 养蜂、酿造 |
| 浆莓灌木 | 浆果（木）、枝叶（木） | 季节性结果 | 动物饲料、糖液发酵 |
| 胶汁灌木 | 天然乳胶（木） | 割胶后逐渐恢复 | 胶料、密封材料 |
| 蜡果灌木 | 植物蜡（火）、果肉（木） | 喜温暖干燥环境 | 蜡烛、燃料、防水加工 |
| 铁刺灌木 | 含铁棘刺（金）、枝条（木） | 需要富含铁的土壤 | 生物采矿、金属原料 |
| 酸浆灌木 | 酸性汁液（水）、果渣（木） | 需要较肥沃土壤 | 矿物浸取、特殊加工 |

**重点推荐：铁刺灌木（生物富集采矿）。**

它将土壤中的微量铁逐渐富集到棘刺中。玩家需向种植区提供含铁矿粉，或寻找天然富矿土壤。由此形成一种替代关系：

- **矿石开采 → 直接冶炼**：速度快；
- **富矿土壤 → 生物富集 → 收获金属棘刺**：可持续生产，但需要维护土壤中的矿物储量。

### 2.3 树木类（6 种）

树木生长时间长但寿命高，适合成为**中长期生产设施**。

| 物种 | 主要产物 | 采集机制 | 用途 |
|---|---|---|---|
| 速生杉 | 原木（木）、树枝（木） | 周期性砍伐、重新种植 | 建筑、木炭、木屑 |
| 果桑树 | 桑叶（木）、桑果（木） | 周期性采摘 | 蚕饲料、果实饲料 |
| 松脂树 | 松脂（火）、木材（木） | 割脂采集 | 燃料、胶黏材料 |
| 油桐树 | 油桐籽（木）、木材（木） | 季节性结果 | 工业植物油 |
| 雾冠树 | 凝结水（水）、木材（木） | 潮湿天气集水 | 水资源生产 |
| 钙骨树 | 矿化树皮（金）、木材（木） | 周期性剥取树皮 | 石灰质材料、矿质原料 |

**树木设计两种采集模式**：

- **可持续采集**：不杀死树木——摘果、采叶、割胶、收集露水、剥取部分树皮；
- **破坏性采集**：直接砍伐获得大量木材，但需重新种植。

玩家因此面对具体的经济决策：**保留一棵成熟的松脂树长期采脂，还是砍掉它立即获得大量木材？**

### 2.4 真菌 / 蘑菇类（6 种）

真菌不依靠光合作用，而是依赖其他生产模块提供的有机物或特殊培养基——**天然适合承担废料循环、特殊材料转化和高级培养功能**。

| 物种 | 主要消耗 | 主要产物 | 生产用途 |
|---|---|---|---|
| 草腐菇 | 秸秆、牧草碎料 | 菌菇（木）、菌渣（土） | 处理农业废料 |
| 木腐菇 | 木屑、树皮 | 菌菇（木）、腐殖土（土） | 木材废料回收 |
| 酝酿菌 | 糖液、谷物浆 | 酵母菌体（木）、发酵液（水） | 酒精生产的菌种 |
| 油脂霉 | 糖液、有机培养液 | 菌脂（火）、菌渣（土） | 生物油脂生产 |
| 净水菌毯 | 含有机污染物的水 | 净化水（水）、污泥（土） | 污水处理 |
| 金囊菌 | 含矿粉培养基 | 矿菌核（金）、菌体（木） | 生物矿物富集 |

**高级真菌示例——金囊菌**：分泌有机酸分解培养基中的矿物，将特定元素沉积在菌核中。游戏中要求它消耗腐殖土、低品位矿粉与水，逐渐产出可用于精炼的矿菌核。

以上 24 种作物覆盖了较完整的农业原料来源。

## 3. 畜牧模块：10 种候选动物

动物与植物的区别：**植物通过光、水、养分缓慢积累资源；动物通过进食已有材料完成更有针对性的物质转化。** 每种动物至少有一项无法被其他普通动物替代的能力。

| # | 物种 | 食物 | 产物 | 机制要点 |
|---|---|---|---|---|
| 1 | 钢绵羊 | 青牧草、谷物、含铁矿盐 | 钢绒（金）、粪肥（土） | 消化草料营养、利用摄入的铁形成金属纤维；周期性剪毛 |
| 2 | 岩腹兽 | 含矿岩石（土）、少量草料（木） | 富集矿砂（土）、尾砂（土） | 消化道分离岩石中的矿物成分；富集矿砂继续冶炼才能得到金属（金），避免凭空生成金属（v2 调整） |
| 3 | 炭腹虫 | 木屑、枯枝、秸秆 | 炭丸（火）、有机粪土（土） | 共生微生物将部分有机物转化为富碳颗粒；需维持较高巢穴温度 |
| 4 | 叶丝蚕 | 桑叶 | 蚕丝（木）、蚕蛹（木） | 高品质纤维；蚕蛹可再加工为动物蛋白饲料 |
| 5 | 蜜盏蜂 | 花蜜、花粉 | 蜂蜜（木）、蜂蜡（火） | 蜂蜜用于发酵/饲料、蜂蜡作燃料或工业原料；还能提高部分作物授粉效率 |
| 6 | 露壳蜗牛 | 湿润草叶、嫩叶 | 凝露（水）、黏液（水） | 外壳吸附空气中水汽；产水效率受湿度影响，适合温室养殖 |
| 7 | 矿鳞蜥 | 富矿饲料、矿盐、少量昆虫 | 矿质鳞片（金）、蜕皮（木） | 吸收矿物沉积于鳞片；须等蜕皮周期才能大量收获——慢速高价值材料生产者 |
| 8 | 堆肥鼠 | 落叶、坏果、农业有机废料 | 高肥粪土（土）、少量兽毛（木） | 消化道微生物处理低价值有机物，快速转为有机肥 |
| 9 | 啮岩鼹 | 菌菇（木）、水（水）——**加工对象是天然岩石（土），不食岩** | 碎石（土）、石粉（土） | 以有机物为食、用坚硬牙齿挖掘岩层；不同岩石决定破碎效率，特定矿层可产出少量特殊矿物副产物（v2 新增） |
| 10 | 砾甲蜗牛 | 石粉（土）、藻料（木）、水（水） | 岩壳片（土）、黏液（水） | 摄入矿物与自身分泌物生长层状硬壳；周期性采集外层岩壳，可加工成石板等建材（v2 新增，中期实装） |

十种动物分别承担：**金属纤维生产、矿物分选、岩石破碎、石料成型、炭化、纺丝、酿蜜、集水、矿化、堆肥**。

**动物不只是加工机器**——饲养方式应产生差异：钢绵羊产毛速度受饲料品质影响；矿鳞蜥必须在特定环境中蜕皮；蜜盏蜂需要附近存在开花植物。

## 4. 水产模块：9 种候选动物

水产不能只是把畜牧动物换成鱼类，它有自己的生产优势：

- 能处理水体中的悬浮有机物和底泥；
- 能从盐水、矿化水中富集材料；
- 能生产陆地不易获得的凝胶、珍珠和水生油脂；
- 部分水生动物直接参与水质净化、温度调节。

| # | 物种 | 摄入 | 产出 | 定位 |
|---|---|---|---|---|
| 1 | 滤藻鲤 | 微藻、水草、悬浮颗粒 | 鱼肉（木）、鱼粪（土） | 水产基础鱼类，处理过剩藻类 |
| 2 | 珍珠蚌 | 浮游生物、水中矿物 | 珍珠（金）、贝壳（金） | 高价值矿化材料，兼具滤水能力 |
| 3 | 油鳍鱼 | 高营养藻料、谷物饲料 | 鱼油（火）、鱼肉（木） | 水产油脂生产，与陆地油料作物竞争 |
| 4 | 净泥鳅 | 底泥有机碎屑 | 肥泥（土）、鱼肉（木） | 处理池塘沉积物、减少淤积 |
| 5 | 盐背蟹 | 盐水中的藻类和微生物 | 盐晶（金）、蟹壳（金） | 盐水养殖、盐分富集 |
| 6 | 凝胶水母 | 浮游生物 | 凝水胶（水）、胶质膜（木） | 保水凝胶、特殊液态材料 |
| 7 | 暖潮鳗 | 小型水生生物、藻料 | 蓄热鳞片（火） | 吸收温泉/地热池热量，形成可采集的储热材料 |
| 8 | 砂滤虾 | 浮游藻、矿砂中的有机颗粒 | 砂珠（土）、矿化虾壳（金） | 池底沉积物处理与矿物富集 |
| 9 | 礁骨珊瑚 | 富含钙和碳酸盐的海水（水）、浮游生物（木） | 珊瑚石（土） | 生物造岩：不断沉积碳酸钙形成礁体，定期采集部分礁石（现实造礁珊瑚同机制；v2 新增） |

**基础生产资源：藻类。** 微藻作为水产模块的基础培养物，而**不是**新增第五大种植类别。藻池消耗光照、营养盐、二氧化碳和水，生产藻料（木）；藻料可直接喂鱼，也可经干燥、压榨成为其他动物的饲料原料。

## 5. 岩石产业线（v2 新增）

### 5.1 岩石生物加工链：四种生产能力

为岩石资源配置四种不同功能的动物，避免它们都只是简单地"吃石头、排石头"：

| 动物 | 生产能力 | 输入 | 产出 |
|---|---|---|---|
| 岩腹兽 | 矿物分选 | 含矿岩石 | 富集矿砂 |
| 啮岩鼹 | 岩石破碎 | 完整岩石 | 碎石、石粉 |
| 砾甲蜗牛 | 石料成型 | 石粉 | 岩壳片 |
| 礁骨珊瑚 | 生物造岩 | 矿化海水 | 珊瑚石 |

### 5.2 岩石种类与生产价值

岩石不应该只有硬度差异，还应该存在不同的加工用途：

| 岩石 | 属性 | 特色 | 加工用途 |
|---|---|---|---|
| 砂岩 | 土 | 易于破碎，获取成本低 | 砂子、建筑石块 |
| 石灰岩 | 土 | 富含碳酸钙 | 石灰、钙质饲料添加剂 |
| 花岗岩 | 土 | 坚硬、耐久 | 高强度石板、建筑 |
| 玄武岩 | 土 | 硬度高，耐热性好 | 耐热石材、岩棉 |
| 含铁矿岩 | 土 | 含有可提取的金属成分 | 富集矿砂、冶炼 |
| 珊瑚石 | 土 | 生物来源、多孔 | 过滤介质、石灰质材料 |

**珊瑚石特别值得保留**：它赋予水产模块生产建筑资源的能力，而不是只生产鱼肉、鱼油、珍珠。与陆地开采岩石相比，珊瑚石可以持续生长，但速度缓慢，需要保证水中的钙质和其他生长条件。

### 5.3 资源来源三分原则

在岩石系统里区分三种资源来源：

- **天然资源获取**：地图开采、地下矿层、河床采集——提供岩石和矿物的初始来源；
- **生物资源加工**：啮岩鼹破碎岩石、岩腹兽富集矿物、砾甲蜗牛生产石质材料——改变材料的形态、纯度和使用价值；
- **生物资源积累**：珊瑚通过消耗水中溶解的矿物，缓慢形成新的固态石料。

**核心约束：动物可以改变材料的形态、纯度和使用价值，但不能无代价地增加物质。**

### 5.4 土属性双产业路线

土属性由此有两条完整且相对独立的产业路线：

```
农业路线：有机废料 → 腐殖土 → 种植 → 饲料 → 动物粪肥（循环）
地质路线：天然岩石 → 破碎 / 富集 → 砂砾、矿砂、成型石材 → 建筑 / 冶炼 / 工业
```

两条路线可以通过**矿物肥料、石灰改良土壤、植物为碎岩动物提供饲料**等环节连接。

**后续继续设计物种时保持此思路：土属性同时承担农业基质与无机建筑材料两种功能，不必再新增独立的"岩属性"。**

## 6. 长期候选优先集：18种（非Demo V1清单）

原P0名单保留为种植、畜牧、水产全景设计的优先集。用户已确认V1只做四种核心植物，其他成员按模块分期，不因为出现在此表而进入V1验收。

候选库中部分功能存在重合（油籽花 vs 油桐树、铁刺灌木 vs 矿鳞蜥）。重合未必是坏事——后续可通过生产效率、空间、环境条件和副产物制造区别。但**初版验证阶段优先保证产业链闭合**。

**长期优先物种名单：**

| 模块 | 物种 |
|---|---|
| 花草 | 青牧草、金穗麦、油籽花 |
| 灌木 | 蜜铃灌木 |
| 树木 | 速生杉、果桑树、松脂树 |
| 真菌 | 木腐菇、油脂霉 |
| 畜牧 | 钢绵羊、岩腹兽、啮岩鼹、蜜盏蜂、堆肥鼠 |
| 水产 | 滤藻鲤、珍珠蚌、净泥鳅、礁骨珊瑚 |

v2 调整：**岩腹兽（机制调整）、啮岩鼹、礁骨珊瑚列入初期优先**；**砾甲蜗牛放到中期**，用来引入高级建材生产。

### 产业链 A：农业废料循环

```
青牧草 / 金穗麦 / 果桑树 → 牧草 / 果实 → 动物饲料
                        ↘ 秸秆 / 木屑 → 真菌培养基
动物粪肥 / 废菌渣 → 堆肥加工 → 肥沃土壤（土）→ 回到种植区，提高作物产出
```

### 产业链 B：生物材料生产

```
青牧草（木）＋ 含铁矿盐（金） → 钢绵羊 → 钢绒（金） → 纺丝、金属制造
                                      ↘ 粪肥（土）→ 回到种植系统
```

### 产业链 C：燃料生产

```
油籽花 → 榨油 ┐
松脂树 → 割脂 ├→ 植物油 / 松脂 / 酒精（火）→ 燃烧、供能、热量收集
浆果 / 谷粒 → 发酵 + 蒸馏 ┘
```

### 产业链 D：地质与建材（v2 新增）

```
天然岩石 ─→ 啮岩鼹破碎 ─→ 碎石 / 石粉 ─→ 砂砾建材、砾甲蜗牛成型（中期）
含铁矿岩 ─→ 岩腹兽富集 ─→ 富集矿砂 ─→ 冶炼 ─→ 金属（金）
矿化海水 ─→ 礁骨珊瑚 ─→ 珊瑚石 ─→ 过滤介质、石灰质材料
```

四条链提供不同玩法：**农业循环、生物制造、能源生产、地质建材**——而不是单纯依靠种田获得资源。

## 7. 物种名单四规则

1. **先确定功能生态位，再决定物种名字。** "吃矿石并产出精矿""利用空气湿度集水""将秸秆分解为肥料"都是值得保留的独立功能；只有外形不同、资源产出完全相同的动物可以暂时合并。
2. **每种动物至少要有一个主产物和一个合理的副产物。** 主产物决定玩家养殖它的原因，副产物帮助它与其他模块形成联系；但不强制每种动物都拥有两种资源产出。
3. **资源转化必须有来源和代价。** 铁刺灌木从土壤提取铁，应降低土壤的矿物储量；堆肥鼠生产有机肥，必须消耗有机废料；燃烧木材收集到的"火焰"可设定为幻想储能技术，但必须有燃料消耗和收集效率——避免无成本的无限资源循环。
4. **不要让五行分类限制物种设计。** 一只动物产出木、金、土三类资源完全合理。**五行是玩家管理材料的标签，不是限定资源转换方向的规则。**

## 8. 下一步：资源生产关系表

> **推进顺序已由 [design-outline.md](design-outline.md)（V0.2 纲要）§12 确定为总入口**：先从 43 种候选确定首批名单 → 逐个记录基础消耗/特殊增益需求/主产物/副产物/下游用途 → 资源流向明确后按同类工艺归并加工建筑；[economy-systems.md](economy-systems.md) §10 的三表方案并入此流程。

候选库解决"世界里有哪些生物可以生产资源"；下一轮把重心转移到**物种的输入、输出和加工依赖**。以下是长期18种优先集的示例，当前V1先补全四植物和天然资源点，正式首批关系见[资源表](demo-v1-resources.md)：

| 生产者 | 输入 | 直接产物 | 可加工产物 | 下游消费者 |
|---|---|---|---|---|
| 青牧草 | 水、土壤养分、光 | 牧草、草籽 | 干草、草粉、堆肥 | 钢绵羊、堆肥鼠 |
| 速生杉 | 水、养分、光 | 原木、枝条 | 木炭、木屑、木板 | 木腐菇、加工设施 |
| 钢绵羊 | 牧草、铁质补料 | 钢绒、粪肥 | 金属丝、肥土 | 制造业、种植业 |
| 木腐菇 | 木屑、水 | 菌菇、菌渣 | 干菌、腐殖土 | 饲料加工、种植业 |
| 珍珠蚌 | 浮游生物、矿物质 | 珍珠、贝壳 | 珍珠粉、贝壳粉 | 制造业、饲料加工 |
| 岩腹兽 | 含矿岩石、少量草料 | 富集矿砂、尾砂 | 冶炼金属（金） | 冶炼设施、建筑业 |

（行为示例，正式表待补全。）

**本系统最有潜力的设计点**：同一种原料可以进入不同生产路线，而不同生产路线又能产出具有相同属性、但用途不同的材料。例如木材既可燃烧获得热量，也可炭化制成木炭，或粉碎后作为真菌培养基。**玩家选择的不是简单的"五行转换配方"，而是如何组织整个生产系统、决定资源流向哪条产业链。**

因此后续不必急于增加更多物种：先用V1四植物、资源点和加工构建可运行依赖图，再沿长期18种优先集扩展，检查——

- [ ] 有没有孤立产物（无消费者、无加工路线）
- [ ] 有没有无法获得的饲料
- [ ] 有没有缺少回收途径的废料
- [ ] 有没有可能无限增殖资源的循环

——再决定优先集之外的25种候选如何加入。
