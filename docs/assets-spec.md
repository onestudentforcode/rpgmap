# 资产规格（ComfyUI 对接用）

MVP 当前用 `tools/gen_placeholder_assets.py` 生成的程序化占位图。
ComfyUI 正式图到位后，**按本规格覆盖 `assets/` 下同名文件即可**，
Godot 自动重导入，无需改任何代码或场景。

## 通用要求

- 格式：PNG，RGBA；**alpha 只允许 0 或 255**（半透明像素会糊边）
- 缩放：一律 NEAREST 最近邻（大图 → 小图降采样同理）
- 色板：每张资产 ≤ 16 色，颜色从一个统一调色板取（见下）
- 风格基调：暖米色大理石地面 / 深青绿墙体 + 黄铜饰线 / 深红地毯；
  角色深色大衣 + 橙红围巾。整体低饱和、略带 Limbus 式压抑百货感

## 1. assets/tileset.png —— 224×32，单行 7 枚 32×32 图块

| 列 | 用途 | 语义 |
|---|------|------|
| 0 | 大厅地砖 A | 米色大理石，右/下 1px 拼缝线（平铺出网格感） |
| 1 | 大厅地砖 B | 同上略深，作点缀变体 |
| 2 | 地毯 | 深红 + 菱形暗纹，可平铺 |
| 3 | 后廊地面 | 灰绿色水磨石，右/下拼缝线 |
| 4 | 墙体 | 深青绿墙板 + 顶部深色压条 + 一条黄铜横线（碰撞块） |
| 5 | 门洞 | 东西墙通道门：黄铜门框 + 暖光门洞（可行走传送格） |
| 6 | 虚空 | 近黑（碰撞块，当前地图未用到，保留备用） |

## 2. assets/player.png —— 128×192，4 方向 × 4 帧，帧 32×48

- 行序（上→下）：**下 / 左 / 右 / 上**；列序（左→右）：**待机 / 迈步1 / 过渡 / 迈步2**
- 代码读取方式：`Rect2(col*32, row*48, 32, 48)`；行走动画取列 1,2,3,2 循环 @8fps
- 角色：脚底必须贴帧底边（引擎以脚底做 Y-sort 锚）
- ComfyUI 建议：先出一张立绘大图，再手工切出四向行走帧；
  或只出下/左两向，右=左镜像，上=下帧去脸

| 区域 (x,y,w,h) | 用途 | 说明 |

| (32,0,32,32) | 货架 | 深木框 + 两层彩色商品， solid |
| (64,0,32,32) | 盆栽 | 陶盆 + 绿叶， solid |
| (96,0,32,32) | 告示牌 | 木柱 + 米纸板 + 墨线， solid |
| (128,0,32,64) | 电梯门 | 32×64 竖长：黄铜框 + 双开金属门 + 顶部红色指示灯 |
| (160,0,16,16) | E 提示气泡 | 深底白框 + 像素 "E" |
| (176,0,32,48) | NPC 帧 1 | 32×48，脚底贴帧底边 |
| (208,0,32,48) | NPC 帧 2 | 同上，整体上移 1px 的待机呼吸帧 |

## QC 检查（替换后必跑）

```bash
python tools/gen_placeholder_assets.py   # 占位管线自带 QC，可参考其检查逻辑
```

- 尺寸与上表完全一致（引擎按固定区域取图，尺寸错了会串图）
- alpha 二值、无半透明毛边
- 逐张肉眼核对四向行走帧方向正确、脚底对齐

## 运行方式

- 编辑器：Godot 4.7 打开本目录，F5 运行
- 命令行：`Godot_v4.7.2-stable_win64_console.exe --path .`
- 自测：`... --headless --path . -- --selftest`
- 截图：`... --path . -- --shots=<输出目录>`
